# Component Lab Guidelines

## Purpose

组件库是当前原型的 UI 样式事实来源。当前 `/component-lab` 只展示样式 C 主线组件；旧强调态、样式 A/B、样式 D 和重复过程稿迁入 `/component-drafts`，不再混在当前交互组件页里。

## Views

交互组件页支持：

- 分栏：左侧组件目录，右侧查看选中组件与样式参数。
- 平铺：一次性查看所有组件，用于总览和一致性检查。

交互组件页在分栏 / 平铺之上增加二级分页：

- 通用组件：跨页面复用的基础控件和状态原语。
- 工艺执行：工艺参数、路径点位、3D 视窗和工艺规划任务面板。
- 生产执行：生产工位、设备状态、托盘管理和 AGV 调度。

每个分页内的组件分组使用风琴式折叠：

- 默认展开当前分页的第一个分组。
- 展开任一分组时，当前分页内其它分组收起。
- 分栏目录和平铺总览使用同一组折叠状态，避免长页面丢失层级逻辑。

交互组件页按四层信息架构治理：

- 基础交互控件：按钮、输入、Slider、Checkbox、多选和对象选择等跨页面原语。
- 领域复合组件：工艺参数、点位、路径、安全点、关节角和组合参数卡片。
- 工作区 / 视窗组件：3D 视窗壳、顶部工具条、视窗内玻璃浮层、模型对象 pill 和特征回显；不得混入任务面板应用变体。
- 场景应用变体：按业务边界展示页面组合，工艺规划、生产执行和托盘管理分别成组。

新增 `/component-drafts` 作为过程稿留档页，用于收纳旧白底橙色强调态、样式 A/B 完整大卡片、样式 D 圆角玻璃浮层和重复探索稿。`/component-lab` 保持当前样式 C 的详细 demo，不再展示完整旧强调态组件。

新增 `/component-system` 作为 code-first 组件系统一致性控制台，原 `/component-lab` 保持详细 demo 和过程稿入口。

新增 `/component-demo` 作为纯 bento 展示页，用于展示组件在页面中的美感、秩序感和轻量动效。该页的动效契约记录在 `docs/frontend/component-demo.md`；它不替代 `/component-lab` 的状态矩阵、规格记录和组件治理职责。

`/component-system` 用于：

- 展示组件 registry 草案：分类、契约、demo、token 覆盖、应用位置和风险。
- 展示状态覆盖矩阵：default、hover、selected、execution-active、open、invalid、disabled、loading、dirty。
- 展示风险队列：重复实现、token 覆盖不足、业务复合组件漂移风险。
- 扩展视觉标尺库：间距、高度、圆角、任务面板真实宽度、树缩进和方向性阴影。
- 指引后续把 `/component-lab` 的 `componentSections` 和 `componentContracts` 收敛为同一份 `componentRegistry`。

## Required Sync Rules

- 主页面新增或修改组件样式，必须同步组件库。
- 组件库新增基础组件后，复合组件应引用基础组件，而不是复制视觉规则。
- 组件库需展示默认、异常、置灰状态。
- 视觉监控点云示例中，默认态展示 `WP-06` 异常等待机，异常态才加载真实点云并通过 `VisionFeedBar` 同时覆盖异常红、告警黄、正常绿、离线灰四种状态，置灰态展示视觉能力不可用。
- 生产执行组件区保留 `GantryVisionScanPanel` 的重构结果异常示例，仅作为 Component Lab 组件展示；原始第二种异常处理和 `demo` 变体继续保留。新增 `VisionExceptionDemoPanel` 的 8 视觉 Tab Demo：Tab 切换点云观察角度和异常结果字段，一次只展示当前视觉面板；桁架、搬运和焊接视觉分别覆盖六轴、抓取 / 直线 / 圆弧定位和测量交点 XYZ，均覆盖编辑结果、重新扫描、扫描中和跳过 / 确定状态。
- 生产执行组件区必须展示工位手动控制示例：一个覆盖机器人和 J1-J16 的长列表工位，一个覆盖物料编辑、搬运机器人和 AGV 取货点的托盘工位；两者都直接复用 `ProductionManualControlPanel`。
- 影响布局的组件必须在平铺视图中检查溢出。
- token utility 或跨组件规则优先放在“组件契约”页，而不是塞进单个交互组件示例；例如 `label-input gap`、`title-content gap` 在规则卡片中展示。
- 规则展示必须同时写明规则名、唯一 class、token 值和像素值，并放置 2 个以上真实控件样例，确保规则不是孤立文字说明。
- 新增或调整基础组件时，应同步检查 `/component-system` 中的 registry、状态矩阵、风险队列和视觉标尺是否需要更新。

## Rule Visualization

`label-input gap` 是参数项 label 到 input surface 的垂直间距规则：

- 唯一 class：`ds-parameter-field`
- 当前值：`gap: ds-075` / `6px`
- input 范围：输入框、选择器、分段选择、多选、Slider 和只读回显框
- Component Lab 表现位置：`组件契约` -> `参数间距规则 / label-input gap`
- 可视化方式：同一卡片内并排展示数字输入、对象多选、分段选择、只读回显和 Slider，外加 6px 标尺；这些样例必须直接使用 `ds-parameter-field`

`title-content gap` 是参数卡片内标题到下面主要控件的专用间距规则：

- 唯一 class：`ds-parameter-card-title-stack`
- 当前值：`gap = ds-200` / `16px`
- 应用范围：抓取页的覆盖率阈值、安全阈值系数、偏心距阈值、抓取路径设置：安全点高度
- Component Lab 表现位置：`组件契约` -> `参数卡片间距规则 / title-content gap`
- 可视化方式：展示 3 个阈值卡片和 1 个安全点高度卡片，外加 16px 标尺；这些样例必须直接使用 `ds-parameter-card-title-stack`

方向性阴影必须在组件库中场景化展示，避免只看 token 方块误用方向：

- Component Lab 表现位置：`Design Token` -> `阴影应用方式 / Directional Shadow Usage`
- `shadow.footerUp` / `shadow-ds-footer-up`：用于任务列表下端操作条、工艺参数设置 footer，表现为向上的外投影，不叠加顶部白色 stroke。
- `shadow.scrollEdgeBottom`：只用于滚动容器底部的薄 inset hint，不用于 footer 或操作条。
- `shadow.stickyOverlap`：用于 sticky heading 遮挡内容时的向下投影。
- 组件库必须展示 inset footer shadow 反例，标明不要使用。

## Current Important Components

- 主导航任务菜单：Component Lab 的“导航、浮层与反馈”分组展示工艺规划与虚拟仿真菜单的先展开交互、任务关闭入口和底部新建入口；任务标题统一为 `14px / 400`，虚拟仿真来源副标题为 `11px / 400`，使用 `来源 · 名称` 格式。该示例同时展示一个本地副本内第 06 / 12 道装配任务的收起态、浅橙选中态和整条删除入口。
- 虚拟仿真多焊接任务：工艺执行的场景应用变体使用真实 `SimulationTaskPanel`、`SimulationProgramPanel` 和 `SimulationProgramGenerateDialog`，展示第 06 道的焊接任务1 / 2、加工程序1 / 2、独立轴值，以及访问末页后保持解锁的 caret 分页交互；同时保留第 12 道单焊接任务切换状态。
- 带单位输入框：输入框内单位正常态使用 `text-slate-300`，异常态使用 `text-red-300`。
- 对象/特征多选下拉。
- 样式 C 点位信息组件，当前只展示任务列表路径点位的 xyz + rpy 轻量选中态；旧 xyz / xyz+rpy 橙色强调态进入 `/component-drafts`。
- 工艺安全点浮窗，包含分组 tab、图例折叠、单点启用/禁用状态；当前只展示样式 C 低调卡片变体；旧强调态安全点卡片进入 `/component-drafts`。
- 手动特征提取浮窗，覆盖焊缝/打磨入口拆分后的 3D 视窗内操作面板；面板宽度与装配基准一致，零件 A/B 上下排列。焊缝浮窗在零件 A/B 下方展示 `选择面` 和 `生成焊缝`，点击 `选择面` 后在视窗内逐个点选面，生成成功后在视窗显示多个焊缝段，并提示点选焊缝段后点击确定创建焊缝特征；生成焊缝前或未点选焊缝段时 `确定` 按钮置灰；错误提示与操作按钮同一行。
- 装配基准提取浮窗，保持独立 3D 视窗内操作面板，不并入手动焊缝/打磨浮窗；装配基准状态行与“设为装配基准”按钮只允许一层灰底容器。
- 工艺规划日志浮窗，使用结构树和任务列表同源的圆角玻璃浮层；展开态不贴底且下端对齐零件结构窗，收起态为视窗内圆角长条；标题只显示“打印日志”。
- Toast 在主页面使用全局居中 `top-14` 定位，并通过 `-translate-y-1/2` 再向上偏移自身高度的 1/2，层级高于样式 C 主导航，避让 3D 视窗顶部工具栏，只允许轻微压到工具栏上沿。
- 轴向单位输入行，当前 Component Lab 只展示样式 C 轻量选中态；旧橙色强调态进入 `/component-drafts`。
- 翻面压紧关节角组件，当前 Component Lab 展示样式 C 轻量选中态，并补充 URDF 滑台/旋转关节的可配置标签、单位、限位和步长示例；旧橙色强调态进入 `/component-drafts`。
- 工艺规划任务面板，仅覆盖样式 C 右侧任务列表、任务详情和工序参数变体；“当前工序对象”移入视窗工作区示例，任务条不重复显示作用零件名称，禁用/删除 icon 不使用包裹层 fill、stroke 或阴影。装配工序中的合并焊接需要展示扫描参数 / 焊接参数小标题和扫描点位 / 焊接点位分段，两侧各 6 组。七套完整 A/B 大卡片进入 `/component-drafts`，主 Lab 使用覆盖矩阵避免重复。
- 工艺规划一级卡片在“工艺规划卡片演进对照”中保留 V1 当前方案，并并列展示主页面采用的 V2 任务状态 Tag；外层预览仍固定使用主页面右栏真实 `420px` 宽度和完整 16 道工序，但 V2 卡片自身外宽固定为与二级任务条同源的 `391px`，仅在窄栏时使用 `max-w-full`。V2 保持左侧对齐，右侧列表间距使用任务条同源的 `4px / pr-1`；不能以 `w-full` 或额外右侧安全区把卡片填满右栏。卡片内边距为 `14px`，顶行和底行使用 `min-w-0` flex，使标题、Tag、对象 block 和工位均在 391px 内收缩而不撑开卡片。V2 顶行左侧为水平居中的“序号 + 工序名称”，序号为 `12px`、名称为 `14px`，右上任务 Tag 文字为 `11px`；中文任务名使用独立文字层和 `1px` 下内边距校正基线，Tag 内边距为左 `6px`、右 `8px`。V2 示例须可验证序号在 hover / keyboard focus 时替换为 checkbox、勾选后 checkbox 常驻，以及勾选不产生卡片 fill 或 stroke；该勾选只用于“导出全部” / “导出(n)”的工序导出范围。主页面导出按钮固定 `70px` 宽度，文案改变不移动工具栏结构。底行对象与工位为 `12px`，与顶行保持 `12px` 间距，组合对象按语义分组显示为多个浅灰 Tag block，使用 `4px` 圆角和较低对比度的 Zinc 500 文字，且不显示 `+`。不显示完成数，也不显示列表顶部的“装配体编号 / 16 道工序”摘要。状态色只落在 Tag 前圆点：灰色空心表示自动生成但未确认，橙色表示已确认后修改且待任务保存，绿色表示已确认且干净。V1 不得被覆盖删除，用于保留工序卡片的可视化演进过程。
- 视窗工作区组件，覆盖 3D 视窗壳、视窗内浮层、模型对象 pill 和特征回显。
- 虚拟仿真数模查看的“调整装配体位置”浮窗复用生产执行模型视图“属性参数”的半透明玻璃卡片、header 和折叠结构；在场景页签下方展示世界坐标 / 父系坐标及两行三列的 `X/Y/Z`、`RX/RY/RZ` 带单位输入，分别使用 `mm`、`°`。
- 虚拟仿真“机器人位姿”浮窗固定在视窗右上角，复用同一玻璃卡片与折叠结构；Robot1/Robot2 上下 stack 同时显示，每个机器人标题行使用独立 caret 渐进披露详情，并在收起态保留自己的世界/父系/物体 radio。展开态展示两行三列的末端位姿与 J1-J7 只读回显，其中 J7 使用 `mm`。Component Lab 必须在真实视窗宽度附近验证该浮窗不会遮挡右上角重置按钮或产生单位溢出。
- 视窗工作区组件必须展示共享 `ProcessPathPointMarkerModel` 的 P1-P6 点位标记预览。该组件是工艺规划打磨路径与虚拟仿真点位回显的共同样式来源：默认使用点球和 12px 半粗编号标签，并允许业务侧传入颜色、点球半径和标签偏移以处理重合点位。编号标签的 HTML 层级固定在视窗内 `0–10`，低于视窗控件和任何全局弹窗，不能透出程序生成、确认替换等弹窗遮罩。
- 工艺规划工具栏状态示例需注明主页面中间 6 个入口以 `320px` 左栏与 `420px` 右栏之间的 3D 有效视窗为居中基准；组件库中的压缩示例只表达控件状态，不以预览卡片宽度复刻整页三栏位置。
- 生产执行组件，覆盖生产执行工位卡片、轴测托盘卡片、产线轴测状态、模型视图结构树下的属性参数浮层、视觉监控真实点云、异常处理和底部设备状态；属性浮层按当前装配体的全部零件纵向堆叠，卡片标题使用结构树同源的半透明 fill 和关联 / 选中语义，可逐张折叠，字段区独立滚动，展示工艺规划同源的名称、材质、重量、厚度，且不能与顶部视图控制或底部打印日志重叠。生产执行整页预览提供「旧样式 / 新样式」切换，旧样式回归 24 条原工序，新样式在每个 WP 分组内使用原单行序号、状态灯、工序名称和零件名称样式展示 16 条聚合任务，不在条目中显示工位。轴测托盘卡片除占用状态外，增加执行、暂停和异常状态示例，与生产监控中当前任务映射一致。点云和异常处理示例继续复用主页正式组件。工位卡片方案切换仍持久化并同步控制生产执行工作台。新建工单示例使用完整编辑器缩略布局，覆盖草稿工单卡片 stack、项目结构树、上模型 / 下工序分区、局部「下一步」和弹窗级「确认新建」。
- 托盘管理组件状态，覆盖现场视图、理料区计划视图、AGV 调度状态和托盘清单卡片；「托盘管理 Header 规范」中的 AGV 标题栏展示历史任务和新建任务，AGV 行覆盖归档与历史恢复，理料区示例同步展示计划卡片序号行的执行 / 确认到达及待执行、执行中、已完成三种状态。
