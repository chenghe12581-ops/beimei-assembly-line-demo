# 工艺规划弹窗 Layout 说明

## 3D 默认视角

- 装配体首次进入或切换模型集合时，以模型工作面正面为主视方向；当前模型主平面为 `XY`，相机位于 `+Z` 一侧。
- 默认视角从模型上方向下约 `45°`，并保留约 `25°` 水平环绕角，使工件长轴在画面中呈左低右高的清晰斜向，同时表达整体轮廓、板厚和零件前后关系。
- 初始取景使用紧凑边界，留白系数为 `0.97`。模型应尽量占满左右任务面板之间的有效视窗，但不得被侧栏遮挡或贴边裁切；样式 C/D 结合非对称侧栏和斜向透视后的轮廓，默认相机向左补偿 `20px`，以完整工件的可见轮廓而非整张画布为居中基准。
- 默认视角只在模型集合首次出现或发生切换时应用。用户开始旋转、平移或缩放后，不得持续把相机拉回默认角度；视窗尺寸变化沿当前视线方向重新适配。

## 视窗浮层

- 样式 C 工艺规划顶部工具栏使用与下方有效视窗相同的 `320px / minmax(0, 1fr) / 420px` 三栏标尺；中间 6 个工具入口以 `320px` 左侧零件结构与 `420px` 右侧任务列表之间的 3D 视窗为居中基准，不以整页或左右工具区剩余空间为基准。
- 视窗浮层使用 `bg-ds-bg-glass-float`、`backdrop-blur-md`、浅色 border 和 `shadow-black/5`。
- 坐标转换、手动特征、装配基准、磁铁参数从左侧结构区右侧开始排列；路径点位从右侧任务列表左侧避让显示。
- 默认紧凑浮层宽度为 `280px`；坐标转换为 `320px`；路径点位根据图例开关使用 `360px / 500px`。
- header 使用 `px-3 py-2`，最小化和关闭使用 icon-only button，并提供 `title` 或 `aria-label`。
- footer 使用 `border-t + px-3 py-2`，错误提示和主要操作保持在同一行，避免额外错误块撑高浮窗。

## 装配基准提取

子板与父板是两个上下排列的 `label-input-mini` 行：

```txt
子板  [全宽单选下拉]
父板  [全宽单选下拉]
```

选择器触发器支持长名称换行，四个步骤按 `子板基准1 -> 父板基准1 -> 子板基准2 -> 父板基准2` 顺序纵向展示。当前步骤用品牌橙色，已完成步骤用成功色，未到步骤降低对比度。

## 全屏弹窗

- 工艺参数设置使用 `bg-black/45` 遮罩、`max-w-[1280px]` 内容区和固定 header/footer。
- 新增任务使用 `max-w-[520px]` 紧凑内容区，选择控件和确认动作由页面业务回调驱动。
- 全屏弹窗的滚动只发生在内容区，header 和 footer 保持稳定高度。

## Responsive 检查

- 组件库平铺视图中，长零件名不得让子板/父板字段横向挤压或导致页面溢出。
- 浮窗宽度和 toolbar button 高度使用稳定尺寸，避免菜单打开、名称换行或 hover 改变布局。
- 主页面和组件库共享同一套 panel token；组件库中的 demo 只表达视觉状态，不复制页面业务状态机。
