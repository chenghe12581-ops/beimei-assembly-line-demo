# Layout Guidelines

## General

- 操作型界面优先清晰、紧凑、可扫描。
- 不要使用过多嵌套卡片。
- 灰底区域用于表达同一组参数，不应层层套灰底。
- 重复条目可以用卡片，但不要卡片套卡片。
- 固定格式控件应有稳定尺寸，避免 hover、badge、长文本导致布局跳动。

## Component Lab

- 分栏视图：左侧组件目录，右侧展示选中组件和样式参数。
- 平铺视图：用于快速总览所有组件。
- 表格型规格展示应优先占满整行。
- 宽组件在平铺视图中可跨列。

## Process Panel

- 任务面板应模拟实际右侧任务列表宽度。
- 当前工作区固定侧栏标尺统一为：工艺规划 / 生产执行左栏 `320px`，工艺规划任务列表 / 生产执行单步调试右栏 `420px`；样式 C 项目管理复用同一组 `320px / minmax(0, 1fr) / 420px` 三栏标尺，不使用 `1fr 2fr 1fr` 让侧栏随视口膨胀。
- 组件库中每行展示两个任务面板变体通常比三个更合理。
- 点位 XYZ 输入框不得溢出容器。
- 关节参数可两列展示。
- 样式 C 工艺规划的零件结构和任务列表外壳使用带半透明白色 fill 的无圆角直角侧栏，与样式 C 项目管理一致；样式 D 保留圆角玻璃浮层版本。

## Tree

- 保持结构树层级线和缩进稳定。
- 独立特征父级可有数量 badge。
- 特征对象不使用彩色文字，不使用尾部类型 badge。

## 3D Viewport

- Component Lab 视图盒子固定使用品牌反馈方案；业务页面在文字清晰度和交互验收后再接入。
- 视图盒子的视觉锚点固定在 3D 视窗右下角，中文面标签按 `右 / 左 / 上 / 下 / 前 / 后` 表达；面、棱和角均可点击，切换视向时保留当前 OrbitControls 的观察中心和相机距离。
- 视图盒子常态使用白色 / Zinc 中性面，品牌橙只用于 hover 反馈，不使用金属高光、渐变或厚重阴影；中文面标签使用至少 `512 × 512` 的 CanvasTexture、中文系统字体和加粗字重，避免低分辨率纹理发虚。
- 3D 视窗顶部工具条只承载与模型点选/特征提取直接相关的工具。
- 生产执行工作台轴测工位、竖线、工位卡片和托盘地面区域标注必须遵守 `docs/frontend/production-workbench-isometric-geometry.md`：竖线下端锚定工位立方体上表面中心，线上端锚定卡片底边中点，HTML 卡片层必须复刻 SVG viewBox 的实际缩放；托盘区域文字必须从实际占地几何中心沿共享角平分线方向定位，不允许区域级手工偏移。
- 新建工单弹窗使用固定工单栏 + 局部任务工作区：工单栏约 `240px`，任务配置阶段的项目管理结构树约 `300px`；右侧工作区下层使用固定高度，刚好包住左侧「所属项目 / 当前工件 / 加工设置 / 加工数量」卡片和局部 footer，上方 3D / 托盘依据视图自适应剩余高度。「下一步」固定在下层局部 footer，弹窗 footer 只承载全局「取消 / 下发生产」，两层操作不得混用；footer 左侧显示 Checkbox 选中数量。
- 工单栏、项目树、工序列表和配盘明细各自管理滚动；工单栏标题与关键词筛选框固定，仅卡片 stack 滚动；工单卡片的状态、数量和删除入口不得因内容滚动或切换局部步骤而位移。
- 特征提取工具条使用单排入口：焊缝特征提取下拉、打磨特征提取下拉、装配特征提取；焊缝和打磨下拉各自提供 `自动提取` / `手动提取`。
- 焊缝与打磨的手动提取分别打开视窗内独立浮动面板，不在面板内使用 tab 切换。
- 装配特征提取沿用原有装配基准弹窗，不并入手动焊缝/打磨浮窗。
- 程序生成、定位焊接、焊接等工序或生产执行动作不放入 3D 视窗工具条。
- 工艺规划日志窗口保持圆角玻璃浮窗，不贴底显示，窗口下端与左侧零件结构窗下端对齐。
- 工艺规划日志标题只显示“打印日志”，不显示 icon、状态灯或“实时输出”。
- 日志窗口折叠时收成视窗内圆角长条；展开时仍为独立浮窗，不挤压主视窗布局。
