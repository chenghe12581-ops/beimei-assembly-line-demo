# Component Guidelines

## Component Categories

- Page Component：页面入口，只负责组合。
- Feature Component：业务功能组件，可以连接业务 hooks 和 demo state。
- Pure UI Component：纯展示组件，不包含业务请求或领域判断。
- Scene Component：Three.js 场景组件，负责 3D 渲染。
- Component Lab Demo：组件样式和状态展示，不应成为业务逻辑唯一实现。

## Rules

- Ant Design 优先用于表单、弹窗、下拉等复杂控件；使用时必须经过项目 `ConfigProvider` 或本地封装，主色对齐 `color.brand.primary`，不得暴露 Ant Design 默认蓝色。
- 样式 C 主导航的工艺规划与虚拟仿真任务菜单中，有任务时单击导航只展开或收起菜单，选择具体任务才切换工作区。任务标题统一为 `14px / 400`；虚拟仿真来源副标题为 `11px / 400`，格式固定为 `本地导入 · 文件名称` 或 `工艺规划 · 装配体名称`。
- 虚拟仿真主导航菜单按副本展示；本地文件副本内部的第 06 / 12 道装配任务只出现在左侧任务列表，不拆成两项主导航菜单。重复本地导入追加递增副本。
- 虚拟仿真左侧装配任务根节点的选中态使用 `border-orange-200 + bg-orange-50/75 + ring-orange-100`，名称与工位侧别使用品牌文字；未选根节点保持白色中性表面并收起焊接层级。删除 icon 使用无包裹层中性图标，hover 转危险红，确认弹窗明确说明内部焊接任务、焊缝段和程序一并删除。
- 虚拟仿真程序生成弹窗的焊接任务标题行右侧使用 `页码 + 左右 caret` 紧凑翻页器。多页首次进入时主按钮为中性置灰，访问最后一页后使用正常品牌主按钮，返回前页不撤销解锁；单页不渲染翻页器。
- 虚拟仿真程序树的根节点使用“加工程序1 / 加工程序2”命名，每个根节点内部均保留 Robot1 / Robot2 双机分支；不同根程序的轴值详情必须读取各自焊接任务数据。
- Tailwind 用于布局和轻量样式。
- 不要动态拼接 Tailwind class，例如 `bg-${color}`。
- 通用组件不能依赖业务 service。
- 页面组件不要直接写复杂业务逻辑；当前原型阶段允许局部 demo state，但新增业务规则必须写入 domain 文档。
- 复合组件应索引基础组件，而不是自己重新定义输入框、单位、异常边框。

## Token Component File Layout

新的 token 驱动基础组件放在 `src/components/ui/<component-name>/`，不要继续放进 `src/app/components/ui/`。

每个基础组件目录至少包含：

```txt
Button.tsx
button.types.ts
index.ts
```

其中 `Button.tsx` 只实现纯 UI 和 token 样式，`button.types.ts` 只放组件类型，`index.ts` 作为外部引用入口。页面和组件库应通过目录入口引用，例如：

```ts
import { Button } from '../components/ui/button';
```

## Unit Number Input

带单位输入框是基础组件，应统一：

- height
- padding
- font size
- unit position
- value/unit gap
- stroke thickness and color
- disabled state
- invalid state
- alignment

输入框内单位文字正常态统一使用 `text-slate-300`，异常态继续使用 `text-red-300`；工艺规划点位输入和生产执行异常处理输入应复用同一六轴字段内核，只在外层容器、折叠能力、stepper 是否显示上区分场景。

复合组件只决定使用哪个变体，例如：

- 普通参数：`md / left`
- Slider 右侧输入：`sm / right`
- 点位 XYZ：`sm / right`
- 轴向输入：`sm / left`
- 关节参数：`sm / right`

## Process Panel Variants

工艺参数里的参数项间距统一使用 token utility，不在业务 JSX 中散写 `mb-1`、`mt-3`、`space-y-3`：

- 参数项 `label-input gap` 使用 `ds-parameter-field`，当前为 `gap: ds-075` / `6px`；这里的 input 泛指输入框、选择器、分段选择、多选、Slider 和只读回显框。
- 任务列表展开区、样式 C 详情区等密集任务参数使用 `ds-label-input-compact`，当前为 `gap: ds-100` / `8px`，label 使用 `text-xs` 同级 token；不要在这些区域用 `mb-1`、`mb-2`、`mt-2` 人工制造 label 到 input 的距离。
- 新建工单弹窗的工序任务使用轻量隔离预览样式：点击右侧任一工序任务后，工序行进入浅橙底 + 浅橙细边框的选中态（如 `border-orange-200 bg-orange-50/70 text-orange-700 shadow-sm`），避免粗重描边抢占右侧面板视觉层级；同时把该工序的 `partObject` 解析为 `relatedPartIds` 传给 `ProductionModelScene`。关联零件保持 100% 不透明并叠加半透明黄色遮罩，非关联零件降为半透明，和生产执行任务树中点选工序后的模型高亮规则一致。再次点击当前工序可清除弹窗内预览高亮；切换装配体时清除已选工序，避免旧工序高亮串到新工件。弹窗左侧结构树零件行使用与装配体行一致的名称起点，不额外增加子级左 padding；点击零件行清除右侧工序任务选中并按单零件传入 `ProductionModelScene` 高亮，点击工序任务也必须清除结构树零件选中，避免两侧同时选中。
- 新建工单弹窗的「当前工件」摘要下方提供「加工设置」，其中侧面打磨快捷 toggle 只同步禁用 / 启用三道贴板侧面打磨，不影响普通打磨和表面打磨。工序任务预览标题行只承载全选 checkbox、已选数量和批量动作按钮；按钮文案始终显示下一步动作，当前可禁用时显示「禁用」，当前可启用时显示「启用」。每条工序行左侧常显 checkbox，右侧提供单条禁用 / 解除禁用入口。工序名称使用 `text-xs`，零件对象使用 `text-[11px]` 并复用生产任务列表的组合零件括号格式。禁用行使用 `border-zinc-200 bg-zinc-100/80 opacity-75 grayscale shadow-none`，显示「已禁用」badge，中央预览点击区不响应模型高亮；checkbox 和单条禁用入口仍保持可操作，用于批量或单条解除禁用。
- 新建工单弹窗两步共享同一右侧结构：项目管理结构树、上部视窗和下部两列设置 / 预览区域不因步骤切换而改变尺寸或位置；下部区域固定到刚好包住左侧「所属项目 / 当前工件 / 加工设置 / 加工数量」卡片的高度，上部视窗自适应剩余高度。第二步只把 3D 工件视窗替换为启用 `fitOverview` 的 `TrayReferenceStrip` 区位图，把原「工序任务预览」容器替换为 `TrayAllocationCard` 网格。`fitOverview` 只用于弹窗内无计划卡片的总览，使完整区位图适配现有视窗宽度，不改变托盘管理页面默认最小宽度。加工数量输入和配盘容量提示固定归入「加工设置」卡片；下层外壳不滚动，工序列表超出时只在右侧列表内部滚动，托盘预览在固定下层高度内完整露出。局部 footer 按顺序放置「返回任务设置」与品牌主按钮「确认工单」，确认后当前草稿状态显示「配置完成」，编辑数量、工件或禁用任务会恢复为待确认。工单卡片 Checkbox 只在配置完成且数量有效时可用；卡片本身仍复用现有编辑选中态，选中卡片右侧继续展示对应工序选择和禁用内容。弹窗 footer 左侧显示 Checkbox 选中数量，右侧「下发生产」仅在有选中项时可用。
- 新建工单弹窗的工单栏标题行在品牌色「新建工单」按钮左侧放置 `sm` 全选 Checkbox；它只汇总可下发工单，并使用 checked / indeterminate / disabled 三态表达全部选中、部分选中和暂无可选工单。
- 新建工单弹窗的工单栏在标题行下方使用项目管理结构树同款 `32px` 关键词搜索输入；左栏 surface 使用更高白度的 `bg-white/80`，右边界使用 `border-zinc-200/70`，与右侧项目树和任务工作区形成明确层级。搜索行固定，只有卡片列表纵向滚动。
- 生产执行页左侧生产任务列表中的工序任务选中态使用主高亮面：`bg-orange-50 text-orange-700 ring-1 ring-inset ring-orange-100`；模型视图结构树中的对应零件条目复用组件库 `ProcessSequenceBento` 的次高亮详情态：`bg-transparent text-orange-700 ring-1 ring-inset ring-orange-200/90`，不使用浅橙底主选中面。再次点击当前工序任务应 deselect，并清除模型视图中的关联零件高亮。
- 生产执行的生产工作台、模型视图、视觉监控与工艺规划 3D 视窗统一使用 `color.bg.viewport / #E4E4E4`。视觉监控不使用深色沉浸底，改用同源灰底 + 浅灰网格；默认使用虚线空状态表达「视觉监控待机，等待 WP-06 异常」，不创建 Three.js 点云画布。仅当 `WP-06` 处于异常状态时加载点云和视觉状态栏；点云使用真实 XYZ 数据生成 `THREE.Points`，自动居中并按最大轴跨度归一化；高度使用 slate 灰阶并在最高区域轻量混入品牌橙，点大小保持紧凑，不使用发光粒子或彩虹渐变。六路相机通过点云根节点预设旋转表达，保留 OrbitControls 的旋转与缩放，禁用平移。左下角视觉状态栏复用 `VisionFeedBar` 的白色半透明玻璃层，状态灯固定为异常红、告警黄、正常绿、离线灰；异常色由 `abnormalVisionFeedId` 覆盖，不能再按数组序号生成，按钮选中面与状态灯语义相互独立。
- 异常处理使用 `bg-ds-bg-glass-modal` 玻璃浮层壳，但只允许挂载在视觉监控视窗内部，不使用全局遮罩或居中弹窗。浮窗宽度约 420px，标题和底部操作固定，中间内容单列滚动。标题固定为「异常处理」且不显示图标，也不显示灰色上下文。结果点和拍照位置使用弹窗专用的扁平六轴输入组，不复用带卡片与折叠 caret 的 `ProcessPosePointInfoRow`，两组输入直接位于内容区并以统一的浅灰色分隔线区分；拍照位置可编辑输入框使用扁平 `shadow-none`，不叠加浮起阴影。结果组不显示「视觉识别结果」层级，先展示当前异常工序标题，例如 `当前任务：WP-01 · 装配0162-01-010101-02 + 0162-01-010101`，不得回显泛化的任务工件名称；当前任务行与异常原因块之间使用 `gap-ds-150 / 12px`。Demo 异常原因统一显示「点云识别失败」，不追加红框第三行辅助说明；其下方显示结果字段。生产 Demo 在搬运机器人 1/2 Tab 下双击 WP-01 左侧第 4 行「抓取」时，右侧切换为抓取六轴和工件代号面板。拍照组只保留一行标题栏，「重置」紧跟「拍照位置」标题右侧，绝对位置 / 相对位置分段控件与带刷新图标的「重新扫描」居右排列，且「重新扫描」位于最右侧；拍照位置标题行到六轴输入使用 `gap-ds-150 / 12px`，绝对 / 相对分段控件与「重新扫描」之间使用 `gap-ds-150 / 12px`，六轴两行之间使用 `gap-ds-100 / 8px`。相对位置模式的 XYZ 标签显示 `ΔX / ΔY / ΔZ`，RXYZ 保持姿态轴标签。底部左侧仅在重新扫描进行中显示「正在使用当前拍照位置重新扫描」，其它状态不显示提示文字；次按钮「跳过」和品牌主按钮「确定」始终右对齐。视觉视窗只保留点云、视觉状态栏和异常处理浮窗，不叠加点云信息卡或识别异常摘要；全局异常 Alert 的「查看详情」和选中视觉状态栏中红色异常相机都是打开异常处理的入口。
- 生产执行页右侧任务状态监控展开后的工序条目同步左侧工序禁用状态：禁用行使用 `border-zinc-200 bg-zinc-100/80 opacity-75 grayscale shadow-none`，序号、名称和零件对象降低对比度，状态 badge 显示「已禁用」，并隐藏异常视觉入口。
- 生产执行工位卡片和右侧单步调试工位按钮的中性空闲态按语义拆分：工位标题空闲使用 `text-ds-text-control-muted`（Zinc 500），有任务时使用 `text-ds-text-control`（Zinc 700）；「暂无任务」和「暂无」使用 `text-ds-text-disabled`（Zinc 400），空闲 badge 使用 `bg-slate-100` + `text-slate-400`，badge 内状态圆点使用 `bg-slate-300`。纯空闲工位卡片使用约 68% 白色透明表面、`backdrop-blur-md`、弱化边线与无阴影，并折叠为标题 + 状态行，隐藏「加工零件：暂无」占位行；托盘纯空闲态使用约 58% 白色透明表面 + `backdrop-blur-md`，空托回收态保留约 68% 表面以表达物流状态，二者均不使用整张卡片 opacity。已预约、已占用、暂停和异常继续使用各自物流或执行状态色。
- 生产执行新版工件工序条目与工艺规划工序电池共享文字基线：用户可见编号使用 `工件-01` 格式和 `text-ds-text-control`，不得直接显示内部 `WP-01`；工序名称使用 `text-ds-text-control`，零件对象使用专用 `text-ds-text-part-object`（Slate 500 的 80% 透明度，降低蓝感），工序名称与零件对象之间使用 `12px` 间距；条目高度使用 `32px` 并保留 `4px` 上下内间距，避免左侧任务栏过度拥挤。禁用项使用 `text-ds-text-disabled`；条目序号复用 `.ds-process-index`、`12px / 400` 和 `text-slate-400`，作为跨页面工序标号的固定 Slate 例外。空闲状态圆点使用 Slate，运行中 / 暂停 / 异常圆点继续使用绿色 / 琥珀色 / 红色。
- 生产执行页左侧生产任务列表的“清除当前列表”按钮必须先打开居中小型确认弹窗；弹窗使用 `bg-ds-bg-glass-modal + backdrop-blur-md + shadow-black/5` 玻璃外壳、`bg-black/45` 遮罩和橙色 warning icon，确认文案需说明仅移出当前筛选后可见任务，不删除工艺规划数据。
- 生产执行页左侧生产任务和右侧任务状态监控的缺省态复用工艺规划任务列表：虚线框占满面板内容区，使用 `SlidersHorizontal size-10` + `text-sm font-light` 单行文案，内部内容 `-translate-y-6`，默认文案为「暂无任务」；筛选无结果可替换文案但保持同一结构。
- 生产任务列表的工单概要名称使用 `text-sm` / 14px 等宽字体，并与新建工单弹窗一致展示自动生成的工单号；工序名称使用 `text-xs` / 12px。工单概要的状态使用 `text-xs` / 12px；WP 编号、WP 进度、工序序号和零件编号继续使用 `text-[11px]`。只有受限宽度的状态 badge 保留 `text-[9px]`，不得再引入 10px 标注档。
- 生产执行左栏将任务概要升级为工单概要，但不增加外层工单卡片：概要左侧只使用折叠 caret 和自动生成的工单号，不显示排单序号、装配体图号、件数或独立拖动抓手；已下发工单状态保持右对齐，不显示理料状态下拉。折叠态只显示概要首行，展开态在第二行保留原总体进度。工单展开后直接渲染现有 WP 容器，禁止修改 WP 容器与内部工序条目的 class、尺寸、间距、状态色和交互，也禁止因新增工单层级增加内容缩进。
- 工单概要的状态区使用固定宽度；未执行已下发工单的删除 icon 位于状态文字左侧，默认 `opacity-0` 且不可点击，仅在工单概要 hover 或删除按钮 focus-visible 时显示。删除 icon 的显隐不得推动状态文字或改变已执行工单状态的右对齐位置。
- 工单概要条目不绘制外壳 stroke；生产任务栏中的工单 stack 使用 `8px` 上内边距，与左右 `px-2 / 8px` 保持一致。该间距只属于工单 stack，不传递到展开后的 WP 容器或工序条目。
- 生产任务栏与新建任务弹窗的工序任务预览共用 `ProductionProcessTitle`，该方法通过 `.ds-production-process-title` 消费 `typography.productionProcessTask`（12px / 16px / 500）；组合零件对象统一使用 `formatCombinedPartObject()` 的共同前缀括号格式。
- 任务列表详情中，可复用三类参数语义间距：`ds-parameter-group` 表示同一参数组内标题/控件行距，当前 12px；`ds-parameter-group-stack` 表示相邻同类参数组之间的间距，当前 16px；`ds-parameter-category-stack` 表示参数类别之间的间距，当前 36px。抓取工艺中抓具类型只读回显行与左/中/右磁铁行属于同类参数组栈，使用 16px 组间距；样式 C 抓具类型回显行需使用与磁铁参数组相同的横向内容 inset，保证抓具左侧与左磁铁左侧对齐；左/中/右磁铁各自为参数组，磁铁名称与启用开关作为父行，下面的 Z 值 / 磁力档位附属输入行在父行内容起点基础上左右各增加 2px inset（`px-0.5`），用于表达层级但不改变两列间距；覆盖率/安全系数/偏心距结果区自身也使用 `ds-parameter-group`，磁铁参数组与结果区之间使用类别间距。定位焊扫描的扫描距离、扫描偏移、扫描姿态三组参数使用 `ds-parameter-group-stack`；其中扫描偏移和扫描姿态的三个输入框是各自标题的附属输入组，也使用左右各 2px 的附属 inset。
- 3D 视窗内的紧凑特征提取浮窗使用 `label-input-mini gap`，对应 `.ds-label-input-mini`，当前为 `gap: ds-050` / `4px`；适用于焊缝、打磨、装配特征提取中的小型 label + `ObjectSingleSelect` 组合。
- `title-content gap`：参数卡片内标题到下面主要控件的专用间距使用 `ds-parameter-card-title-stack`，当前为 `gap = ds-200 / 16px`；该规则不替代 `label-input gap`。
- 相邻参数行之间使用 `ds-parameter-stack`，当前为 `gap: ds-150`。
- 任务列表各工序的工艺参数详情内容起始顶部 padding 使用 `.ds-task-parameter-detail-top`，当前为 `ds-100` / 8px；该类只表达上 padding，不表达左右 padding，也不要包住或改写路径点位/结果点位的现有格式。工艺参数设置弹窗继续使用参数卡片自己的 16px inset 体系。
- 样式 C 任务详情下半区是常驻详情面板，外壳 stroke 使用浅灰实线（当前为 `border-ds-border-process-planning-structure`，与详情 tab 下边沿和生产任务列表标题分隔线同源），不要使用虚线；虚线只保留给真正的空状态或待生成占位。

样式 C 工艺参数设置弹窗中，抓取页签的 `桁架抓具` / `机器人抓具`、工作台页签的工作台类型、打磨页签的 `inhand` / `tohand` 切换，均使用与样式 C 任务详情 `工艺参数` / `路径点位` 同源的轻量下划线 tab。该 tab 位于右侧内容区顶部，用于切换对应参数内容；不要使用胶囊分段、浅底选中或卡片化选择器。

抓取任务的阈值校验区只回显计算结果，不展示阈值设定 label 或输入框。三项指标统一为一行结构：`电磁铁覆盖率 / 安全系数 / 偏心距` + 计算结果 + 阈值 badge。满足时 badge 显示 `满足阈值`；不满足时 badge 显示异常方向和阈值数值，例如 `低于阈值 50%`、`超出阈值 0.80`、`超出阈值 200mm`。

交互状态的颜色语义：

- 选中、当前项、勾选、启用等主交互状态使用品牌橙或品牌浅底。
- 蓝色仅保留给信息状态、基准特征等明确业务语义，不作为默认控件主题色。
- 点位、轴向输入行和 J 轴行的旧选中表面 `border-orange-200 bg-white shadow-selected ring-1 ring-inset ring-orange-200` 只用于样式 A/B 过程稿，并迁入 `/component-drafts`；普通树节点、导航和按钮选中态继续使用各自组件 token。样式 C 紧凑详情中的点位、轴向输入行和 J 轴行使用 subtle selected 变体：浅灰背景 + 深灰 stroke，不使用白底、橙色发光或 ring。
- 结构树拖拽排序的目标位置线必须使用 `color.brand.primary`。页面代码通过 `getStructureTreeDropIndicatorClassName()` 返回主题色 class，不要在 JSX 中散写 `bg-blue-*` 或其他状态色。
- 工艺规划结构树中，装配体根节点与“焊接特征 / 打磨特征 / 装配特征”父级使用统一灰底 header、11px 字号和数量 badge，header 自身不显示橙色选中态；特征父级名称前放类型 icon。特征对象行与零件对象行使用统一字号，不再显示类型 icon，行首 checkbox 默认隐藏，仅在 hover 或已勾选时显示，用于勾选删除。
- 特征独立显示模式下，独立分组里的特征对象行不显示树状竖线/横线，只保留同宽占位以维持既定对齐；非独立显示在零件树层级内的特征对象行继续保留树状连接线。
- 特征非独立显示时，同一零件下直接挂载的特征对象按焊接特征、打磨特征、装配特征顺序展示；该顺序只调整 feature children，不改变零件条目的 padding 或 gap。
- 装配体根节点、特征分组 header、项目管理项目条目中，类型/项目 icon 与标题名称之间使用 `space.treeIconTitleGap`，当前解析为 `8px`；项目管理中无类型 icon 的装配体/零件行，checkbox 与标题名称之间也使用同一间距语义；其余列间距仍可使用紧凑 `gap-1`。
- C/D 样式工艺规划结构树中，工作面条目的 caret 默认隐藏，仅在 hover 时显示；零件行保留父子层级但使用压缩左缩进：`01` 主零件为 `8px`，工作面为 `36px`，`02/03` 为 `36px`，`04` 为 `48px`。项目管理结构树不使用这套压缩缩进。
- 样式 C immersive 左侧零件结构的滚动内容底部不要保留大块安全 padding；面板本身已固定在视窗内，底部留白使用 `pb-0`，投影从面板底边直接向上压内容，不叠加白色遮挡条。右侧任务列表内容区需要保留与顶部一致的外部留白，使用 `py-ds-150`，避免详情灰底面板贴到底部边框。

- 工艺规划 3D 视窗顶部特征提取入口中，焊缝提取和打磨提取均使用下拉按钮，菜单只包含 `自动提取` / `手动提取`；不要再新增独立的“自动提取特征”按钮。
- 3D 视窗零件模型颜色由源码中的 `modelColors` 数组按模型收集顺序循环分配；当前顺序通常为 `01 -> 02 -> 03 -> 04`，色值为蓝 `#1e40af`、绿 `#34d399`、紫 `#7c3aed`、红 `#f87171`。03 零件不要使用黄/橙邻近色，避免与选中高亮和黄色零件过近。

## 样式 C（immersive）结构树间距规范

> 样式 A/B 为早期过程样式，仅作留档；样式 C 是当前继续发展的主版本。以下规则仅描述样式 C 下左侧结构树的间距与 icon-title gap。

### 通用 icon-title gap

- 需要 8px icon-title gap 的条目使用 `ds-tree-icon-title-gap`。
- 该 class 通过容器 `gap-1`（4px）+ 标题 `margin-left: 4px` 实现 8px 视觉间距。
- 当前应用位置：
  - 项目管理：项目根条目、0162 分组标题、0162 项目条目、装配体条目、有 modelPath 的零件条目。
  - 工艺规划：装配体根节点、独立显示特征分组 header。
- 未应用位置保持 4px（仅容器 `gap-1`）：工艺规划普通零件/工作面行、非独立显示特征分组 header、特征节点。

### 项目管理（样式 C，全部项目页）

| 条目 | 左 padding |
|---|---|
| 普通项目根（`proj-`） | 12px |
| 0162 分组标题 | 12px |
| 0162 项目条目 | 18px |
| 装配体（直接子节点，level=0） | 18px |
| 零件（直接子节点，level=0） | 3px |
| 子零件（level=1） | 17px |
| 更深零件（level=n） | 14n + 3 px |

实现常量：

- `projectManagementGroupPaddingLeft = 12px`
- `projectManagementAssemblyPaddingBump = 6px`
- `projectManagementPartPaddingBump = -1px`

### 工艺规划（样式 C，进入项目后）

样式 C 下对象节点启用 `compactObjectNode` 压缩缩进：

| 条目 | 左 padding |
|---|---|
| 装配体根节点 | 8px |
| 主零件（level=1，compact） | 8px |
| 工作面分组 | 36px |
| 子零件 level=2/3（compact） | 36px |
| 更深零件 level≥4（compact） | 48px |
| 非独立显示特征分组 header（level=3） | 62px |
| 非独立显示特征节点（level=4） | 64px |
| 独立显示特征分组 header | 8px |
| 独立显示特征条目 | 20px |

实现规则：

- compact 对象节点（样式 C 下非根、非特征、非工作面、非特征分组）：`level≤1 → 8px；level≥4 → 48px；其余 → 36px`
- 工作面分组固定 36px
- 非 compact 节点（特征分组/特征节点）：`level × 18 + 8 px`
- 样式 C 非独立显示的特征节点在上述非 compact 结果基础上减少 16px；该修正只允许命中特征节点，不改变独立显示特征条目，也不改变任何零件条目的 padding 或 gap
- 样式 C 非独立显示中，父零件下第一条 grind 特征的竖向连接线使用短线（`top: 0; height: 16px`），避免在主零件紧凑缩进下压到父零件标题；该规则只调整连接线长度，不改变行 padding 或 gap
- 样式 C 特征对象行（独立显示和非独立显示）hover 使用零件条目同源的中性灰 `hover:bg-zinc-100`，不要使用偏蓝的 slate hover
- 独立显示特征分组 header 8px，特征条目 20px（硬编码）

对象/特征选择下拉：

- 特征提取里的零件 A/B 选择使用 `ObjectSingleSelect` 单选对象下拉，不使用原生 `<select>`；装配基准提取中 A/B 的展示名为子板/父板，两个选择器上下排列且各自占满浮窗宽度，并使用“装配基准 1 / 装配基准 2”纵向步骤引导，不再用 A/B 平铺四行，分组标题前不显示额外数字 badge。
- 任务配置里的工件模型、焊缝特征、打磨特征、装配基准特征选择使用 `ObjectMultiSelect` 多选对象下拉。
- 坐标转换这类对象批量操作可以在 `ObjectMultiSelect` 下拉菜单顶部启用“全选”入口；普通任务配置不默认显示全选，避免误选。
- `ProcessSingleSelect` / `ObjectSingleSelect` 触发框全局使用白底、轻边框和无阴影；默认 `elevation` 为 `none`，只有明确的历史特殊场景才允许显式开启阴影。展开后的下拉菜单保留浮层阴影与品牌橙选中态。`ObjectMultiSelect` 沿用自身触发器样式；异常态使用 red stroke / red subtle background，不暴露浏览器或 Ant Design 默认蓝色。

弹窗一致性：

- 图纸管理、工艺参数设置等密集玻璃弹窗使用 `rounded-lg` / `radius.lg` 外壳，避免在样式 C 中出现过大的 12px/16px shell 圆角。
- 图纸管理、工艺参数设置等全局弹窗层级必须高于样式 C 主导航；工艺参数设置主弹窗当前使用 `z-[110]`，其弃改确认弹窗使用 `z-[130]`。
- 样式 C 的工艺参数设置弹窗保留内层参数卡片 Wrapping；右侧内容滚动区使用更接近白色的底色（当前 `bg-white/50`），避免卡片间负形因灰色/磨砂底透出过强而打断阅读动线。
- 样式 C 工艺参数设置弹窗左侧页签选项使用结构树对象条目同款 `rounded-md` / `radius.md`，不要使用 `rounded-lg`、`rounded-xl` 这类更大的圆角。
- 样式 C 工艺参数设置弹窗 footer 不使用顶部白色 stroke 或 inset shadow；使用任务列表下端收起条同款向上投影 `shadow-ds-footer-up`。
- 弹窗 header 使用 `bg-ds-bg-glass-modal` 与中性文字色，不在标题区放业务 icon；状态和类型语义放到列表项、内容区或按钮上表达。
- 就地确认 popover 覆盖在密集任务卡片上时优先保证文字可读性，并使用磨砂玻璃质感：`ds-popover-glass-surface`；小尖角使用 `ds-popover-glass-arrow`，与浮层同底色和 stroke。
- Ant Design `Tooltip` 在工艺规划、生产执行和组件库中统一使用 `typography.tooltip`（12px / 16px / 300）；不要在 Tooltip 内容上覆盖 `text-[11px]` 或 `font-normal`。
- 下拉菜单、对象选择菜单、导航菜单属于 menu/dropdown surface，和确认 popover 共用高可读白底 surface；3D 视窗临时浮层继续使用 `ds-glass-float-surface`。
- 主页面 Toast 使用 `fixed top-14 left-1/2 z-[2000]` 居中显示，层级必须高于全屏弹窗、确认弹窗、下拉 portal 和就地 popover。

生产执行与工艺规划的复用规则：
