# Virtual Simulation Domain

## Workspace And Assembly Tasks

- 主导航中的仿真项是仿真副本；一个副本可以包含一条或多条装配任务。工艺规划发送副本当前为单任务，本地文件 Demo 固定包含第 06 道和第 12 道两条任务。
- 第 06 道装配任务读取 `simulationSide=front`，第 12 道读取 `simulationSide=back`。任务选择只读取显式侧别，不根据名称推断。
- 程序、机器人分配、支撑/压紧轴值、装配体位姿、URDF 状态、焊缝选择和播放进度均以装配任务 ID 为状态边界；同一副本内切换任务不得串用状态。
- 删除装配任务等价于删除该任务聚合根：内部焊接任务、焊缝段、加工程序及任务级派生状态同时删除。删除副本内最后一条任务时，该副本不再保留。
- 本地导入是 append 操作。重复导入同名文件创建递增副本，不替换当前副本。

## Weld Tasks And Processing Programs

- 一个装配任务包含一组或多组焊接任务；每组焊接任务独立拥有焊缝段、机器人分配、支撑/压紧机构轴值和同序号加工程序。
- 当前本地 Demo 的第 06 道装配任务固定包含焊接任务1与焊接任务2，第 12 道固定包含单组焊接任务。焊接任务2复用焊接任务1的数据结构，但必须使用独立 ID 和确定性偏移后的轴值。
- 多焊接任务的程序生成弹窗以焊接任务为分页边界。只有首次访问过最后一页后才允许生成；解锁状态在本次弹窗会话内保持，返回前页不能重新置灰。单焊接任务无需分页，也无需额外解锁。
- 生成操作一次替换当前装配任务内全部焊接任务对应的加工程序；程序1与程序2分别读取自身焊接任务的数据，不得共享或覆盖轴值与机器人分配。

## Unified Station Scene

- 仿真视窗不再维护独立“数模查看”场景；任务只保留显式的 `front / back` 工位侧别，当前任务不适用的一侧不可选择。
- 工位设施、滑台和双机械臂来自项目内的 `beimeiji_weld_0623.urdf` 与本地 STL；工件使用应用侧标定位姿落台，直到 URDF 提供正式装夹基准帧。
- 左侧焊接任务选择决定是否使用顶视焊缝相机：任务级选择显示全部焊缝段，单段选择只过滤几何回显，不再次改变相机尺度。
- 右侧任意程序节点选择都会清除左侧焊接选择，并发出一次新的工位全景相机请求；即使已经处于工位视图，也必须重新把双机械臂、工作台和工件完整纳入构图。
- 焊接任务或焊缝段处于选择状态时播放器不可启动；选择程序节点恢复工位全景后再按既有播放范围规则执行。

## Assembly Visual Pose

- 仿真副本可维护一份仅用于视窗回显的装配体位姿：`X / Y / Z` 平移单位为 `mm`，`RX / RY / RZ` 旋转单位为 `°`。
- 位姿属于仿真副本内的单个装配任务，不回写工艺规划来源数据，也不改变加工程序、焊接点位或工位配置。
- 视窗以装配体包围盒中心为旋转中心；装配体的焊缝、扫描点和焊接点必须与装配体使用同一变换，工位设施和地面网格不随之移动。
- 坐标系可在世界坐标和父系坐标间切换。当前 Demo 的装配体父级即视窗根节点，两者共享零点；后续接入真实装配层级时，保持同一字段语义并由场景适配层负责坐标转换。

## Program And Weld Segment Association

- 扫描或焊接程序节点通过 `weldSegmentId` 关联一个焊缝段；选中 Robot 或根程序时，通过其子程序递归汇总关联焊缝段。
- 扫描/焊接程序的点位选择以当前子程序为边界，只允许一个 `instructionId` 处于选中态；点位携带子程序的 `robotName`，用于当前机器人关联回显。选择程序节点、焊接任务或焊缝段时清除点位选中态。
- 右侧程序节点选中后，左侧任务列表显示关联态；左侧直接选中焊接任务或焊缝段时，直接选中态覆盖关联态。

## Robot Pose Readout

- 机器人位姿回显依赖当前装配任务已生成的加工程序；未生成程序时不渲染位姿浮窗，切换到另一条未生成程序的装配任务时也必须隐藏。
- 机器人位姿浮窗读取仿真副本当前的 URDF 关节状态，不维护第二套可编辑机器人轴值；Robot1 与 Robot2 上下同时展示，并分别维护自己的坐标系显示选择。
- `Robot1` 映射左机械臂，`Robot2` 映射右机械臂；两者均以各自 `tool0` 作为末端位姿回显对象。浮窗中的 `J1-J6` 映射机械臂六个旋转关节，`J7` 映射对应 URDF 滑台直线轴；支撑/压紧机构外部轴仍属于独立业务域，不得混入机器人回显状态。
- 世界坐标以 URDF `base_link` 为参考，父系坐标以对应机械臂 `manipulator_base_link` 为参考，物体坐标以应用侧标定的工件装夹坐标为参考。
- 末端位姿通过 URDF 关节树正向运动学计算，只用于 Demo 回显；不执行逆运动学、碰撞检测，也不回写程序指令或导出数据。

## Playback Pose Mock

- 播放姿态使用独立的视图派生值：以仿真副本当前的 URDF 关节输入为基准，根据选中的程序节点和 `0-100%` 播放进度生成临时关节偏移。
- 扫描和焊接使用不同的确定性动作曲线；选中扫描/焊接子程序时只驱动其绑定机器人，选中 Robot 父级时按其子程序顺序驱动单机，选中根程序时 Robot1 与 Robot2 按同一进度并行驱动。未参与当前范围的机器人保持基准姿态。
- 每个动作曲线在进度起点和终点回到基准姿态；暂停保持当前派生姿态，快进/快退直接映射到对应姿态，完成或重置不覆盖手动输入。
- 关节偏移和滑台偏移始终经过 URDF 显示限位裁剪。该逻辑仅用于视窗和位姿浮窗的视觉演示，不代表真实轨迹、速度、可达性、碰撞或控制器反馈。

## URDF Joint State Boundary

- 每个装配任务独立保存 14 个可调 URDF 轴：Robot1 左滑台与左机械臂 `J1-J6`、Robot2 右滑台与右机械臂 `J1-J6`。
- 可调范围来自 URDF limit。滑台以 `mm` 展示，旋转关节以 `°` 展示；旋转范围按 `0.1°` 步长向限位内部对齐，保证中性 `0°` 是合法步进值，写入场景前仍按原始 URDF limit 截断。
- 支撑机构 `J1-J8`、压紧机构 `J1-J6`、程序点位 `J1-J6` 与 `E1` 属于既有业务/程序数据。它们与 URDF 姿态状态同名但不同域，禁止互相覆盖、推导或导出替换。
- 调整 URDF 姿态只驱动对应机器人场景链和位姿浮窗；程序重新生成继续沿用当前支撑/压紧机构数值，不读取 URDF 姿态值。
