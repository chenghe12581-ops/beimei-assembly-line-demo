# Process Sequence Domain

## Concepts

- 工序：产线执行的一个可配置步骤。
- 样式 C 固定工序：由装配体解析得到的生产路线节点，顺序、对象和工位映射固定存在，不由用户新增、删除或排序。
- 工艺规划任务：归属于固定工序的可配置动作。样式 C 包含抓取、放置、打磨、装配、翻面压紧和合并焊接；样式 A / B / D 继续保留独立的定位焊扫描和定位焊任务。
- 工件：结构树中的零件对象。
- 特征：由特征提取得到的打磨线、焊缝或装配基准。
- 点位信息：路径或位置的 XYZ 回显/编辑数据。
- 关节参数：翻面压紧中 J1-J8 的关节/位移参数。
- 脏状态：用户修改点位或关节后尚未点击更新应用。
- 任务确认：用户通过任务条尾部“保存”确认该任务当前配置；任务确认与整个工艺规划项目是否已保存是两层独立状态。

## Process Types

- 抓取：选择一个或多个工件，生成抓取位置。
- 放置：选择一个或多个工件，生成支撑位置。
- 打磨：选择打磨特征，生成打磨路径。
- 装配定位：选择装配基准特征，生成定位路径。
- 翻面压紧：选择工件，生成压紧位置；结果点位参数使用 J1-J8。
- 定位焊扫描：选择焊缝特征，生成定位焊扫描路径。
- 定位焊：选择焊缝特征，生成定点焊接路径。
- 合并焊接：仅用于样式 C，在一个任务内共用焊缝特征，并独立维护扫描与焊接两套参数、结果点和安全点。

### Style C Fixed Task Slots

样式 C 的 16 道固定工序进入工艺规划时只具备解析后的工序和固定任务定义，不创建实际任务；首次一键生成成功后才写入完整 27 项任务：

- 01：抓取、放置
- 02：正面打磨、反面打磨
- 03：抓取、放置
- 04：抓取
- 05：打磨
- 06：装配、翻面压紧、焊接
- 07：翻面压紧
- 08：抓取、放置
- 09：抓取
- 10：打磨
- 11：打磨
- 12：装配、翻面压紧、焊接
- 13：抓取
- 14：打磨
- 15：装配、翻面压紧、焊接
- 16：抓取、放置

每个任务槽位具有稳定 ID、任务类型、显示名称和固定工件对象。工件对象继承所属固定工序，不允许在任务内改选；打磨线、焊缝和装配基准等特征仍按任务类型配置。删除任务后该槽位可由新增任务流程恢复，但浏览或返回上一级不得自动恢复、确认或改变任务状态。

### Task Generation, Validation and Dirty State

- 装配体进入样式 C 工艺规划后，16道固定工序已经解析完成，但不自动创建任务；工序卡片右上角不显示任务 Tag，进入工序显示“暂无任务”。
- 首次点击“一键生成”且全部任务成功生成后，才一次性创建27项固定任务及其默认参数、结果点位和路径点位；对应 Tag 使用绿色实心圆点。
- 已生成任务发生参数、点位、路径、关节、磁铁、装配或焊接修改后为“待任务保存”；对应 Tag 使用品牌橙色实心圆点，任务名称右侧显示品牌橙色 `*`，任务条尾部显示“保存”。
- 参数校验失败使用红色三角感叹号，不使用橙色修改灯。任务同时存在未保存修改与校验错误时，红色错误优先显示，橙色 `*` 保留；修正后恢复橙色待保存，保存按钮在校验失败时不可用。
- 任务条只在存在未保存修改时显示“保存”。点击任务级“保存”后清除该任务的参数、点位、磁铁、装配和焊接脏状态；名称右侧 `*` 与“保存”消失，Tag 变为绿色。
- 任务级“保存”不得清除工艺规划项目的未保存状态。顶部项目级“保存”只保存整个工艺规划，不批量保存或清除橙色任务状态。
- 仅查看任务、切换详情 Tab、进入或退出隔离模式、返回工序列表都不得改变任务状态；黄色修改在切换任务、工序和返回项目管理后保留。
- 任务生成完成后，入口文案切换为“重新生成”。重新生成会替换全部现有任务及其参数、点位、排序、禁用状态和手动新增任务；确认后才执行，生成不完整时保留替换前的任务列表。

## Rules

- 样式 C 使用“固定工序 -> 工艺规划任务”两级结构；样式 A / B / D 保留原平铺任务结构。
- 样式 C 的固定工序在装配体解析后立即存在，但不自动生成任务；一键生成成功后才创建完整任务与默认配置。在首次生成成功前，新增、筛选、批量操作、禁用和删除等任务级入口不可用。
- 样式 C 一级工序卡片的多选集合只表达批量导出范围，不改变工序导航、隔离、任务生成、任务配置或任务条批量操作。未勾选时导出全部固定工序；有勾选时仅导出勾选工序及其当前任务、顺序、生成 / 禁用状态和参数。
- 样式 C 的新增任务入口只出现在当前工序的任务列表中，新增任务必须显式记录所属工序。
- 样式 C 中工序不可新增、删除和排序；任务的新增、删除、禁用、筛选和排序只作用于当前工序。
- 工艺规划任务与生产执行右侧单步调试中的工位工步是不同概念；工位工步不写入工艺规划，也不能通过新增任务创建。
- 样式 A / B / C / D 的一键生成任务必须先检查打磨、焊缝、装配基准特征是否存在；缺少特征时不得生成任务。
- 工序命名应包含工艺类型和对应工件/特征关系。
- 样式 C 的抓取、放置、翻面压紧使用所属固定工序的工件对象，只读回显，不允许重新选择；样式 A / B / D 继续沿用原工件选择规则。
- 打磨选择打磨特征。
- 装配定位选择装配基准特征。
- 样式 C 使用一个合并焊接任务，共用一次焊缝特征选择；样式 A / B / D 的定位焊扫描和定位焊仍是两个独立任务。
- 当前 Demo 只允许将样式 C 第 06 道“装配”工序发送到虚拟仿真，不把工序内的合并焊接子任务单独作为仿真对象。
- 本地文件导入不受单次工艺规划发送入口限制；当前 Demo 每个本地副本同时复制第 06 道正面装配任务和第 12 道反面装配任务，用于演示同一仿真副本内的多装配任务选择与工位切换。
- 本地文件 Demo 的第 06 道装配任务在原焊接任务结构上复制出焊接任务2，两组各自维护 6 个焊缝段和独立轴值；第 12 道仍保留单组焊接任务。该复制只用于本地仿真演示，不改变工艺规划原工序的任务数量。
- 第 06 道装配仿真副本将该工序内“翻面压紧”任务的 `J1-J8` 轴值作为支撑机构轴值，并另行维护本地 Demo 的压紧机构 `J1-J6` 轴值；两组轴值均随仿真副本独立保存，重新生成程序或导出时保持当前编辑值。焊接任务继续提供扫描路径点位和焊接路径点位。
- 第 06 道装配仿真副本固定包含 6 个焊缝段。每段包含 2 个扫描结果点和 2 个焊接结果点，因此扫描共 12 点、焊接共 12 点，数量与工艺规划一致；虚拟仿真任务树不得再把扫描和焊接拆成两个任务节点。
- 6 个焊缝段从所选焊缝特征曲线按弧长分散取样，段内端点跨度约为曲线长度的 `8%`，必须清晰表达一段线而不是近似重合的点。焊接端点位于曲线上；扫描端点与同序号焊接端点保持 X/Y 和姿态一致，并沿正 Z 按扫描参数 ΔZ 远离焊接点位，当前默认 `80 mm`。不得通过模型包围盒投影、规则网格或任意世界坐标伪造路径。
- 工艺规划每次发送第 06 道装配工序都创建新的仿真数据副本；副本创建后不受上游后续修改影响，仿真结果也不回写工艺规划。
- 虚拟仿真的正反面不得根据工序名称推断，必须读取固定工序的 `simulationSide`；主筋板装配工位1为正面，主筋板装配工位2为背面，兼容旧“筋板及贴板翻转工位”时按背面处理。
- 虚拟仿真中的 `加工程序1` / `加工程序2` 分别对应同一装配任务内的焊接任务1 / 焊接任务2；每组加工程序都是 Robot1 与 Robot2 同步启动、并行执行的双机程序，树中两个 Robot 子程序上下排列只表达并行分支，不表达执行先后。
- 虚拟仿真点击“程序生成”时按焊缝段分配执行机器人；一个焊缝段的扫描与焊接必须绑定同一个机器人。默认焊缝段 1-3 属于 Robot1，焊缝段 4-6 属于 Robot2，用户可在生成前逐段调整。
- 虚拟仿真生成的扫描/焊接子程序采用 Pathsim 的点位语义，每个子程序固定生成 6 个点位：`P_APPROACH_1`（`PTP`，目标位姿为 `J1-J6 + E1`，速度 `S=100%`）、`P_SCAN_START / P_WELD_START`、`P_1`、`P_2`、`P_SCAN_END / P_WELD_END` 和 `P_DEPART_1`（其余均为笛卡尔 `X/Y/Z/RX/RY/RZ + E1` 点，速度单位为 `mm/s`）。`P_APPROACH_1` 关节目标固定为 `J1=15°、J2=-60°、J3=10°、J4=180°、J5=30°、J6=0°`；Robot1 的外部轴从 `-1200 mm` 进入，Robot2 从 `+1200 mm` 进入。扫描/焊接各自维护的 2 个端点仍是工艺规划的几何源；生成器在两端之间插入 `P_1`、`P_2`，不改变 3D 视窗点位数量。
- 虚拟仿真的播放范围由程序树选中节点决定：加工程序根节点执行双机完整程序，Robot 子程序节点执行对应单机完整程序，扫描/焊接程序节点只执行所选程序段；切换节点必须重置原播放范围的状态和进度。
- 虚拟仿真的数模查看与工位视图互斥表达当前对象：选择左侧“焊接任务”或某个焊缝段时进入数模查看；选择焊接任务回显全部 6 段，选择单段只回显该段的 2 个扫描点和 2 个焊接点。从数模查看选择右侧程序时进入任务适用工位并清除焊缝段选中。数模查看中的程序只保留描边详情态，不使用浅橙底选中态；进入工位也必须清除左侧路径任务选中。
- 新建、切换或本地导入虚拟仿真副本时，默认场景必须为数模查看；初始相机从工件正面（正 Z）查看，背景网格与该正面平行。程序未生成时，工位页签只查看工件数模，工位示意台、支撑和设备必须在程序生成成功后才出现。
- 正面和背面工位必须使用与数模查看分离的标准初始机位：工位长边在画面中保持水平，平台及两侧设备完整入镜；用户点击重置视图后恢复当前工位的标准机位。
- 未接入机械臂和真实运动模型前，播放使用进度条 mock 动画和视图内状态说明回显范围与并行关系，不弹出 Modal，不生成或伪造机器人运动结果。
- 虚拟仿真播放器使用一个品牌重点色主播放按钮承载播放、暂停和继续，尺寸大于两侧的快退/快进按钮：播放中显示暂停，暂停后显示继续。主按钮两侧提供按 mock 时间轴一次跳转 `±3 秒` 的中性快退/快进按钮，不进入橙色选中态；重置只允许在暂停态执行，播放中、初始和完成态必须置灰。
- 抓取结果点位用于表达电磁铁工具头位姿，路径点位维护 6 个安全点。
- 放置和翻面压紧结果点位使用 J1-J8，其中 J1 单位为 `mm`，J2-J8 单位为 `°`；不维护安全点路径入口。
- 打磨结果点位按特征路径生成 `P1-6(n)`，每个点包含 XYZ 坐标与 RPY 姿态；路径点位只维护单组 6 个安全点，安全点弹窗不显示分组 tab。
- 打磨工序生成时，从所选打磨特征 OBJ 的中心路径按弧长 `0% / 20% / 40% / 60% / 80% / 100%` 取 6 个结果点；结果点坐标必须位于特征线上。
- 打磨安全路径按 `起点远 -> 起点中 -> 起点近 -> 结果点1-6 -> 终点近 -> 终点中 -> 终点远` 组织，安全点沿特征面法向表达接近和远离结果点的趋势。
- 打磨路径在 3D 视窗中以橙色点和 `P1-P6` 标签标注，不回显工具头模型；结果点、安全点和 RPY 数据保持不变；当前多选特征时取第一条已选特征生成这一组路径。
- 装配定位结果点位按装配基准生成 `P1-3/4(n)`，每个点包含 XYZ 坐标与 RPY 姿态；当前原型路径点位按 4 组安全点维护，安全点弹窗使用“扫描点组1-4”tab。
- 定位焊扫描结果点位按焊缝扫描路径生成 `P1-6(n)`，每个点包含 XYZ 坐标与 RPY 姿态；当前原型路径点位按 6 组安全点维护，安全点弹窗使用“扫描点1-6”tab。
- 样式 C 合并焊接任务的焊接结果点按 6 组焊缝段组织，每组包含焊缝段起点和终点，共 12 个结果点；样式 A / B / D 的独立定位焊任务继续保留原 4 组、8 个结果点留档。每个结果点包含 XYZ 坐标与 RPY 姿态 6 个参数。
- 任务卡片中的每个结果点位行都应可被单击，并触发 3D 视窗回显对应高亮；打磨只回显路径点，其他工序可回显工具头位置或复用安全点遮罩作为 demo 效果。
- 点击定位焊结果点中的焊缝段分组标题时，3D 视窗应高亮该焊缝段，并同时回显该段起点和终点的工具头位姿。
- 打磨路径点位按单组 6 个安全点维护，安全点弹窗不显示分组 tab。
- 定位焊扫描路径点位按 6 组扫描安全点维护，安全点弹窗使用“扫描点1-6”tab。
- 样式 C 合并焊接任务的焊接路径按 6 组焊缝段维护；样式 C 路径点位以焊缝段表格呈现，安全点与结果点内嵌在选中段的「扫描路径 / 焊接路径」视图中编辑，不再使用安全点配置浮窗。样式 A / B / D 的独立定位焊任务继续使用安全点弹窗与“焊缝段1-4”tab。
- 压紧点配置与翻面压紧任务的结果点位同源：焊接任务路径点位的「压紧配置」视图按当前选中焊缝段维护 J1-J6 共 6 个关节结果点（J1 为直线位移 mm，J2-J6 为旋转角 °）；每段可独立设置不启用压紧，关闭后该段点位不再参与 demo 回显；视图只编辑结果点位，不显示工作台、压紧编号、覆盖率等翻面压紧工艺参数字段。
- 修改点位或关节后，该任务条目和点位信息处应出现脏状态标记。
- 点击更新后清除脏状态。
- 任务卡片支持拖拽排序；样式 C 只改变当前工序内的任务顺序，样式 A / B / D 改变平铺任务顺序，均不改变任务类型与点位配置。
- 样式 A / B / D 任务列表的“重新排序”用于恢复一键生成任务的默认顺序；手动新增任务保留在默认生成任务之后。
- 任务卡片左侧删除按钮点击后必须先通过 popover 二次确认，确认后才允许删除。
- 点击样式 C 工序卡片后，左侧结构树和 3D 视窗立即按固定工序的 `workpieceIds` 与工序任务特征进入工序隔离：工序对象保持 100% 不透明，工序外对象降至 25%。选择任务后增加任务聚焦层，任务关联对象保持 100%，同工序非当前任务对象降至 50%，工序外对象保持 25%。再次点击当前任务只退出任务聚焦并回到工序隔离，任务详情继续保留。
- 工序对象统一在 3D 视窗左上角显示“当前工序对象”及多个灰底对象 block，block 复用工序卡片第二行的语义分组，例如第 12 道为 `...-03` 与 `...-(02+01)`；任务条不重复显示作用零件名称。
- 工序和任务隔离只通过透明度与视窗轮廓表达，不给结构树任务关联对象增加橙色次选中行。结构树零件、特征和右侧任务共用唯一主选中语义；点击树对象后退出隔离，树对象使用主选中，零件与特征之间继续使用既有次选中关系，原任务降为仅品牌描边、无浅橙 fill 的保留详情态。点击“显示全部”同样退出隔离并保留任务详情；点击“隔离显示”后只恢复工序隔离，不自动恢复任务聚焦。返回工序总览或切换工序时必须清理旧工序的隔离、任务聚焦和对象回显。

## Common Mistakes

- 不要把样式 C 的合并焊接规则扩散到样式 A / B / D；留档样式必须继续保留两个独立任务。
- 不要漏掉放置工序。
- 不要只显示单个工件名；组合工序需要显示完整组合关系，必要时中间省略并 tooltip 展示完整名称。
- 不要让新建工序默认展示未选择对象的灰字名称。
