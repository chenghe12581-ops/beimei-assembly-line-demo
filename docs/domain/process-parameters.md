# Process Parameters Domain

## Concepts

- 工艺参数设置：按工艺环节维护默认参数。
- 任务条目配置：可在单个工序内 override 部分全局工艺参数。
- 阈值校验：将设定阈值与当前计算结果进行比较。

## Gripper Parameters

抓取工艺参数包含：

- 抓具配置：桁架抓具 / 机器人抓具。
- 磁铁参数：左、中、右磁铁的尺寸、磁力档位、负载等。
- 磁力档位使用下拉选框，选项为 `大` / `中` / `小`。
- 中间磁铁没有升降行程。
- 磁铁间距：左--中磁铁间距、中--右磁铁间距。
- 覆盖率阈值。
- 安全阈值系数。
- 偏心距阈值。
- 抓取路径设置。

## Pick Process Overrides

抓取任务条目可 override：

- 抓具配置：从工艺参数设置随任务生成并在任务详情中只读回显；任务详情不提供桁架抓具 / 机器人抓具切换。
- 左、中、右磁铁启用状态。
- 左、右磁铁 Z 值；中磁铁 Z 固定回显 `--`，不允许输入修改。
- 左、中、右磁铁磁力档位。
- 电磁铁位置 Y/Z 当前仅由计算结果维护；抓取工艺参数区暂不展示点位输入，不允许人工修改。

这些调整会影响覆盖率、安全系数、偏心距的回显结果。

抓取任务条目内不直接编辑覆盖率阈值、安全阈值系数和偏心距阈值。任务条目只回显 `电磁铁覆盖率`、`安全系数`、`偏心距` 三项计算结果，并用 badge 显示是否满足当前阈值；当不满足时，badge 文案必须带上用于比较的阈值数值。阈值来源优先使用该任务已有 override，没有 override 时使用工艺参数设置里的全局值。阈值编辑入口在工艺参数设置中维护。

抓取任务条目内的抓具配置、左中右磁铁启用状态、左/右磁铁 Z 值、磁力档位和电磁铁位置是该工序 feature，需要随工序记录。任务详情中的抓具类型只读回显；用户修改左中右磁铁启用状态、左/右磁铁 Z 值或磁力档位后，系统实时重新计算电磁铁覆盖率、安全系数、偏心距，并同步刷新电磁铁位置 Y/Z 回显，同时标记当前装配体为未保存状态。当前抓取工艺参数区不展示电磁铁位置点位输入和更新按钮。左中右磁铁启用状态可以由计算结果回显，也允许人工打开或关闭；左/右磁铁 Z 值使用输入框展示，作为后续重新计算的输入；中磁铁 Z 固定显示 `--`，不可编辑。

抓取任务条目中，左中右磁铁名称右侧的齿轮入口打开的是当前任务的磁铁参数 override 浮窗；浮窗内尺寸、磁力档位、额定负载、升降行程等参数只覆盖当前任务，不回写全局工艺参数设置。

## Grind Parameters

打磨工艺参数包含：

- 打磨工具配置：随动 / 固定等工具模式。
- 打磨宽度。
- 打磨速度。
- 打磨力。
- 打磨转速。
- 打磨偏移 ΔX / ΔY / ΔZ，单位 `mm`，只在工艺参数设置中维护。
- 轴角、摆动幅度、预压高度、安全点高度等路径生成参数。
- 采样密度，单位 `mm`。
- 路径自动合并角度范围：直线与直线、直线与圆弧切线、圆弧与圆弧切线三类夹角均使用最小值 / 最大值两个输入，单位 `°`，三项从上到下排列。

打磨任务条目中的工艺参数从工艺参数设置迁移而来，可在单个打磨任务内覆盖，覆盖后不回写全局工艺参数设置。当前打磨任务工艺参数区不展示打磨偏移 ΔX / ΔY / ΔZ 输入；偏移只保留在工艺参数设置弹窗中。

## Weld Scan Parameters

定位焊扫描工艺参数包含：

- 扫描距离。
- 扫描偏移 ΔX / ΔY / ΔZ，单位 `mm`，基于焊接起点。
- 扫描姿态 Rx / Ry / Rz，单位 `°`。

定位焊扫描任务条目中的工艺参数从工艺参数设置迁移而来，可在单个定位焊扫描任务内覆盖，覆盖后不回写全局工艺参数设置。

## Weld Parameters

定位焊工艺参数包含：

- 焊脚高度，单位 `mm`。

定位焊任务条目中的焊脚高度从工艺参数设置迁移而来，可在单个定位焊任务内覆盖，覆盖后不回写全局工艺参数设置。

## Style C Combined Welding Overrides

样式 C 的装配工序使用一个合并焊接任务。该任务共用焊缝特征选择，但必须独立保存以下两组 override：

- 扫描参数：扫描距离、扫描偏移 ΔX / ΔY / ΔZ、扫描姿态 Rx / Ry / Rz。
- 焊接参数：焊脚高度。

任务详情使用“扫描参数 / 焊接参数”小标题纵向分区。当前暴露的所有参数均允许修改；修改任一字段后，当前合并焊接任务和装配体进入未保存状态。重置时两组参数分别恢复其全局默认值。样式 A / B / D 继续使用独立任务和原参数结构。

## Workbench Parameters

工作台参数按工作台类型维护支撑与压紧默认值。工作台类型选择下方必须使用分页 tab 切换 `支撑参数` / `压紧参数`；支撑参数组只出现在支撑参数页，压紧参数卡片只出现在压紧参数页。支撑编号候选必须随工作台类型变化：

- 主筋板打磨翻面平台：`1` / `2`
- 主筋板正面装配平台：`1` / `2`
- 主筋板翻面平台：`1` / `2`
- 主筋板背面装配平台：`1` / `2` / `3` / `4` / `5`

支撑编号多选下方必须按已选支撑编号生成同数量的支撑参数组。每个支撑编号都有独立的：

- 支撑宽度。
- 零件位置：使用 `左端` / `右端` 分段选择，不使用数值输入。
- 软限位轴范围：按当前平台与支撑编号允许的轴向生成若干组最小值、最大值输入。

不同平台的支撑软限位轴规则：

- 主筋板打磨翻面平台：`1` 支撑为 `Y` / `Z` 向，`2` 支撑为 `Y` 向。
- 主筋板正面装配平台：`1` / `2` 支撑均为 `Y` / `Z` 向。
- 主筋板翻面平台：`1` 支撑为 `Y` / `Z` 向，`2` 支撑为 `Y` 向。
- 主筋板背面装配平台：`1` / `2` / `3` / `4` / `5` 支撑均为 `Y` / `Z` 向。

压紧编号候选对所有工作台均只显示 `1` / `2`。压紧编号多选下方必须按已选压紧编号生成同数量的压紧参数组。每个压紧编号都有独立的：

- 压紧类型。
- 压紧尺寸：长 / 宽。
- 零位位置：使用 `左端` / `右端` 分段选择。
- 软限位轴范围：按当前平台与压紧编号允许的轴向生成若干组最小值、最大值输入。

不同平台的压紧软限位轴规则：

- 主筋板打磨翻面平台：`1` / `2` 压紧均为 `Y` / `Z` 向。
- 主筋板正面装配平台：`1` / `2` 压紧均为 `X` / `Y` / `Z` 向。
- 主筋板翻面平台：`1` / `2` 压紧均为 `Y` / `Z` 向。
- 主筋板背面装配平台：`1` / `2` 压紧均为 `X` / `Y` / `Z` 向。

放置任务条目可 override 使用的工作台类型和支撑编号。放置工艺参数结果区必须位于结果点位面板前，结果点位标题和更新按钮行继续紧贴 `J1-J8` 输入行：

- 使用工作台：使用与工艺参数设置中工作台类型同源的单行只读回显，不在放置任务内提供修改入口。
- 使用支撑编号：按当前工作台类型显示可选支撑编号，支持多选、单选和取消选择。
- 支撑覆盖率：根据当前任务选择的工作台、支撑编号和对应工作台支撑参数实时计算回显；该值是计算结果，不直接输入。支撑覆盖率必须按已选支撑编号逐个回显，选择几个编号就显示几条覆盖率结果，覆盖率结果区位于支撑编号选择区下方，不与编号选择控件挤在同一行；每条结果使用 `编号N覆盖率` 作为 label，回显框内只显示数值和计算状态。
- `J1-J8`：支撑编号变化后同步刷新放置结果点位数值，并显示工序点位脏状态。

翻面压紧任务条目可 override 使用的工作台类型和压紧编号。翻面压紧工艺参数结果区必须位于结果点位面板前，结果点位标题和更新按钮行继续紧贴 `J1-J8` 输入行：

- 使用工作台：使用与工艺参数设置中工作台类型同源的单行只读回显，不在翻面压紧任务内提供修改入口。
- 压紧编号：按当前工作台类型显示可选压紧编号，支持多选、单选和取消选择。
- 编号 1 覆盖率 / 编号 2 覆盖率：根据当前任务选择的工作台、压紧编号和对应工作台压紧参数实时计算回显；该值是计算结果，不直接输入。
- `J1-J8`：压紧编号变化后同步刷新翻面压紧结果点位数值，并显示工序点位脏状态。

## Validation States

- 未计算：显示待计算。
- 满足：显示满足阈值。
- 超出/低于：显示异常 badge 和 warning tip；抓取任务条目中的异常 badge 需同时显示阈值数值，例如 `低于阈值 50%`、`超出阈值 0.80`、`超出阈值 200mm`。
- 修改任务内磁铁启用、左/右磁铁 Z 值、磁力档位或磁铁参数后实时刷新计算结果，并让当前装配体进入未保存状态；当前抓取工艺参数区不提供电磁铁位置 `更新` 按钮。任务详情中的抓具类型只读回显；中磁铁 Z 固定回显 `--` 且不触发修改。
- “重置”会恢复全局工艺参数并清除 override。

## Unsaved Changes

- 工艺参数设置弹窗内任一输入、开关、分段选择或多选变更后，弹窗进入未保存状态。
- 用户点击弹窗右上角关闭或底部关闭时，如果存在未保存状态，必须显示拦截确认弹窗。
- 拦截确认弹窗文案应说明：关闭后未保存的工艺参数不会应用到当前项目。
- 用户选择“继续编辑”时保留弹窗和当前编辑状态。
- 用户选择“放弃更改”时恢复到打开弹窗前的工艺参数状态，关闭工艺参数设置弹窗，并清除未保存状态。
- 用户点击“保存”后清除未保存状态并关闭弹窗。
- 磁铁启用等参数开关显示 `启用` / `关闭` 状态文字：状态文字使用语义化 switch label token；切换开关必须像输入框、分段选择一样触发未保存状态。

## Common Mistakes

- 不要把实际计算结果做成可输入字段。
- 不要把覆盖率、安全系数、偏心距做成不同视觉结构。
- 不要在抓取任务条目内展示覆盖率阈值、安全阈值系数、偏心距阈值的输入框；这些阈值只在工艺参数设置内编辑，任务条目内只回显计算值和阈值 badge。
- 当前抓取工艺参数区暂不展示电磁铁位置区域；后续恢复人工调整时需重新同步阈值回显和脏状态规则。
- 不要允许带着未保存的工艺参数直接关闭弹窗。
