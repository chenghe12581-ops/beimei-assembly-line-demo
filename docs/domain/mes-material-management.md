# MES 物料管理领域规则

## 概念

- **MaterialMaster（物料主数据）**：制造构件投入物料的编码、名称、类别、规格和计量单位。
- **MaterialLot（物料批次）**：物料的炉批号或来料批次，包含质保书、质量结论、可用数量和仓储位置。
- **WorkOrderMaterialRequirement（工单物料需求）**：工单对某物料的需求、预留、发料和缺口信息。

## 数量规则

- `available = max(onHand - reserved, 0)`，其中 `onHand` 为现存量，`reserved` 为已预留未释放量。
- `shortage = max(required - reserved - issued, 0)`，其中 `required` 为需求量，`issued` 为已发料量。
- 工单齐套状态按最高风险展示：存在缺口为“缺料”；无缺口且所有需求已发料为“已发料”；无缺口且所有需求均已预留为“已预留”；所有需求满足且无待发料项目为“已齐套”。

## 边界

- 物料管理维护物料可用性和批次质量的查看模型，不处理入库单、库位容量或实物库存移动。
- 库存管理是入库、库位和受控库存流转的页面。
- 托盘和 AGV 页面负责将已备齐物料送达产线，不承担物料主数据维护。
- 构件追溯以已制造的构件实例为对象，记录模型、工艺、生产、质量和库存证据；它不是物料主数据页面。
