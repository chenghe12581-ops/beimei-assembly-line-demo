# Feature Domain

## Concepts

- 打磨特征：从零件表面或边界提取出的打磨线。
- 焊接特征：从零件相接关系提取出的焊缝/交线。
- 装配基准特征：用于装配视觉定位和装配路径生成的基准边或基准特征。
- 独立显示：结构树中将所有特征从原零件层级抽出，按特征类型分组展示。

## Feature Types

- `grind`：打磨特征。
- `weld`：焊接特征。
- `datum`：装配基准特征。

## Structure Tree Rules

- 项目管理结构树不展示解析/提取出来的特征节点，只展示装配体、工作面和工件模型。
- 工艺规划结构树可以展示特征节点，并支持独立显示。
- 特征独立显示时，特征应分为父级：
  - 焊接特征
  - 打磨特征
  - 装配特征
- 父级下的特征对象应同层级挂载。
- 特征对象文字样式应与零件条目统一，不使用彩色文字。
- 特征对象行不显示类型 icon；行首保留 checkbox，用于勾选后批量删除特征对象。未勾选时 checkbox 默认隐藏，仅在 hover 时显示。
- 特征对象 checkbox 只表示删除该特征对象本身，不应勾选或半选关联零件、装配体或工作面；关联零件只能通过选中特征后的视觉高亮表达。
- 选中具体零件模型时，可对 `relatedPartIds` 包含该零件的特征对象进行关联弱高亮，弱高亮可同步到结构树和 3D 视窗；该状态不得写入 checkbox 删除集合，也不得替换装配体/工作面的现有选中与 3D 显示逻辑。
- 右侧任务列表选中的工序进入隔离模式：特征类工序将对应特征及其关联零件作为隔离对象以 100% 不透明显示，不关联零件/特征统一降至 25% 不透明度；零件类工序只将任务工件作为隔离对象，不额外纳入关联特征。隔离背景零件使用中性低饱和材质并保留低对比轮廓，隔离目标零件保留原材质并使用品牌橙色轮廓；隔离模式不叠加普通选中的整面黄色遮罩。
- 特征对象尾部不显示类型 badge。
- 打磨特征、焊接特征、装配特征父级名称前显示对应类型 icon。
- 父级数量 badge 可使用主题浅色，用于快速区分特征类型。
- 非独立显示时，同一零件下直接挂载的特征对象按工艺生成顺序展示：焊接特征、打磨特征、装配特征。
- 工艺规划结构树中的装配体根节点在 C/D 样式中使用与特征父级一致的灰底 header、11px 字号和数量 badge；可点击以更新 3D 视窗/属性上下文，但 header 自身不显示橙色选中态。
- 保留结构树原有竖线样式，不要因增加 checkbox 或独立显示破坏层级线。

## Project Management Property Panel

- 项目管理页可以把真实工艺规划树派生成扁平零件列表展示，但不得删除或改写底层树里的工作面分组和零件父子关系。
- 项目管理页点击结构树中的装配体、工作面或零件节点时，右侧“属性参数”面板必须根据该节点刷新。
- 缺失装配图纸的装配体不能直接进入工艺规划；项目管理条目中原图纸管理位置显示红色 `FileWarning` icon，工艺规划入口 icon 不显示但保留占位。
- 选中具体零件节点时，属性参数面板展示该零件的一张参数卡片。
- 选中装配体或工作面等包含子零件的节点时，属性参数面板必须收集该节点下所有带模型的零件，并按卡片纵向堆叠展示。
- 该堆叠展示是项目管理页查看装配体所含零件参数的核心 feature，不要退化为“只有叶子零件才显示属性”。
- 页面代码中该行为由 `ModelPropertiesPanel` 根据选中节点执行 `collectModels(selectedNode)` 完成；项目管理结构树点击入口必须允许非叶子节点写入当前预览选择。

## Viewport Highlight Contract

- 点击任一特征节点必须触发 3D 视窗特征回显和高亮；这个功能不可因结构树样式、独立显示或 3D 视窗重构丢失。
- 样式 C 工艺规划结构树中，点击零件、装配体或特征节点只更新 3D 视窗高亮/上下文，不自动隐藏其它模型；显隐只由行尾小眼睛控制。
- 样式 C 工艺规划结构树选中具体零件时，3D 视窗高亮应保留零件原实色，叠加 0.58 不透明度的半透明黄色遮罩，并使用约 1.2px 的 `amber.500` / `#F59E0B` 轮廓；普通选中时其它零件叠加 0.58 不透明度的 Slate 灰遮罩以拉开饱和度对比，不要用纯色材质替换零件本体颜色。隔离目标零件复用同一轮廓颜色、透明度和线宽。
- 样式 C 工艺规划正常进入时不默认显示零件操作轴。作为 demo hack，双击 `坐标转换` 工具按钮后，相当于当前装配体所有零件都已设置过操作轴，用户获得逐个查看操作轴的 access；之后选中具体零件时，3D 视窗只在该零件 bounding box 体积中心显示同款 Rhino Gumball 风格操作轴，仅用于可视化回显。03、04 零件属于反面零件，操作轴默认翻转 180°；坐标转换浮窗打开时由坐标转换选择结果接管操作轴显示，避免重复。
- 特征选择应通过显式方法表达，而不是散落在 JSX 中：
  - `showFeatureInViewport(featureNode)`：选中特征并确保该特征在 3D 视窗中可见。
  - `selectTreeNode(node)`：结构树统一选择入口；当 `node.nodeType === 'feature'` 时必须调用 `showFeatureInViewport`。
  - `collectSceneFeatureViews(tree, featureType, selectedFeatureId)`：把特征树节点转换为 3D 视窗使用的 FeatureView。
- 3D FeatureView 必须同时保留：
  - `id`：渲染实例 id，多段特征可以使用 `${featureId}-${index}`。
  - `sourceId`：原始特征节点 id，用于选中、隐藏/显示和业务状态映射。
- 判断选中高亮时使用原始特征节点 id；判断隐藏/显示时使用 `sourceId`，不要直接使用渲染实例 id。
- 独立显示和原树层级显示两种模式必须共享同一套选择和 3D 高亮方法。

## Extraction Rules

- 焊缝特征提取生成焊接特征。
- 手动焊缝提取必须先在 3D 视窗选择面并生成焊缝段候选；所选面不相交时不得创建焊缝特征，生成成功后必须点选焊缝段再确认创建。
- 打磨特征提取生成打磨特征。
- 打磨特征应保留来源焊缝关系；选中打磨特征时，3D 视窗必须同步高亮其来源焊缝/交线模型，但不应让来源焊缝在结构树中进入选中或关联弱高亮状态。
- 手动打磨特征提取必须先选择已有焊缝特征，再把该焊缝指配给相接的两个零件；确认后一次创建两个打磨特征对象，分别挂载到零件 A 和零件 B 下，且每个打磨特征的 `relatedPartIds` 只包含其归属零件。
- 装配基准提取可手动设置，也支持 demo 下连续点击批量创建。手动设置时，零件 A/B 在装配语义中分别显示为子板/父板，并必须按子板基准 1、父板基准 1、子板基准 2、父板基准 2 的顺序完成，避免基准序号和零件对应关系被误配。
- 创建打磨特征和装配基准特征前必须先存在焊缝特征；若用户从零件或 3D 工具入口直接创建打磨/装配基准，demo 应用 Toast 拦截并提示先创建焊缝特征。
- 特征提取会改变当前装配体的工艺规划内容，必须标记该装配体为未保存状态。
- 未保存状态只在装配体实例上表达：页面面包屑中的装配体名称后追加橙红色 `*`，工艺规划下拉菜单对应装配体条目后追加橙红色 `*`；不要给主导航“工艺规划”tab 追加 `*`。
- 保存当前工艺规划后，应清除由特征提取产生的未保存状态。
- 装配特征提取必须打开独立的“装配基准提取”浮窗，不并入焊缝/打磨手动提取浮窗。
- 装配基准提取浮窗是 3D 视窗内的操作面板；在 C/D 方案工艺规划布局中，必须浮在右侧任务列表之上或避开右侧任务列表，不允许被任务列表面板遮挡。
- 工艺规划浮窗按 `CoordinateTransformPanel`、`ManualFeatureExtractionPanel`、`AssemblyDatumExtractionPanel` 等职责拆分；组件只负责呈现和回调，项目页面负责领域校验、临时选择清理和特征写入。
- 装配基准提取的子板/父板选择器必须纵向满宽展示，长零件名称允许换行；不得恢复为并列两列布局。

## Coordinate Transform

- “坐标转换”是 3D 视窗工具栏中的模型对象操作，不创建结构树特征节点，也不改变任务列表。
- 点击“坐标转换”后必须在 3D 视窗内打开浮窗，浮窗包含：
  - 零件对象多选下拉，下拉菜单提供“全选零件”入口。
  - 零件对象多选下方 divider 分隔后的重选中心操作，label 为 `重选中心`，只包含整行 primary `设为中心` 按钮，不使用独立描边容器，不提供单独的中心目标零件选择或 `吸附选点` 按钮。
  - XYZ / RPY 偏移输入，用于对所选零件的质心 pivot 应用平移与旋转偏移。
  - footer 操作按钮：`应用` 与 `取消`。
- 用户选择零件后，3D 视窗必须对这些零件显示 bounding box，并在几何质心显示 XYZ pivot 轴；同一批选择零件也是重选中心的目标零件，视窗必须立即提供每个零件的角点、面中心点、体中心点和面上点选吸附能力。
- 用户在视窗内选择一个新的中心候选点后，`设为中心` 按钮启用；未点选新的中心点时该按钮置灰。点击 `设为中心` 后，本次坐标转换 pivot 轴更新到该点。
- pivot 轴回显使用类似 Rhino Gumball 的纯可视化样式，包含三向平移箭头和三色旋转环；当前 demo 不实现拖动或旋转交互。gumball 视觉尺寸固定为 01 零件选中时的大小，不随当前选择零件尺寸缩放；多选零件时只显示一个 gumball，位置为所选零件 bounding box 并集的体积中心。
- 点击 `应用` 时，如果未选择零件，应提示先选择零件对象；如果已选择零件，应 Toast 提示 `对[零件对象名称]应用了坐标转换`。多个零件使用 `、` 连接。
- 点击 `取消` 或关闭浮窗时，应清空当前选择和偏移输入，不保留跨项目的坐标转换临时状态。

## Common Mistakes

- 不要把装配基准显示成普通焊缝。
- 不要把装配基准提取弹窗改成焊缝/打磨浮窗里的 tab。
- 不要让装配基准提取弹窗落在右侧任务列表面板下面。
- 不要在独立显示中给特征对象再加一层 stroke wrap。
- 不要在特征对象上重复显示“打磨线/焊缝/装配基准”尾部 badge。
- 不要把坐标转换实现成只发 toast 的占位操作；必须有 3D 视窗浮窗、对象选择和 pivot/bounding box 回显。
