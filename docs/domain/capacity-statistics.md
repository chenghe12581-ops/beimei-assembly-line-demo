# 产能统计领域规则

## 时间指标

- `开机时长`为统计周期内系统开机时间。
- `运行时长`为生产线处于加工状态的时间。
- `故障时长`为故障报警到复位的累计时间。
- `待机时长 = 开机时长 - 运行时长 - 故障时长`，结果不小于零。
- `稼动率 = 运行时长 / 开机时长 * 100%`，开机时长为零时为 0%。

## 工件并行时序

- 正面第一块贴板可与主筋板打磨并行，后续正面贴板可与上一块定位焊准备并行。
- 反面第一块贴板可与翻面和反面上料并行，后续反面贴板可与上一块定位焊并行。
- 贴板提前完成后到主体到位前的间隔单独标记为等待。
- 工件总加工时长为首个工序开始到下料完成的墙钟时间，不是工序时长简单相加。
- 加工中的工件可以存在尚未完成的计划工序，界面用当前时刻线区分已完成和计划段。

## 动态贴板

- 正面和反面贴板分别计数。
- 双面装配才生成组件翻面和主筋板装配工位 2 上料。
- 贴板工序至少包含打磨、装配和定位焊三个阶段。
