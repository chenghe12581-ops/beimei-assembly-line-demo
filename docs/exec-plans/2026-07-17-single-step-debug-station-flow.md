# 生产执行单步调试与工位联动

## Goal

让生产执行右侧单步调试面板可以选择当前工作台可见的六个工位，并从页面共享的生产任务状态回显选中工位的当前工序任务、加工零件和数量。面板提供自动、单步、手动三种执行模式，与左侧 WP 工序任务和中间工作台使用同一份任务状态。

## Contract

- 六个可选工位来自 `productionWorkbenchAreas`，不从工序名称或列表序号推断工位。
- 工位 Tag 统一为「空闲 / 执行中 / 已暂停 / 异常」；异常处理完成后任务状态进入暂停，工位 Tag 变为「已暂停」。
- 当前工位任务通过 `productionWorkbenchProcessPlacements` 的显式映射解析；没有映射到所选工位时显示空闲状态。
- 六个工位消费显式工步模板：主筋板打磨 6 步、主筋板装配工位1 7 步、贴板打磨工位1/2 各 2 步、翻面工位 3 步、主筋板装配工位2 8 步；装配步骤中的贴板使用完整零件名称，焊缝使用当前组合序号。
- 选中空闲工位时仍展示对应完整工步模板，使用「工位工步示例」标题且不标记当前工步；有活动工序时再切换为真实任务进度。
- 自动模式继续使用生产任务自动推进；单步和手动模式由面板按钮推进同一个 WP 的一个工步。模式切换不重置任务状态，手动模式只允许推进当前选中且匹配活动工序的工位。
- 左侧 WP 任务树、中间工位卡片和右侧单步调试面板均读取 `tasks` 状态，不能各自维护当前工序副本。
- 右侧工位详情中，每个工位的自动/单步控制按钮独立反映本工位状态：
  - 任务未开始时显示「初始化」（就绪/已停止时可用）和「自动执行 / 执行工步」。
  - 本工位工件 running 时，执行按钮显示「暂停」。
  - 本工位工件 paused 时，执行按钮显示「继续」。
  - 两个模式均提供「停止执行」按钮，仅在本工位占用执行会话时可用。
- 全局互锁：一个工位启动自动或单步执行后（running 或 paused），其他工位的初始化、执行、停止执行按钮全部置灰，tooltip 提示「当前有工位正在执行，请先暂停或停止当前任务」。
- 「停止执行」只停止当前自动/单步执行会话并释放工位锁，不停止整张工单；顶部工具栏的「停止任务」才是全局停止。
- 暂停不释放工位锁；停止执行、任务完成/异常/停止后才会释放锁。

## Implementation

1. 扩展生产工件运行状态，记录当前聚合工序的工步索引。
2. 将自动定时器和面板单步操作收敛到同一份推进逻辑。
3. 将六工位快照和执行回调传入 `SingleStepDebugPanel`。
4. 在 Component Lab 中复用同一组件，保留静态示例数据用于样式检查。

## Verification

- `npm run build`
- 页面初始、任务执行中、暂停和装配工步切换时检查右侧面板与左侧 WP / 中间工位同步。
