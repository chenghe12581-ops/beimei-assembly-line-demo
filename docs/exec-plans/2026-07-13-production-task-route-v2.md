# 生产执行新版 15 条任务路线

## Goal

- `ProductionTaskTreePanel1` 保留原 24 条工序名称和零件对象。
- `ProductionTaskTreePanel2` 在每个 WP 分组内展示用户确认的 15 条聚合任务。
- 任务条目继续使用单行「序号 / Checkbox + 状态灯 + 工序名称 + 零件名称 + 禁用」样式，不显示工位。
- 工位与托盘映射只驱动生产监控视图中对应状态卡片和轴测工位。

## Route

1. 上料 / 01 / 托盘 01
2. 打磨 / 01 / 主筋板打磨工位
3. 上料 / 01 / 主筋板装配工位1
4. 抓取 / 02 / 托盘 03
5. 侧面打磨 / 02 / 贴板打磨工位1
6. 装配 / 02+01 / 主筋板装配工位1
7. 抓取 / 03 / 托盘 05
8. 侧面打磨 / 03 / 贴板打磨工位1
9. 表面打磨 / 03 / 贴板打磨工位1
10. 翻面 / 02+01 / 翻面工位
11. 装配 / 03+02+01 / 主筋板装配工位2
12. 抓取 / 04 / 托盘 07
13. 侧面打磨 / 04 / 贴板打磨工位2
14. 装配 / 04+03+02+01 / 主筋板装配工位2
15. 下料 / 04+03+02+01 / 托盘 09

## Verification

1. `npm run build`
2. Component Lab 旧样式仍显示 24 条，新样式每个 WP 显示 15 条。
3. 新样式任务行不显示工位，继续保持单行高度和原交互。
4. 执行托盘任务时，01 / 03 / 05 / 07 / 09 对应托盘卡片更新状态；其余任务更新对应工位卡片。
