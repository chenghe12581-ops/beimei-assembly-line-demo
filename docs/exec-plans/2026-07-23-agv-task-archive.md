# AGV Task Archive

## Goal

在托盘管理的 AGV 任务调度区增加已完成任务归档能力，并在同一托盘管理页面内提供历史任务视图。

## Scope

- AGV 已完成任务在操作列增加「归档」，归档后从当前任务列表移出。
- AGV 调度标题栏增加「历史任务」入口，并显示归档任务数量。
- 历史任务列表只读，可恢复到当前任务列表。
- 历史任务模式隐藏托盘整体视图，AGV 任务列表占满托盘管理内容区可用高度。
- Component Lab 同步当前任务、历史任务、归档和恢复状态。

## Domain Constraints

- 只有 `已完成` 任务可以归档，避免隐藏仍参与点位锁定或等待执行的任务。
- 归档任务不参与 AGV 点位占用、计划任务匹配或执行互斥判断。
- 恢复只改变任务所属列表，保留任务的类型、零件、路线和完成状态。

## Verification

1. 在托盘管理中确认待执行和执行中任务的「归档」不可用，已完成任务可归档。
2. 归档后当前列表移除该任务，「历史任务」数量更新。
3. 进入历史任务后确认托盘整体视图隐藏，任务区填满剩余高度，表格字段只读。
4. 恢复任务后确认历史列表移除该任务，当前列表重新显示。
5. 检查 Component Lab 分栏与平铺视图并运行 `npm run build`。
