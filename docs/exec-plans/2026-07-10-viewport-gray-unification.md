# 视窗灰阶统一审计与执行方案

## 审计结论

- 工艺规划 3D 视窗当前使用 `#E7E9EC`，是现有产品中最稳定的视窗背景基准。
- 生产工作台此前使用 `#DFE3E8`，模型视图 Canvas 使用 `#E5E7EB`，视觉监控使用深色 `slate-900`，同组 tab 切换时明度与色温跳变明显。
- `#E7E9EC` 比 `slate-200 / #E2E8F0` 蓝感更弱，能与工艺规划的 zinc 边线、白色玻璃浮层和橙色品牌高亮保持一致。

## 统一方案

1. 新增语义 token `color.bg.viewport = #E7E9EC`。
2. 工艺规划、生产工作台、模型视图和视觉监控共用该底色。
3. 视觉监控保留浅灰网格、准星和识别框，不再使用深色渐变背景。
4. 相机名称、相机切换和识别摘要统一使用白色半透明玻璃层。
5. 组件库增加三类视图共用灰阶基线示例，作为后续实现事实来源。

## 验证

- 检查生产执行三种视图切换时背景无明显明度或色温跳变。
- 检查视觉监控文字、相机 tab、识别状态和准星在浅灰底上的可读性。
- 检查工艺规划原视窗不受 token 新增影响。
- 运行 `npm run build`。
