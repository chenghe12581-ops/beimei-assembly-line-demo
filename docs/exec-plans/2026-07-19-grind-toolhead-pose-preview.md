# 打磨特征工具头位姿回显

## Goal

在工艺规划中先完成打磨工序的真实工具头 demo 回显：六个结果点沿打磨特征线等弧长取样，起点和终点分别生成三段安全进点与安全出点，工具头模型朝向当前特征点。

## Scope

- 复用 `src/solver_Raffles.stl`，不新增工具头资产。
- 只修改打磨工序的结果点、路径安全点和 3D 工具头回显。
- 定位焊、定位焊扫描、装配定位继续使用现有 mock 回显。
- 不接入真实 TCP、机器人运动学或后端接口。

## Rules

- 结果点按特征路径弧长 `0% / 20% / 40% / 60% / 80% / 100%` 生成。
- 安全路径顺序为 `起点远 -> 起点中 -> 起点近 -> 结果点1-6 -> 终点近 -> 终点中 -> 终点远`。
- 结果点保留在特征线上；工具头渲染位置使用工具头 TCP 安装偏移。
- 工具头的 TCP 朝向当前特征点，姿态输入作为局部旋转微调。

## Verification

- 生成打磨路径后，六个结果点与打磨特征线重合且间距均匀。
- 点击结果点可回显单个工具头；点击安全点可回显接近或离开姿态。
- 工具头局部轴翻转 180° 后朝向工件接缝，结果点使用世界坐标橙色点和 `P1-P6` 标签标注。
- 编辑结果点或安全点坐标、姿态时，工具头实时更新。
- 禁用安全点后，该安全点不再显示，重置后恢复。
- `npm run build` 通过。

## Completed Check

- 通过本地工艺规划页面生成任务序列，核对第一道打磨的 12 个路径点顺序和真实 OBJ 坐标。
- 点击安全点 P1 并最小化浮窗，确认 `solver_Raffles.stl` 在 3D 视窗中可见；点击结果点后确认工具头切换到结果点位姿。
- 重新构建产物已包含 `solver_Raffles.stl` 和打磨回显代码。
