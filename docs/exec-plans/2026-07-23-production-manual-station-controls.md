# 生产执行工位手动控制与托盘详情联动

## 目标

- 生产工作台的托盘卡片与工位卡片一样，可点击后在右侧「工位详情」中查看。
- 自动和单步执行保持现有任务推进交互；新增的设备控制只在「手动」模式中显示。
- 机器人、打磨头、三轴、支撑装置和压紧装置均使用矩形、透明背景、灰色 stroke 的硬件控制按钮。
- 所有 J 轴复用同一个「轴号 / 正向点动 / 位置回显 / 负向点动」组件。

## 实现计划

1. 新增手动控制配置与复用组件，按工位 ID 声明机器人、开关和 J 轴分组。
2. 将右侧详情的选中对象扩展为生产工位或托盘工位，保留现有 WP 快照和工步逻辑。
3. 为 01-09 托盘卡片增加整卡详情入口，保留已占用托盘铅笔编辑入口，不新增持久选中描边。
4. 01-08 托盘手动页提供物料编辑、搬运机器人控制和 AGV 取货点调度，复用现有 `traySlots` / `trayTasks` 及点位互斥规则。
5. 同步 Component Lab 中的右侧工位详情示例和长 J 轴列表验收态。
6. 更新 product spec、domain 和前端组件规范，构建后验证主页与 Component Lab。

## 验证

- `npm run build`
- 生产执行中点击工位卡片、空托盘卡片和已占用托盘卡片，检查右侧详情对象切换。
- 自动 / 单步不显示设备控制，手动模式按工位显示对应机器人、打磨头和 J 轴组。
- 所有新增操作按钮为透明背景、灰色边框的矩形硬件按钮，不使用品牌色填充。
- 点击设备命令按钮后按钮持续闪烁到 Demo 命令完成；J 轴点动按钮在按住期间闪烁。
- 手动模式不显示原「手动执行当前工位工步 / 与左侧工件工序任务同步」操作块。
- 点动按钮可改变只读位置回显，三轴「回原位」将 J1-J3 复位。
- 01-08 可修改托盘物料，并可以选择取货点发起 AGV 调度。
- Component Lab 分栏和平铺视图不溢出。
