# 虚拟仿真本地多任务副本执行计划

## 目标

将虚拟仿真从“一个副本等于一条装配任务”升级为“一个副本包含一条或多条装配任务”。本地文件导入 Demo 固定创建第 06 道正面装配任务和第 12 道反面装配任务，支持任务级选择、工位与程序联动，以及整条任务删除；第 06 道进一步演示两组焊接任务、两组独立加工程序和程序生成分页解锁。

## 范围

- `src/features/virtual-simulation/types.ts`
  - 新增仿真工作区副本类型，明确副本与内部装配任务的层级。
- `src/app/BeimeiAssemblyLinePage.tsx`
  - 主导航按仿真副本管理和切换。
  - 本地导入每次新增一个包含 06 / 12 的副本，不替换当前副本。
  - 工艺规划发送继续创建单装配任务副本。
- `src/features/virtual-simulation/components/SimulationTaskPanel.tsx`
  - 展示多条装配任务、明确当前选中态，仅展开当前任务的焊接层级。
  - 删除整条装配任务前进行危险确认。
- `src/features/virtual-simulation/hooks/useSimulationWorkspace.ts`
  - 按装配任务 ID 独立维护程序、参数、位姿与播放状态。
  - 删除任务时清理其派生状态。
- `src/features/virtual-simulation/components/SimulationProgramGenerateDialog.tsx`
  - 按焊接任务分页配置焊缝段执行机器人。
  - 多页首次翻到末页后解锁生成，返回前页仍保持可点击。
- `src/features/virtual-simulation/services/generateRobotProgram.ts`
  - 每组焊接任务生成同序号加工程序，并保持独立轴值、分配和指令 ID。
- `src/app/ComponentLabPage.tsx`
  - 同步多装配任务默认态与选中态示例。

## 数据关系

```txt
仿真副本（主导航一项）
├─ 第 06 道装配任务（正面工位）
│  ├─ 焊接任务1 / 焊缝段 1-6 / 加工程序1
│  └─ 焊接任务2 / 焊缝段 1-6 / 加工程序2（独立轴值）
└─ 第 12 道装配任务（反面工位）
   └─ 焊接任务 / 焊缝段 1-6 / 加工程序1
```

工艺规划发送的副本仍只包含被发送的装配任务；本地导入 Demo 固定包含上述两条任务。

## 验证

- 第一次本地导入创建副本1，左侧同时展示第 06 / 12 道装配任务。
- 第 06 道选中时启用正面工位并禁用反面工位；第 12 道相反。
- 在第 12 道生成程序后切换第 06 道，第 06 道仍显示未生成；切回第 12 道恢复原程序。
- 删除第 12 道时同步删除其焊接任务、焊缝段、程序和任务级状态，并自动选中第 06 道。
- 再次导入创建副本2，主导航同时保留副本1和副本2。
- 第 06 道程序生成弹窗第一页显示焊接任务1且按钮置灰；翻到焊接任务2后按钮解锁，返回第一页仍可点击。
- 第 06 道生成后右侧显示加工程序1 / 2，两组均包含 Robot1 / Robot2；程序2的支撑和压紧轴值与程序1不同。
- 第 12 道程序生成弹窗不显示分页器，生成后仅显示一个加工程序根节点。
- `npm run build` 通过并重新生成 `dist/`。
