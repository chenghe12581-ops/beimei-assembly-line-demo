# URDF 工位视窗与姿态回显

## Scope

- 使用本地 `beimeiji_weld_0623.urdf` 和 `urdf-stls/` 资源渲染工作台、滑台和双机械臂。
- 移除独立“数模查看”页签，工位场景通过焊接近景和程序全景两种相机状态承载模型查看。
- 保留现有支撑/压紧外部轴 J 值、程序生成、播放和导出逻辑。
- 增加独立的 URDF 机械臂关节姿态 mock，不写入现有外部轴业务数据。
- 播放时由独立 motion service 基于程序范围和进度生成临时 URDF 关节值，驱动机械臂网格与位姿浮窗；手动轴值始终作为不可变基准。

## Decisions

- 点击左侧“焊接任务”切到正上方焊缝视角；点击单个焊缝段只改变回显范围，不二次放大。
- 点击右侧任意程序节点切到包含机械臂、工作台和工件的全景视角。
- 工件使用应用侧标定的落台位姿；后续可替换为正式 URDF 装夹基准。
- 左机械臂映射为 Robot1，右机械臂映射为 Robot2。
- 视窗右上角增加只读机器人位姿浮窗；Robot1/Robot2 上下同时显示，并可分别切换坐标系。坐标系切换只改变对应机器人的末端位姿表达，J1-J6 读取机械臂旋转关节，J7 读取对应滑台轴，始终使用同一 URDF 关节状态。

## Non-goals

- 不实现逆运动学、碰撞检测或真实程序轨迹播放；播放只提供确定性的扫描/焊接姿态 mock。
- 不把 URDF 机械臂 J 值映射为现有支撑/压紧外部轴 J 值。
- 不改变现有程序生成器的 E1、外部轴限位和导出协议。

## Verification

- `npm run build`
- 桌面视口检查：焊接近景、程序全景、两台机械臂姿态联动。
- 检查 Component Lab 中共享关节行的可配置范围不会改变原有外部轴样式。
- 检查扫描、焊接、单机父级和双机根程序的播放姿态与 URDF 网格同步，暂停/跳播/重置不改写右侧手动关节值。
