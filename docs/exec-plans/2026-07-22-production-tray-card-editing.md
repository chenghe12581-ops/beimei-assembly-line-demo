# 生产执行占用托盘编辑态

## 目标

- 工作台已占用托盘卡片支持编辑当前零件类型和数量。
- 编辑结果写回生产执行共享的 `traySlots` 状态，并同步未完成的同托盘运输任务。
- 编辑期间暂停托盘 Demo 的后续推进，保存或取消后顺延一个完整步进间隔。
- 普通托盘展示态、托盘管理计划卡片和空托 / 预约 / 回收状态保持原有结构。

## 实现方案

1. `ProductionTrayCard` 在 `loaded` / `full` 占用卡片的编号右侧提供铅笔编辑图标，普通卡片不改变尺寸与布局。
2. `ProductionTrayEditDialog` 复用组件库 `ProcessSingleSelect`，完整显示 01-04 零件名称，提供正整数数量输入和关闭 / 取消 / 保存操作；`ProductionViewport` 负责根据当前托盘状态打开弹窗，保存回调由页面更新 `traySlots`。
3. 页面使用编辑中的 ref 阻止 Demo 定时回调覆盖托盘数据；提交或取消设置下一次 Demo 步进的最早执行时间。
4. Component Lab 同步展示水平和 skew 两种编辑入口，并复用托盘编辑弹窗样例。

## 验证

- `npm run build`
- 生产执行页面在 01 号托盘进入 `loaded` 后可通过卡片编号右侧编辑图标打开弹窗。
- 零件类型可切换 01-04，数量可修改，保存后普通卡片回显新值。
- 弹窗显示关闭、保存和取消入口，普通托盘和非占用托盘不显示编辑图标。
