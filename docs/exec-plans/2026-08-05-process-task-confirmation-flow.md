# 工序固定任务生成与保存状态执行计划

## 目标

样式 C 的16道固定工序在装配体解析后立即可见，但不自动创建工艺任务。用户点击“一键生成”后，系统一次性生成27项固定任务并显示绿色任务 Tag。任务参数修改后只影响对应任务的局部保存状态；项目级保存仍独立负责保存整个装配体工艺规划。

## 范围

- `src/app/process-planning-model.ts`
  - 为固定工序补充领域任务槽位、固定工件 ID 和组合对象显示。
- `src/app/BeimeiAssemblyLinePage.tsx`
  - 工序解析后不自动补齐任务；首次一键生成后才创建固定任务。
  - 一键生成完成后改为“重新生成”；重新生成须确认覆盖现有任务。
  - 新增任务级黄色未保存、红色校验错误与保存行为。
  - 工序卡片 V2 Tag 状态。
  - 一级工序 checkbox 多选与全部 / 部分导出。
  - 点击工序卡片即进入工序级隔离，并在视窗左上角回显固定工序对象 block。
  - 二级任务条移除重复作用零件名称，禁用 / 删除 icon 取消包裹层。
  - 长任务条常驻保存 / 禁用 / 删除操作。
  - 新增任务弹窗固定工件只读回显。
  - 未选任务时详情区缺省状态。
- `src/app/ComponentLabPage.tsx`
  - 保留 V1，更新 V2 状态语义并与主页面 420px 实际尺寸一致。
- `docs/domain/`、`docs/product-specs/`、`docs/frontend/`
  - 固化领域、交互和组件规则。

## 状态机

```txt
进入工艺规划（只显示16道已解析工序；无任务、无 Tag）
  -> 一键生成成功（一次写入27项任务；任务 Tag 绿灯）
  -> 修改任务参数或点位（名称出现橙色 *；Tag 灯变橙；任务尾部出现保存）
  -> 参数校验失败（Tag 显示红色三角感叹号；保存不可用）
  -> 修正校验错误（恢复橙色待保存）
  -> 点击任务保存（清除 *；Tag 灯变绿）
  -> 顶部项目保存（只保存项目；不批量清除橙色任务状态）

已生成后再次点击“重新生成”时，先提示会替换现有全部任务及其参数、点位、排序、禁用状态和手动新增任务。确认后才开始生成；生成未完整成功时保留原任务列表，不留下半新半旧的数据。
```

## 实现约束

- 状态灯只出现在一级工序卡片的任务 Tag 中。
- V2 卡片顶行左侧为“序号 + 工序名称”，Tag 位于右上角；不显示任务计数和列表顶部装配体 / 工序数摘要。
- 序号只在 hover 或 keyboard focus 时替换为 checkbox；勾选只维护批量导出范围，不进入工序，不增加卡片 fill 或 stroke。未勾选显示“导出全部”，勾选 n 道显示“导出(n)”，按钮固定 `70px` 宽度。
- V2 工序规划栏减少 Slate 灰，使用轻量白色 / Zinc 中性色。
- 浏览、返回和切换 Tab 不得改变任务状态；黄色修改在返回工序总览、切换工序和返回项目管理后继续保留。
- 顶部项目保存不得替代任务保存，也不得强制清除黄色任务状态。
- 一键生成前隐藏新增、筛选、批量操作、禁用和删除等任务级入口；进入工序时显示“暂无任务”。
- 状态颜色只表达任务生命周期：绿色为已生成且合法、橙色为有未保存修改、红色为校验错误。红色错误使用三角感叹号图标，不能与橙色修改共用。
- 工件对象从固定工序继承；新增任务弹窗不提供零件下拉。
- V1 组件库示例不得删除或覆盖。
- 工序级隔离只读取固定工序 `workpieceIds`；切换任务不得改变隔离范围。
- 任务条不重复渲染作用零件名称；对象集中在工序卡片第二行和视窗左上角回显。
- 禁用 / 删除 icon 直接贴在任务条上，不使用 fill、stroke、阴影或独立包裹层。

## 验证

- 16 道工序合计 27 个任务槽位。
- 进入工艺规划后只显示16道固定工序；未一键生成前无任务 Tag，进入工序显示“暂无任务”。
- 首次一键生成后完整出现27项任务与绿色 Tag；生成不完整时保留生成前列表。
- 修改后名称出现橙色 `*`、对应 Tag 变橙且尾部出现保存；保存后星号与保存消失、Tag 恢复绿色。
- 参数校验失败显示红色三角感叹号并禁用任务保存；修正后恢复橙色待保存。
- 顶部项目保存后，未单条保存的橙色任务继续保持橙色。
- 未选择任务时详情区不显示第一条任务内容。
- 点击工序卡片后立即进入隔离，视窗左上角显示该工序对象 block；切换任务保持同一隔离范围。
- 任务条不显示作用零件名称，禁用 / 删除 icon 无包裹层背景和描边。
- Component Lab 分栏和平铺视图中的 V1 / V2 均保持 420px。
- 多选工序后返回总览仍保留勾选；勾选和点击卡片主体相互独立；“导出全部”导出 16 道工序，勾选后“导出(n)”仅导出所选工序，切换文案不改变工具栏结构。
- `npm run build` 通过并重新生成 `dist/`。
