# 样式 C 工序规划与内部任务

## Status

- 2026-07-30 已完成实现和回归验证。
- 固定 15 道工序已由工艺规划和生产执行共用同一份领域定义。
- 旧 24 任务平铺方案保留给样式 A / B / D 作为原型对照。

## Goal

- 样式 C 作为持续演进的主方案，将工艺规划右栏从平铺任务改为“工序规划 -> 当前工序任务列表”两级结构。
- 装配体解析后固定展示 15 道工序；任务由用户进入工序后手动新增。
- 复用现有任务参数、结果点位、路径点位、3D 隔离和新增任务能力。
- 样式 A / B / D 保持当前平铺任务逻辑。

## Context

- 当前 `Project.processSteps` 是无父级归属的平铺任务数组。
- 样式 C / D 当前共用紧凑三列任务列表和任务详情。
- 生产执行当前独立维护 15 道聚合工序；新方案需要与工艺规划固定工序使用同一份业务定义。

## Scope

- 新增固定工序定义和任务到工序的显式归属。
- 为现有演示任务建立迁移归属，保留已有配置对象。
- 样式 C 右栏新增工序总览和工序任务二级页。
- 二级页使用单列长条任务，新增入口位于当前工序任务列表中。
- 排序、筛选、批量、禁用和删除只作用于当前工序。
- 同步 Component Lab、产品规格和领域规则。

## Non-goals

- 不修改样式 A / B / D 的平铺任务体验。
- 不把生产执行右侧单步调试中的工位工步写入工艺规划任务。
- 不新增状态管理方案或后端 API。

## Steps

1. 建立固定 15 道工序定义和现有任务归属映射。
2. 扩展 `ProcessStep`，复用原任务配置并支持 `processId`。
3. 实现样式 C 工序总览和当前工序任务列表。
4. 将新增、排序、筛选、禁用和删除限定在当前工序。
5. 同步生产执行的固定工序定义和样式 C 数据语义。
6. 更新 Component Lab 和文档，完成构建与页面验证。

## Risks

- 当前任务相关状态大量使用 `step.id`，迁移时必须保留原 id。
- 同一任务不能同时归属于两个工序；缺失任务应新增实例，不复用同一对象。
- 切换样式时要清理工序/任务选择，避免新版选择态污染旧版布局。
