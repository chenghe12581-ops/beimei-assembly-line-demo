# 生产工位卡片双方案切换执行计划

## 目标

- 保留水平方案工位卡片，并统一为工位名称、已占用 / 未占用和加工零件字段。
- 新增 skew 方案工位卡片，展示同一组字段并沿工位轴测面变换。
- 在组件库工位卡片示例上方提供方案切换，切换结果同步控制生产执行工作台实际使用的卡片方案。
- 两套方案共用任务状态、工位映射和进度，不修改生产执行状态机；异常工位卡片不展示“查看视觉”入口。

## 实现方案

1. 抽取共享 `ProductionStationCard` 纯展示组件，支持 `horizontal` 与 `skew` 两种渲染方案。
2. 把生产任务状态映射为统一的工位展示模型：工位名称、状态和加工零件。
3. 新增轻量方案配置模块，通过 `localStorage` 持久化，并通过自定义事件和 `storage` 事件同步当前页面与其它标签页。
4. Component Lab 仅负责选择方案和展示状态矩阵；Production Execution 读取同一配置决定实际渲染方案。
5. 两种方案分别声明卡片高度，连接线继续根据同一工位几何锚点计算，避免切换后卡片与工位脱节。
6. 轴测工位、竖线和工位卡片的几何契约沉淀到 `docs/frontend/production-workbench-isometric-geometry.md`，后续实现以该 spec 为准。
7. 仅 skew 方案使用工位立方体右侧面投影轴的 `skewY(-25.4deg) scaleX(0.84)`；水平方案保持平面显示。两套方案都以基础尺寸内部层进行 `0.75` 视觉缩放，缩放原点为底边中点，使竖线上端始终对齐卡片底边中点。
8. 工位卡片与竖线位置统一由 `getProductionStationCardPlacement` 计算。该方法把工位立方体 `topCenter.x` 作为卡片底边中点和竖线的唯一横向锚点，再合并线长、缩放后卡片宽高和单工位 Y 偏移；后续调整立方体几何或卡片样式时不能把卡片定位和竖线起点拆开单独计算，也不能在保持竖线语义时单独横向移动卡片锚点。

## 状态映射

- 当前工序未映射到某工位：该工位为未占用。
- 当前工序映射到某工位且任务运行、暂停或异常：该工位为已占用。
- 加工零件使用当前工序 `partObject`，不使用生产任务 `name`。
- 暂停与异常仍保留琥珀色 / 红色视觉语义；异常状态不在工位卡片内展示“查看视觉”入口。
- 水平方案和 skew 方案都不展示加工进度，进度由其它生产执行状态承载。

## 验证

- 在 Component Lab 切换水平方案 / skew 方案后，生产执行工作台使用对应卡片。
- 刷新页面后保持上次选择。
- 检查未执行、运行、暂停、异常状态映射。
- 检查两套方案的长工位名称和工件名称不溢出。
- 检查卡片切换后连接线仍锚定对应工位。
- 运行 `npm run build`。
