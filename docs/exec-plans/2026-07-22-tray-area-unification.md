# 托盘装配区语义统一

## 目标

- 02-08 号托盘不再区分一次装配区和二次装配区。
- 生产工作台、托盘整体视图和托盘卡片不再展示一次 / 二次装配区文案或区域 tag。
- 保留上料区、下料区、01-09 号位、物流状态和现有几何排布。

## 实现方案

1. 将 02-08 号托盘的内部区域值统一为 `装配区`，删除按一次 / 二次装配区分配颜色和内容样式的分支。
2. 生产工作台地面只保留上料区和下料区标注；托盘整体视图只保留上料区和下料区区域 tag。
3. `TrayAllocationCard` 和新建工单托盘树移除区域文案，保留托盘编号、满盘与现场物流状态。
4. Component Lab 和生产执行 demo 数据同步使用统一装配区语义。
5. 更新生产执行、托盘管理和轴测几何规范，明确 02-08 不展示区域归属且使用中性视觉层级。

## 验证

- `rg -n '一次装配区|二次装配区' src docs/product-specs docs/domain docs/frontend`
- `npm run build`
- 检查生产监控、托盘管理、理料区 / 配盘预览和 Component Lab 的卡片分栏与平铺视图。

## 执行结果

- 源码、现行规范和新构建的 `dist` 均无一次 / 二次装配区文案残留。
- `npm run build` 通过；Vite 仅保留现有的大 chunk 提示。
