# 北煤机产能统计原型实施计划

## 目标

在北煤机统一主导航中接入独立的产能统计工作区，先实现产品经理原型中的统计交互和工单工序明细；Excel 导出库暂不在本阶段接入。

## 范围

- `/产能统计` 主导航入口和历史路由。
- 日 / 周 / 月 / 年周期切换和日期选择；当前版本不提供班次筛选。
- 生产能效指标卡片、运行/故障堆叠柱状图和稼动率折线。
- 工单搜索、状态筛选、排序、工单汇总和工件摘要表。
- 工件展开后的工序级耗时、动态贴板列、并行甘特图和加工中当前时刻线。
- 独立的本地 demo service，后续可替换为 API service。

## 非目标

- 本阶段不引入 Excel 导出依赖，也不伪造导出成功结果。
- 不复用旧 capacity-statistics 项目的焊接数据模型。
- 不把产能统计业务 JSX 继续写入 `BeimeiAssemblyLinePage.tsx`。
- 不在本阶段完成旧项目视觉风格的最终迁移。

## 文件边界

- `src/app/CapacityStatisticsPage.tsx`：页面入口。
- `src/features/capacity-statistics/`：类型、demo 数据、计算逻辑和页面组件。
- `BeimeiAssemblyLinePage.tsx`：只增加导航状态、路由映射和工作区挂载。

## 验证

1. 运行 `npm run build`。
2. 访问 `/产能统计`，检查四个周期和日期切换会更新图表与工单数据。
3. 检查工单筛选、搜索、排序和工件展开。
4. 检查双面装配的翻面/反面工序，以及单面装配的条件隐藏。
5. 检查加工中工件的甘特图当前时刻线和计划段样式。
