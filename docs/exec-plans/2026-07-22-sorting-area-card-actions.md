# 理料区托盘卡片任务操作执行计划

## Goal

移除托盘管理 AGV 调度标题栏中的「生成上料任务」，把计划托盘的上料执行入口放到理料区视图卡片序号行，并继续复用现有 AGV 执行、预约与确认到达状态迁移。

## Scope

- 托盘管理仅保留「新建任务」入口。
- 理料区计划托盘卡片序号行增加「执行」和「确认到达」。
- 首次执行时按卡片的托盘号和计划物料创建或复用上料任务；执行中只允许确认到达，完成后两个按钮均禁用。
- 执行中的 AGV 任务继续锁定取货点和卸货点，冲突时其它计划卡片的执行按钮禁用。
- Component Lab 同步托盘管理标题栏和理料区卡片动作状态。

## Non-goals

- 不改变计划配盘算法。
- 不接入真实 AGV、PLC 或仓储接口。
- 不改变 AGV 调度表中的新建、编辑、执行、确认到达和删除能力。

## Verification

1. 托盘管理 AGV 调度标题栏不再显示「生成上料任务」。
2. 理料区每张可见计划托盘卡片序号行显示「执行 / 确认到达」。
3. 点击执行后对应任务进入执行中、卸货点显示已预约，执行按钮禁用且确认到达启用。
4. 点击确认到达后任务完成，计划物料写入现场托盘状态，两个卡片按钮均禁用。
5. Component Lab 的理料区示例覆盖待执行、执行中和已完成状态。
6. 运行 `npm run build`。
