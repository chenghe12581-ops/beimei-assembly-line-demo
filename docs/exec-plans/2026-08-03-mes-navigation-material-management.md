# MES 导航与物料管理调整

## 目标

调整 MES 独立交付包的导航归属，并新增面向制造投入物料的一级“物料管理”页面。

## 范围

- [x] 生产管理首项改为“工位管理”，保留产线与工位资源内容。
- [x] 模型导入、构件列表、构件追溯归入生产管理。
- [x] “排产报工”改为“排产管理”。
- [x] 物料管理新增物料台账、工单齐套、批次与质检三个页签。
- [x] 工单管理保持物料管理之后的一级入口。
- [x] 重建独立 MES HTML、验证路由并运行项目构建。

## 目标导航

```text
生产管理
  工位管理
  模型导入
  构件列表
  排产管理
  生产执行
  构件追溯
物料管理
  物料管理
工单管理
  工单管理
```

## 验证

1. 运行独立交付包的生成脚本并进行模块语法校验。
2. 在浏览器检查导航排序、选中态、各路由页头和物料管理三个页签。
3. 运行 `npm run build`。
4. 生成新的 ZIP 交付包并检查压缩包完整性。
