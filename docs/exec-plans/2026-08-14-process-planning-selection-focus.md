# 工艺规划唯一选中与任务聚焦恢复

## Status

Completed on 2026-08-14.

## Goal

恢复样式 C 工艺规划中零件、特征、任务之间唯一主选中关系，并在工序级隔离之上恢复任务级聚焦。

## Context

- 进入工序二级页后，当前实现只保留工序级隔离，任务选中不再表达关联对象。
- 任务详情状态和主选中状态当前共用同一个 key，导致点击树对象后任务仍显示浅橙 fill。
- 历史任务聚焦通过透明度表达，不对结构树关联对象增加橙色行级高亮。

## Scope

- 工序外对象保持 `25%` 不透明度。
- 当前工序内、当前任务外对象使用 `50%` 不透明度。
- 当前任务关联零件和特征保持 `100%` 不透明度。
- 当前任务主选中使用浅橙 fill + 品牌描边；保留详情态使用任务中性表面 + 品牌描边。
- 再次点击当前任务退出任务聚焦，保留详情并回到工序级隔离。
- 点击零件或特征退出隔离，由树节点使用唯一主选中，原任务降为保留详情态。
- 同步 Component Lab、产品说明、领域规则和前端规范。

## Non-goals

- 不改变固定 16 道工序和 27 项任务定义。
- 不为任务关联对象新增结构树橙色次选中样式。
- 不改变样式 A / B / D 的任务隔离行为。
- 不改变任务参数、保存或校验逻辑。

## Steps

1. 将工序隔离集合与任务聚焦集合拆开，派生三档透明度。
2. 将任务详情 key 与任务聚焦 key分别用于详情内容和主选中视觉。
3. 恢复任务二次点击、树对象点击和“显示全部 / 隔离显示”的状态转换。
4. 同步 Component Lab 的任务主选中和保留详情变体。
5. 构建并回归工序 15 的装配、翻面压紧和焊接任务。

## Verification

- 进入工序 15 时，零件 01-04、`04 03装配基准` 和`反面焊缝 2`属于工序隔离范围。
- 首次点击装配任务后，03、04 和 `04 03装配基准` 为任务焦点；再次点击后恢复工序隔离。
- 点击焊接任务后，03、04 和反面焊缝 2 为任务焦点。
- 从任务焦点点击零件或特征后，树中只有直接对象使用主选中，关联对象使用现有次选中，任务条改为保留详情态。
- `npm run build` 通过。

以上项目均已在本地运行页面逐项验证；Component Lab 的分栏和平铺视图均已检查。

## Risks

- 3D 视窗的中性遮罩与模型透明度叠加后可能过暗，需要浏览器实测三档层级。
- 特征型任务在特征尚未生成时必须回退到工序对象范围，避免全模型被降透明度。
