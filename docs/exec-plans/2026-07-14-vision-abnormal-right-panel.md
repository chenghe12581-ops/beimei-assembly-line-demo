# 视觉异常处理右栏化

## Goal

- 将视觉异常处理从视觉视窗内浮层移到生产执行右侧栏。
- 让右侧栏的内容与工作区 tab 对齐：生产监控使用单步调试，视觉监控使用异常处理。
- 在 WP-01 第 06 个“装配”任务中连续演示两类视觉异常：桁架1视觉工件重构异常在前，焊接机器人1视觉标定在后。

## Scope

- 主页面复用现有 `VisionAbnormalCalibrationPanel` 的状态和操作回调，并新增 `GantryVisionScanPanel` 处理扫描结果、拟合设置、结果点和扫描参数设置。
- 视觉视窗移除异常处理浮层挂载，仅保留点云、相机状态栏和视窗控制。
- 右栏在视觉监控异常上下文中显示异常处理面板；其余视觉状态显示待机空态。
- 桁架1视觉的固定焊缝、P1/P2 标记和 `solver_Raffles.stl` 工具头都挂载到同一份点云坐标变换中；工具头位置和姿态由扫描参数页的两组拍照位置驱动。

## Non-goals

- 不改变焊接机器人1视觉异常的状态机、重新扫描、跳过或确定后的暂停语义。
- 本轮不扩展两阶段异常处理以外的视觉设备、后端协议或工艺规划编辑能力。

## Steps

1. 移除 `VisionMonitorView` 的异常处理浮层 props 与 JSX。
2. 依据 `activeTab` 在右栏选择单步调试或异常处理组件，保留 `task-status` 预览分支。
3. WP-01 的第 06 个装配任务先进入桁架1视觉「异常处理」；应用或跳过扫描处理后，保持同一异常工件并切换到焊接机器人1视觉标定。
4. 在桁架1视觉结果屏中回显短且加粗的固定焊缝和无底板 P1/P2 点旁文字；扫描参数屏在 P1/P2 上方回显两个焊枪朝下的工具头，并让距离、偏移、姿态、启用状态和拍照位置选中态实时驱动场景。
5. 构建并在浏览器确认生产监控和双视觉异常流程。
6. 同步组件库示例、产品规格、领域规则和组件指南。

## Verification

- 生产监控与模型视图右栏显示单步调试。
- 视觉监控发生 `WP-01` 第 06 道装配异常时，全局 Alert 的查看详情，或视觉监控状态栏中选中红色异常相机，均能进入视觉监控并让右栏显示桁架1视觉「异常处理」。
- 扫描处理应用或跳过后，右栏切换到焊接机器人1视觉异常处理；该处理确认或跳过后任务仍保持暂停，WP-01 第 06 道装配行显示黄色暂停状态灯。
- 桁架1视觉结果屏可看见加粗短焊缝、P1 / P2 圆点及点旁文字；扫描参数屏可看见两个焊枪朝下的 STL 工具头，编辑任一拍照位置的距离、偏移或姿态立即更新模型，关闭结果点或扫描点后相应模型灰显，点击拍照位置条目时对应工具头标签高亮。
- 视觉视窗不再叠加异常处理面板；重新扫描、跳过、确定和关闭保持既有行为。
- `npm run build` 通过。
