# 二次定位与工件位置结果闭环

## 目标

- 在翻面工位之外的三个工位详情中，为「二次定位/导入工件位置」提供单步执行选择弹窗。
- 将执行定位和导入工件位置统一收敛为按任务、WP、工位段落和工步隔离的视觉结果。
- 在视觉监控中回显真实点云和只读六轴工件位置，同时保持正常定位结果与视觉异常状态机分离。

## 交互规则

1. 单步模式选中目标工步并点击「执行工步」时先打开定位方式弹窗，不立即推进工步。
2. 执行定位成功后完成当前工步，弹窗保持打开并显示「查看视觉结果」；单步模式停留等待下一次操作，自动模式继续按节拍推进。
3. 导入工件位置第一次点击固定模拟失败，在当前按钮下回显失败原因；第二次点击成功、覆盖同一上下文旧结果并直接进入视觉监控。
4. 目标工步已有结果时，在工步行显示「查看工件位置」；重新执行会覆盖旧结果。
5. 当前执行模式和执行工位继续消费既有互斥锁，其他工位不能进入单步执行。
6. 结果按任务、WP、复合工位段落和工步隔离；切换上下文不串用结果。

## 实现边界

- `PositioningChoiceDialog` 只负责弹窗布局和局部交互状态。
- `VisionPositionResultPanel` 只负责视觉结果只读回显。
- `ProductionExecutionPage` 负责结果身份、覆盖、工步完成、视图跳转和 mock 时序。
- 点云继续复用 `/pointclouds/ori-pcc-in-world-sampled.bin`，不生成随机点。
- 本轮不接真实文件导入、视觉设备协议或后端持久化。

## 验证

- 主筋板打磨工位1、复合工位1、复合工位2均可触发，翻面工位不触发。
- 执行定位成功后可从弹窗和工步行进入结果页。
- 导入第一次失败、第二次成功并跳转，成功结果覆盖旧结果。
- 导入结果隐藏视觉选择栏，执行定位结果显示视觉选择栏。
- Component Lab 分栏和平铺视图包含新弹窗与结果面板示例。
- `npm run build` 通过。
