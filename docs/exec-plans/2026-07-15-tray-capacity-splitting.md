# 托盘容量拆分执行计划

## Goal

新建生产任务在加工数量大于 5 时，把同种零件拆成每批最多 5 件的独占托盘；01 可承接溢出批次，09 保持下料区禁用。配盘预览对满盘和托盘不足提供明确反馈，并保持托盘卡片区两行稳定高度。

## Scope

- `TrayManagement.tsx` 统一计算计划托盘、容量摘要、满盘卡片与区位图状态。
- `ProductionExecutionPage.tsx` 在新建任务第二步展示容量 warning，并在托盘不足时禁用确认。
- `ComponentLabPage.tsx` 增加满盘卡片变体。
- 领域、产品和前端规范记录新的配盘边界。

## Verification

1. 加工数量 5：01-04 为四个 5/5 满盘。
2. 加工数量 6：01-08 显示四种零件的 5 + 1 批次，共 8 个托盘。
3. 加工数量 11：显示托盘不足，确认不可用，09 不被配盘。
4. 少于五张卡片时卡片区仍按两行高度渲染；组件库分栏与平铺示例保持可用。
5. 运行 `npm run build`。
