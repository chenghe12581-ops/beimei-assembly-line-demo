# 生产执行任务状态监控

## 目标

右侧「任务状态监控」用于查看当前生产任务下每一个工件实例的加工状态。它不新增左侧父级任务节点，也不把加工数量拆成多条生产任务；加工数量来自新建任务时输入的数量，例如加工数量为 6，则右侧显示 6 张工件状态卡片。

## 基本事件流

1. 用户在生产执行左侧任务树中选中当前生产任务。
2. 用户点击或进入「任务状态监控」。
3. 右侧面板读取当前生产任务的加工数量和工件实例列表。
4. 每个工件实例以卡片展示当前状态、当前进度和当前流程元；未开始工件默认进一步折叠为紧凑标题行。
5. 工件卡片右侧提供折叠 caret；展开后展示该工件完整加工流程元。
6. 流程元来自「工艺流程参数设置」生成的流程列表，当前 demo 为 `0162-01-010101` 的 24 个流程元。
7. 当某个流程元异常时，异常状态落在该流程元条目上；该条目内提供「查看视觉」按钮。
8. 点击「查看视觉」进入视觉监控视图，用于查看当前工件加工过程中的主筋板、贴板等视觉信息。

## 执行顺序

- 一个生产任务只代表一批同类工件，不把 `WP-01 / WP-02 / WP-03` 拆成左侧多条任务。
- 工件实例内部编号继续使用 `WP-01 / WP-02`，但左侧分组标题、右侧详情、异常提示、日志和删除确认等所有用户可见位置统一显示为 `工件-01 / 工件-02`，不得直接回显内部编号。
- 新版左侧生产任务树（ProductionTaskTreePanel2）在选中任务下按工件实例显示可折叠 WP 分组，组标题仅保留排序生成的 `WP-01 / WP-02` 编号，不拼接工件名称；标题右侧提供删除图标，未执行且剩余多于一个工件时可操作，点击后必须确认；确认删除该工件实例后，任务级加工数量和总体进度按剩余 `workpieces` 同步更新。任务级「工件名称 / 加工数量 / 总体进度」显示为轻量吸顶信息条，工件名称行与总体进度行之间保持 12px 间距，总体进度条和百分比同排显示；未发生遮挡时概要上下 padding 为 12px，开始吸顶遮挡 WP 后恢复为 6px；信息条与其下方 divider 置于同一个 sticky 容器，遮挡层横向突破列表内容的 8px 内边距，与生产任务滚动容器等宽，并统一使用不透明 `#FFFFFF` 底色，完整遮挡向上滚动的 WP 任务；概要文字仍与 WP 列表内容对齐，divider 左右顶满遮挡层；右侧纵向滚动条从概要和 divider 下方开始，不进入吸顶遮挡区域；WP 内容开始滚动并被概要遮挡时，吸顶容器复用工艺参数设置 Header 的 `shadow-ds-sticky-overlap` 下投影，回到顶部后移除投影；WP 分组保持同宽平铺，不做父级卡片嵌套、子级缩进或左侧从属线。ProductionTaskTreePanel1 保持旧版留档结构，不承载该新版样式。
- 左侧 WP 分组标题和工序条目沿用工艺规划样式 C 的中性灰结构层级：标题使用 zinc 分组底，展开内容使用浅灰详情底，工序条目使用半透明白色任务面，不叠加行级阴影，也不单独绘制 stroke；WP 外层不再叠加独立卡片阴影或状态色外框。
- 右侧每张工件卡片都复用左侧任务的完整工序列表，展开后按 01 到末尾从上到下显示。
- 执行推进以工件实例为单位：`WP-01` 从 01 跑到最后一道工序并完成后，再启动 `WP-02` 的第 01 道工序。
- 左侧任务工序高亮、中间生产工作台和右侧任务状态监控同步指向当前正在执行的工件及其当前工序。
- 总体进度按所有工件实例进度取平均，例如 `WP-01` 完成后，`WP-02` 从 01 开始时，总体进度继续体现整批 6 件的完成度。

## Mock 异常演示

- 当前 demo 临时 mock 第 07 个流程元 `generated-assemble-02`（装配）为异常触发点。
- 为缩短演示等待时间，当首件执行推进到该流程元时，系统异步注入 `WP-06` 的第 07 流程元视觉异常，生产任务整体暂停；该事件仅用于 Demo，不改变正式的工件串行执行规则。
- `WP-06` 异常流程元条目保留「查看视觉」按钮，用于进入视觉监控；默认视觉监控只显示待机状态，不加载点云。
- 仅当 `WP-06` 保持任务异常且存在异常流程元时，视觉监控加载真实点云、六路视角和异常摘要。
- `WP-06` 异常注入后先显示全局异常 Alert；用户点击查看详情后进入视觉监控并打开异常处理浮窗。浮窗直接回显结果点、异常原因和拍照位置，拍照位置操作收敛为同一标题行；重新扫描后返回新视觉结果。跳过或确定完成本次异常处理并保持任务暂停。
- 在正式异常处理流程设计完成前，异常流程元内的「查看视觉」按钮承担临时 hack：单击进入视觉监控，双击临时解除异常；解除后 `WP-06` 恢复未开始，点云立即卸载，当前执行工件保持暂停并等待用户继续点击执行。

## 面板结构

- Header：仅显示「任务状态监控」，不显示「已完成 / 加工中」等任务级 badge。
- 空状态：未选中生产任务时显示「暂无任务」，样式复用工艺规划任务列表缺省态，使用占满内容区的虚线框、图标 + 单行文案，并将内容整体轻微上移。
- 工件状态卡片：按 `workpieces` 自上而下堆叠，外层卡片保持中性白底，只在标题旁显示聚合状态 badge；未开始卡片默认只显示工件标题、badge 状态和折叠 caret。
- 流程元明细：点击卡片 caret 后展开，按流程顺序展示全部流程元。
- 自动展开：处于进行中、暂停中或任务异常的工件卡片自动展开，确保当前流程元任务条直接可见。
- 全部收起：点击 Header 右侧「全部收起」后，临时压过进行中、暂停中、异常卡片的自动展开；当当前执行工件、当前流程元或状态变化时，再重新自动展开新的当前卡片。
- 全部完成：当前任务下所有工件均完成后，任务状态栏清空展开状态，所有工件卡片统一折叠为标题行和状态 badge。

## 工件卡片字段

- 工件序号：例如 `WP-01`。
- 工件名称：来自当前生产任务创建时的工件名称。
- 状态：未开始、进行中、暂停中、已完成、任务异常。
- 当前流程元：当前工件推进到的流程元。
- 当前进度：当前工件加工进度百分比。
- 折叠入口：caret 展开 / 收起完整流程元列表。

## 状态样式

- 外层工件卡片：不随状态整体变色，统一使用中性白底，避免右侧栏大面积跳色。
- 工件 badge：标题行右侧展示未开始、进行中、暂停中、已完成、任务异常五种聚合状态。
- 未开始：默认紧凑，只保留标题行、badge 状态和折叠 caret，不显示进度条和当前流程元说明。
- 进行中：外层卡片自动展开，橙色样式只作用于当前执行中的流程元任务条。
- 暂停中：外层卡片自动展开，琥珀色样式只作用于当前暂停中的流程元任务条。
- 已完成：外层卡片保持中性，已完成流程元任务条使用绿色完成态。
- 全部完成：整批工件全部完成后，已完成卡片也进入紧凑折叠态，不继续展示进度条和流程元明细。
- 任务异常：外层卡片自动展开，红色样式只作用于异常流程元任务条；异常条目内显示「查看视觉」按钮。

## 流程元条目

每个工件展开后显示完整流程元列表：

- 序号：按流程元顺序从 01 开始。
- 名称：流程元名称，例如抓取、放置、打磨、装配、定位焊扫描。
- 零件对象：流程元对应的 `partObject`，例如主筋板、贴板或组合件。
- 状态：未开始、进行中、暂停中、已完成、任务异常。
- 条目颜色：流程元任务条承载执行中、暂停中、异常、已完成等颜色状态，外层工件卡片不承载大面积状态色。
- 视觉入口：仅异常流程元显示「查看视觉」按钮。

## 状态聚合

工件卡片状态由该工件流程元状态聚合：

- 任一流程元异常：工件卡片为任务异常。
- 全部流程元完成：工件卡片为已完成。
- 任一流程元暂停中：工件卡片为暂停中。
- 任一流程元进行中：工件卡片为进行中。
- 其他情况：工件卡片为未开始。

当前 MVP 可用工件实例的 `state`、`progress` 和 `process` 字段模拟上述聚合结果；后续接入真实执行数据后，应改为由流程元状态列表计算。

## 总体进度

左侧生产任务栏顶部卡片在「加工数量」下方显示总体进度。总体进度代表当前生产任务下所有工件实例的整体加工完成度，不代表单个工件状态。
