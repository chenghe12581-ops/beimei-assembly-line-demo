# 工艺规划 Product Spec

## Goal

工艺规划页面用于从装配体结构、特征提取结果和工艺参数配置中生成可编辑的任务列表，并在 3D 视窗中回显路径、点位、支撑、压紧等 demo 状态。

## Users

- 工艺规划工程师
- 产线调试人员
- Demo 演示人员

## Main Areas

- 左侧结构树：项目、装配体、零件、焊接特征、打磨特征、装配基准特征。
- 中间 3D 视窗：模型、特征、路径点位、日志。
- 右侧规划区：样式 C 展示固定工序和工序内任务；样式 A / B / D 保留平铺任务列表。
- 工艺参数设置弹窗：抓取、工作台、打磨、装配定位、定位焊参数。
- 组件库：用于管理组件样式和交互变体。

3D 视窗首次显示装配体时，默认从模型上方向下约 45° 观察，并保留约 25° 水平环绕角，使工件长轴在画面中形成左低右高的清晰斜向，并表达板厚与层级。默认取景应比通用自动适配更紧凑；切换装配体后重新应用，用户手动操作相机后不自动回正。

工艺规划前端工程按功能浮窗拆分：3D 视窗工具浮窗分别实现坐标转换、手动焊缝/打磨、装配基准和任务级磁铁参数；全屏弹窗分别实现工艺参数设置和新增任务。页面组件只编排状态与领域回调，浮窗组件不直接读写项目树或 3D 场景。

样式 C 是持续演进的主产品方案。其右侧信息架构改为两级：一级“工序规划”固定展示装配体解析得到的 16 道工序；点击工序后进入二级“任务列表”，使用单列长条任务展示并复用现有参数、结果点位和路径点位配置。进入工艺规划时工序已经解析完成，但不生成任务；用户一键生成成功后才创建完整路线的 27 项固定任务。样式 A / B / D 保持当前平铺任务方案。

样式 C 的一级工序条目使用 V2 工序卡片：卡片左右内边距使用 `14px`，收拢双端信息的视觉重心。序号与工序名称位于左上同一行并垂直居中，序号使用 `12px`，工序名称使用 `14px`，名称后不追加静态任务摘要；首次一键生成前不显示任务 Tag，生成成功后任务 Tag 紧凑排列在右上角，文字使用 `11px`。中文任务名使用独立文字层和 `1px` 下内边距校正基线，Tag 内边距为左 `6px`、右 `8px`，避免文字贴近卡片右缘；工件 / 组合对象与所属工位放在同一底行，文字均使用 `12px`，且顶行与底行之间使用 `12px` 间距。底行中的每个语义对象分组渲染为独立浅灰 Tag block，使用 `4px` 圆角和 Zinc 500 文字，不在 block 之间显示 `+`；例如第 12 道显示 `...-03` 和 `...-(02+01)` 两个 block。卡片不显示 `0/2` 之类任务计数，用户直接通过 Tag 判断状态；工序规划栏也不显示“装配体编号 / 16 道工序”摘要行。序号在卡片 hover 或键盘聚焦时替换为 checkbox；checkbox 勾选仅维护工序批量导出集合，不进入工序、不触发隔离，也不为卡片增加 fill、stroke 或其它条目选中态。勾选可多选且在返回工序总览后保留；未勾选时工具栏显示“导出全部”并导出全部 16 道工序，勾选 `n` 道后显示“导出(n)”并仅导出这些工序及其当前任务、顺序、禁用状态和参数。导出入口固定为原有 `70px` 宽度，文案切换不改变工具栏结构。任务 Tag 名称前使用状态标识：绿色实心圆表示已生成且合法、品牌橙色实心圆表示有未保存修改、红色三角感叹号表示参数校验失败。状态灯只允许出现在一级工序卡片的任务 Tag 中，不进入二级任务条。工序不可新增、删除或拖拽；二级页面的筛选、禁用、删除和排序均限定在当前工序内。

样式 C 二级任务页的任务列表与下方详情区域之间保留水平拖拽分隔条。首次进入时任务列表高度按当前任务数量自适应；用户拖拽后以调整后的高度为准，并将任务列表高度限制在 `72px - 260px`，详情区域占用剩余高度。

样式 C 进入工序后的右侧标题栏统一使用“二位序号 + 空格 + 工序名称”格式，例如 `01 上料`、`16 组合装配`；不显示“第”“道”或中点分隔符。

组合对象使用语义分组写法：第 06 道为 `...-02 + ...-01`；第 07 / 08 道为 `...-(02+01)`；第 12 道为 `...-03 + ...-(02+01)`；第 15 道为 `...-04 + ...-(03+02+01)`；第 16 道为 `...-(04+03+02+01)`。

当前原型提供样式 C Demo shortcut：在工序总览双击标题文字“工序规划”，自动补齐所需特征并将完整 27 项任务配置到固定 16 道工序。已有同 ID 任务优先保留其工艺参数、结果点位和路径点位配置；第 08 道新增的装配体上料任务和其它新任务使用对应任务类型的完整 demo 参数与点位模板。该快捷入口只用于演示，不替代正常的工序内手动新增流程。

## Main Flow

1. 用户进入项目管理。
2. 用户选择装配体并进入工艺规划。
3. 用户在 3D 视窗中通过自动或手动入口提取焊缝、打磨线、装配基准特征。
4. 样式 C 固定展示解析得到的 16 道工序，用户选择目标工序进入任务列表。
5. 用户进入任一工序后，首次生成前看到“暂无任务”；一键生成成功后直接看到系统生成的固定任务条，进入工序时不自动选中第一项任务。
6. 用户选择具体任务后配置参数、结果点位和路径点位；未选择任务时，下方详情区域显示“请选择任务查看和配置参数”的缺省提示。
7. 3D 视窗展示对应回显遮罩或 demo 点位。
8. 用户调整点位、关节角、阈值等参数后，任务名称右侧显示橙色 `*`，工序卡片中的对应 Tag 变为橙色，任务条尾部才出现“保存”。参数校验失败时对应 Tag 显示红色三角感叹号并禁用保存。
9. 用户点击任务条“保存”后，该任务清除任务级 `*` 并恢复绿色 Tag；工艺规划项目继续保持未保存，直到用户点击顶部项目级“保存”。顶部项目保存不会批量清除橙色任务状态。

样式 A / B / D 保留原流程：检查前置特征后可一键生成 24 条平铺任务，也可使用原平铺新增入口。

抓取任务以工序 feature 记录抓具、左中右磁铁启用状态、左/右磁铁 Z 值、磁力档位和电磁铁位置。中磁铁 Z 固定回显 `--`，不允许用户输入修改。修改左中右磁铁启用状态、左/右磁铁 Z 值或磁力档位后，覆盖率、安全系数、偏心距和电磁铁位置必须实时刷新，并让当前装配体进入未保存状态；当前抓取工艺参数区暂不展示电磁铁位置区域。抓取参数校验区不再提供 `应用更改` 按钮。

任务条目展开状态允许多个卡片同时展开；样式 A/B 的任务列表 heading 中，“收起全部”图标按钮只负责将已展开卡片全部合上。样式 C 路径点位工具栏提供同一位置的全部收起 / 全部展开 toggle：收起态显示 `ChevronsUp`，再次点击后展开全部路径点位并显示 `ChevronsDown`。

样式 C 的工序内任务列表 heading 在“删除”按钮左侧提供“筛选”和“禁用”入口。点击筛选后在 3D 视窗范围内靠右打开玻璃浮窗，浮窗避让右侧任务列表面板；浮窗 heading 不显示副标题。筛选方式支持多选，选项文案为：零件名称、任务类型、焊缝特征、打磨特征、装配特征；筛选方式选框下方使用无文字 divider；下方筛选条件选框随已选筛选方式动态增删，并且各条件选框也支持多选，其中焊缝、打磨、装配特征分别使用独立条件选框，同一条件内任一选中值命中即可保留任务，多个条件之间同时生效以筛选当前工序的长任务条目。

样式 C 的工序内任务列表 heading 中，新增任务使用 icon + 文字按钮；筛选使用常驻的仅 icon 按钮，禁用和删除使用仅 icon 按钮但只在进入批量操作后显示，hover 时通过 tooltip 显示功能文案。禁用按钮位于删除按钮左侧，用于将当前选中的长任务条目切换为禁用样式，再次点击解除禁用。筛选按钮左侧提供“批量操作”文字按钮，点击后右侧任务条目进入批量模式，左侧标号切换为 checkbox 变体，并在“批量操作”左侧显示“全选”文字按钮；点击“全选”仅勾选当前筛选后可见且可操作的任务条目。再次点击“批量操作”退出批量模式并清空当前批量勾选，同时隐藏禁用和删除按钮。

点击样式 C 的工序卡片后，左侧结构树和 3D 视窗立即按整道工序的固定 `workpieceIds` 与工序内任务特征进入工序隔离；进入时清空结构树既有选中态，工序关联对象保持 100% 不透明，工序外对象降至 25%。点击任务后，在工序隔离之上进入任务聚焦：当前任务关联零件和特征保持 100%，同工序但不属于当前任务的对象降至 50%，工序外对象继续保持 25%；任务关联仅通过透明度和视窗轮廓表达，不给结构树行叠加橙色次选中样式。当前任务使用浅橙 fill + 品牌描边的主选中态；再次点击当前任务退出任务聚焦并回到工序隔离，任务详情继续显示，任务条改为中性任务表面 + 品牌描边、无浅橙 fill 的保留详情态。工序对象只在 3D 视窗左上角集中显示为“当前工序对象”及多个对象 block，不进入结构树或任务面板；对象 block 复用卡片第二行的对象分组格式，例如第 12 道显示 `...-03` 和 `...-(02+01)` 两个 block。该浮层复用生产执行模型属性浮窗的低填充玻璃背景：`bg-white/25`、内嵌白色弱边线和 `backdrop-blur-xl`，对象 block 使用更低的 `bg-white/16`，不使用实白底或投影。隔离目标零件保留原材质，并复用普通选中态的 `#F59E0B / opacity 0.9 / 1.2px` 轮廓；隔离背景零件改用中性低饱和材质，并叠加低透明度 Slate 灰遮罩和低对比轮廓；隔离模式不叠加普通选中的黄色遮罩。普通结构树零件选中时，选中零件使用 `#FACC15 / opacity 0.58` 黄色遮罩，其它零件叠加 `#475569 / opacity 0.58` Slate 灰遮罩；关联特征继续使用现有次选中样式。点击结构树对象或“显示全部”退出工序/任务隔离，树对象成为零件、特征、任务三者中唯一主选中对象，仍在右侧显示详情的任务降为保留详情态；同一位置切换为“隔离显示”，点击后重新进入当前工序隔离但不自动恢复任务聚焦。返回工序列表或切换其他工序时，旧工序的隔离、任务聚焦和对象回显一并清理。

样式 C 的长任务详情区域不展示工件模型/特征选择控件，也不展示生成位置/生成路径按钮。手动新增任务入口位于当前工序二级页：点击“新增任务”后弹窗内先选择任务类型，工件对象固定继承当前工序并以只读字段回显，不使用零件下拉选择。打磨任务仍配置打磨线并支持多选；合并焊接选择一个焊缝，并在同一任务内生成扫描和焊接两套结果；装配选择装配基准特征并支持多选；抓取、放置、翻面压紧直接使用只读工件对象。确认新增后，当前 demo 直接生成对应位置、路径或结果点位，使任务详情只保留参数、结果点位和路径点位编辑。打磨任务的工艺参数详情不展示打磨偏移 ΔX / ΔY / ΔZ 输入；该偏移只保留在工艺参数设置弹窗中。样式 A / B / D 继续保留独立的定位焊扫描和定位焊任务。

样式 C 长任务条尾部操作常驻显示，不依赖 hover。任务条不重复显示作用零件名称，作用对象统一由工序卡片第二行和视窗左上角对象回显承担。顺序固定为条件显示的文字按钮“保存”、禁用 icon、删除 icon；无未保存修改时不显示“保存”文字，但为避免其余操作图标位移保留同宽空位。禁用和删除 icon 直接贴在任务条尾部，不使用 fill、stroke、阴影或悬浮包裹层。任务有未保存修改时显示橙色可用“保存”按钮并在名称右侧显示橙色 `*`；参数校验失败时显示红色三角感叹号并禁用保存。点击任务保存只清除当前任务的局部脏状态，不清除项目级未保存状态。仅查看任务或返回工序总览不得改变任务状态。

样式 C 合并焊接任务的工艺参数详情使用“扫描参数 / 焊接参数”小标题分区，所有已暴露字段都可编辑。路径点位详情不再使用顶部“扫描点位 / 焊接点位”分段，改为焊缝段网格（一行三个）：点击选中某焊缝段后，在「扫描路径 / 焊接路径 / 压紧配置」三个视图间切换，两侧路径点位均按 6 组焊缝段维护，压紧配置按段设置启用与否。坐标系 radio 已移除，坐标固定按“世界”处理。段详情标题行右侧为全部展开/收起图标；“安全点配置”浮窗在样式 C 已移除（仅样式 A / B / D 保留）。

样式 C 合并焊接任务条目提供“进入虚拟仿真”入口。入口允许使用尚未保存的工艺规划内存状态，跳转时携带当前装配体、固定工序和焊接任务上下文；从虚拟仿真返回后必须恢复当前工序和任务详情。加工程序在虚拟仿真中独立生成和保存，不清除或替代工艺规划的未保存状态。

项目管理列表中的项目条目尾部提供导出入口。当前 demo 不生成真实文件：同一项目第一次点击导出显示失败 toast，第二次点击显示成功 toast，用于演示导出异常与成功反馈。

C 样式项目条目尾部的“新增装配体”入口使用图纸管理弹窗的新建变体。点击后真实系统应先弹出本地文件夹选择器；当前 demo 用 2 秒居中圆角灰框示意“本地选择文件夹”，灰框消失后再打开弹窗。弹窗标题为“创建模型”，内容复用图纸管理列表和预览，初始显示装配图纸缺失，零件图纸分区不展示任何零件图纸条目。弹窗左侧顶部保留“导入文件夹”；“装配图纸”和“零件图纸”副标题右侧分别提供“导入”入口，用于区分装配图纸/零件图纸导入来源。用户点击“装配图纸”标题右侧的“导入”后，demo 切换为装配图纸已导入、零件图纸部分缺失的创建模型内容版本；存在任意图纸缺失时右下角“确认解析”置灰。用户关闭弹窗后，再次从同一入口打开时保留当前图纸存在状态。用户对第三个零件图纸单独针对性替换导入时，demo 显示失败 toast“图纸解析不成功，导入失败”，并保留该零件图纸缺失状态；用户继续点击零件图纸导入、零件行导入或导入文件夹后，demo 切换为无缺失状态。确认解析后弹窗关闭，并在该项目下一层级新增一个 demo 装配体及其 4 个零件模型。

C 方案信息架构中，主导航隐藏“项目管理”tab，项目管理保留为进入工艺规划前后的工作区状态，不作为顶部主导航项展示。工艺规划 tab 通过下拉菜单列出已打开的装配体工艺规划；主导航“工艺规划”tab 本身不显示脏状态 `*`。当前装配体存在未保存的特征提取、点位、磁铁或工艺参数更改时，只在页面面包屑装配体名称后和对应装配体下拉菜单项后显示橙红色 `*`，装配体名称保持原文字颜色。点击返回项目管理时，如果当前装配体存在未保存工艺规划更改，应弹窗提示“当前未保存，可稍后在顶部工艺规划下拉任务中继续编辑”，弹窗只保留一个“确认”按钮；确认后返回项目管理但保留该装配体的未保存状态和下拉任务。菜单项尾部提供关闭 `X`，关闭存在未保存更改的当前工艺规划时必须弹窗拦截，并提示关闭将丢弃所有未保存的工艺规划更改；用户确认丢弃后关闭该工艺规划任务并清除对应未保存状态。工艺规划页顶部在“工艺参数设置”右侧提供“保存”和“导出”入口，保存用于清除当前 demo 脏状态，导出沿用项目包导出反馈；有未保存更改时，保存按钮的 icon 和文字用品牌橙色亮起。

特征提取属于工艺规划脏状态来源。自动提取焊缝、自动提取打磨、手动创建焊缝、手动创建打磨线、手动或批量创建装配基准后，当前装配体进入未保存状态；点击“保存”后清除该状态。

D 方案用于项目管理页的视窗化布局：顶部工具栏提供“新建项目”和“导入项目”入口，左侧项目结构和右侧属性参数均以悬浮层形式贴在内容区上方；“图纸管理”仍保留在属性参数标题右侧，不挪入顶部工具栏。工艺规划页中，样式 D 保留原样式 C 工艺规划的圆角玻璃面板作为左侧零件结构和右侧任务列表外壳；样式 C 工艺规划改为与样式 C 项目管理一致的无圆角直角侧栏外壳，并保留半透明白色 fill。

C/D 方案工艺规划顶部工具栏中，“焊缝提取”左侧保留“模型坐标系转换”入口，并通过 divider 与特征提取入口分组。点击“坐标转换”后在 3D 视窗内打开模型坐标系转换浮窗，用于选择零件、查看 bounding box / XYZ pivot、重选中心，并对 pivot 应用 XYZ / RPY 偏移。

## One-click Process Generation (Styles A / B / C / D)

样式 A / B / C / D 均显示一键生成入口。样式 C 仍使用固定工序总览承接生成后的任务；工序总览标题的双击填充完整工序任务 Demo shortcut 保持不变。

成功生成前必须存在：

- 打磨特征
- 焊缝特征
- 装配基准特征

缺少任一类特征时：

- 首次点击不生成任务，Toast 提示缺少哪些特征
- 同一项目再次点击“一键生成任务”时，作为 demo 加速入口自动补齐缺失的焊缝、打磨和装配基准特征，再生成完整任务列表
- 自动补齐必须写入结构树特征节点和任务配置的 featureIds，不允许只生成空特征任务

成功时：

- 生成完整任务列表
- Toast 提示已一键生成完整任务列表，或提示已自动补齐特征并生成完整任务列表

## Feature Extraction Entry Points

特征提取入口统一放在 3D 视窗内，不放在页面面包屑或全局 heading 中。3D 视窗顶部显示一排特征提取工具，焊缝和打磨入口各自使用下拉菜单，装配入口保持独立按钮：

- `焊缝特征提取`：下拉菜单包含 `自动提取` 和 `手动提取`。`自动提取` 执行原焊缝自动提取逻辑并生成焊缝特征；`手动提取` 打开手动焊缝特征提取浮窗，用户先选择两个相接零件，再点击 `选择面` 进入面选择状态，3D 视窗应显示所选零件 A/B，并把这些零件的面拆成可点击的半透明面片；用户在 3D 视窗内逐个点击面完成选择，按住 Ctrl 或 Command 点击已选面可取消选择。点击 `生成焊缝` 后，系统根据所选面计算交线候选；若所选面不相交则 Toast 提示 `生成失败，所选的面不相交`，若生成成功则 Toast 提示 `生成成功` 并在 3D 视窗显示可点击的焊缝段候选；用户点选焊缝段后点击确定，在结构树中创建焊缝特征对象。点击 `生成焊缝` 之前，以及生成后尚未点选焊缝段时，确定按钮必须保持置灰不可用。
- Demo 快捷路径：连续两次点击 `焊缝特征提取 / 手动提取` 时，直接创建 `01-02 手动焊缝`，挂载到 02 零件下，使用 `front-intersection.obj` 并关联 01/02 两个零件。
- `打磨特征提取`：下拉菜单包含 `自动提取` 和 `手动提取`。若当前装配体尚未创建焊缝特征，自动/手动打磨入口均不打开创建流程，Toast 提示 `请先创建焊缝特征`；焊缝特征已存在后，`自动提取` 执行原打磨自动提取逻辑并生成打磨线特征，`手动提取` 打开手动打磨特征提取浮窗。浮窗顶部先选择焊缝特征，3D 视窗高亮该焊缝并弱高亮关联零件，浮窗内回显所选焊缝；分割线下方指配相接的零件 A/B。点击确定后创建两个打磨特征对象，分别挂载到零件 A 和零件 B 下，且各自只关联对应零件。
- `装配特征提取`：打开原有装配基准提取弹窗，零件 A/B 在该浮窗中分别命名为子板/父板。子板和父板选择器必须上下排列并占满浮窗宽度，避免长零件名称被并排布局截断。用户先选择相接的子板和父板，再按步骤设置装配基准 1 和装配基准 2：先点选子板基准 1 并设为子板基准 1，再点选父板基准 1 并设为父板基准 1；随后同样依次设置子板基准 2、父板基准 2。后续步骤在前置步骤完成前置灰，当前步骤使用橙色强调；“装配基准 1/2”分组标题不显示额外数字 badge，四个基准均完成后 footer 的 `确定` 才可用。

装配基准特征也必须在焊缝特征已存在后才能创建；若用户在尚未创建焊缝特征时点击装配入口或尝试创建装配基准，demo 使用 Toast 提示 `请先创建焊缝特征` 并阻止打开/确认创建。

焊缝/打磨的手动提取入口已经在 3D 视窗工具栏中拆分。对应浮窗标题分别为“焊缝特征提取”和“打磨特征提取”，在 C/D 工艺规划布局中出现在左侧零件结构面板右边，宽度与装配基准提取统一为紧凑面板。浮窗 header 支持最小化为条状态，使用与装配基准提取一致的最小化/关闭图标。浮窗不再提供内部 tab 切换，也不重复展示“焊缝特征/打磨特征”“手动点选模式”和点选说明文案。焊缝浮窗保留上下排列的相接零件选择，并在零件 A/B 下方提供 `选择面` 和 `生成焊缝` 两个操作按钮；点击 `选择面` 后用户在 3D 视窗内逐个点选面，点击 `生成焊缝` 进行相交校验并显示成功/失败 Toast；生成成功后视窗显示多个焊缝段，候选状态行提示用户点选焊缝段后点击确定创建焊缝特征；点击 `生成焊缝` 前或未点选焊缝段时，footer 中的 `确定` 置灰不可用。打磨浮窗顶部为焊缝特征单选控件，选中后在 3D 视窗高亮焊缝并弱高亮关联零件，控件下方状态行回显所选焊缝；随后使用分割线区分焊缝选择和零件指配区域，分割线下方保留零件 A/B 单选控件。候选状态行未满足条件时提示选择焊缝并指配零件，满足条件时提示将创建零件 A/B 两条打磨特征；footer 中的 `确定` 在未选择焊缝、未指配两个相接零件时置灰。焊缝/打磨 footer 必须与装配基准提取一致，使用 `border-t + px-3 py-2` 的独立底栏，零件不相接提示与清空/确定放在同一 footer 行，避免额外错误提示块撑高面板。坐标转换、手动焊缝、手动打磨和装配特征提取均属于会接管 3D 视窗点选/高亮行为的工具浮窗，同一时间只能打开一个；打开任一新浮窗时必须关闭并清理其它 3D 工具浮窗的临时选择、候选和吸附点状态。装配基准提取内部不再显示蓝底点选引导提示，装配基准状态和“设为子板/父板基准”按钮只共用一层灰底或步骤容器，不再给“未选特征”状态自身叠加灰底。装配基准 footer 的次要按钮文案为“清空”，用于清除当前零件、特征和错误状态，不关闭浮窗。

焊缝、打磨、装配特征提取里的零件 A/B 都是单选语义，使用项目对象单选下拉，不使用浏览器原生 `<select>`；任务配置里的工件模型和特征对象仍保留多选语义。

焊缝手动提取的长期交互为：选择两个相接零件、点选模型面、生成焊缝段候选、确认写入左侧特征树。打磨手动提取的长期交互为：选择已有焊缝特征、指配相接零件 A/B、确认后分别为两个零件创建打磨特征。当前 demo 的焊缝面/线点选使用 3D 视窗中的可点击几何表达，打磨创建复用焊缝特征与关联零件高亮表达。

## Coordinate Transform

模型坐标系转换是 3D 视窗工具栏中的辅助操作：

- 浮窗内容包括零件多选下拉、重选中心操作、XYZ / RPY 偏移输入和 footer 的 `应用` / `取消`。
- 零件多选下拉菜单必须提供“全选零件”入口。
- 重选中心操作位于零件多选下方的 divider 后、操作轴偏移输入上方，label 为 `重选中心`，只包含整行 primary `设为中心` 按钮；该区域不使用独立描边容器，也不提供单独的中心目标零件选择或 `吸附选点` 按钮。
- “选择零件”多选结果就是重选中心的目标零件。选择零件后，3D 视窗立即渲染这些零件各自的 bounding box 和可点击吸附点：每个零件 8 个角点、体中心点、6 个面中心点，并支持在所选零件表面直接点选面上中心点。
- 用户在视窗内点选新的中心候选点后，`设为中心` 按钮启用；未点选新的中心点时该按钮置灰。点击 `设为中心` 后将 pivot 轴移动到所选点。
- pivot 回显使用类似 Rhino Gumball 的纯可视化操作轴：三向平移箭头和三色旋转环均可见，但当前 demo 不实现拖动或旋转交互。gumball 视觉尺寸固定为 01 零件选中时的大小，不随当前选择零件尺寸缩放；多选零件时只显示一个 gumball，位置为所选零件 bounding box 并集的体积中心。
- 选择零件后，3D 视窗显示所选零件 bounding box 和质心 XYZ pivot；设置中心后显示所选吸附点位置的 XYZ pivot。
- 点击 `应用` 后 Toast 提示 `对[零件对象名称]应用了坐标转换`；未选择零件时提示先选择零件对象。
- 点击 `取消` 关闭浮窗并清空本次选择和偏移输入。
