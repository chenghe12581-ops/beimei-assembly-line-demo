# 产能统计工作区

## 页面入口

- 北煤机主导航固定提供“产能统计”，路径为 `/产能统计`。
- 页面复用北煤机统一主导航，不创建第二套产品级导航。
- 页面内部提供“生产数据”和“工单数据”两个分页。

## 生产数据

- 支持日、周、月、年四种统计周期。
- 支持日期筛选；班次筛选暂不提供。
- 顶部显示开机时长、运行时长、待机时长、故障时长、稼动率和产量。
- 图表按周期聚合运行时长与故障时长，使用堆叠柱状图；稼动率使用右轴折线。
- 待机时长只在指标卡片中展示。

## 工单数据

- 左侧展示工单列表，支持按工单编号/工件代号搜索、状态筛选、开始时间排序和完成数量排序。
- 右侧展示选中工单的计划数量、完成数量、加工中数量、开始/结束时间、工单状态和总加工时长。
- 工件摘要固定展示工件代号、开始/结束时间、贴板配置、故障等待、总加工时长和加工状态。
- 点击工件后展开工序分组和并行甘特图。
- 正面、反面贴板按实际数量动态生成；单面装配不展示翻面和反面工序。
- 总加工时长按并行工序的关键路径计算。
