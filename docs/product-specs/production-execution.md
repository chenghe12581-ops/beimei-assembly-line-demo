# 生产执行 Product Spec

## Goal

生产执行页面用于把工艺规划产出的工件、工序和配盘需求转化为可排单的生产工单，并提供任务控制、状态监控、视觉监控、设备状态和托盘 / AGV 调度的 MVP 闭环。

## Users

- 生产人员
- 产线调试人员
- Demo 演示人员

## Main Areas

- 视窗悬浮控制组：生产监控 / 模型视图 / 视觉监控以窗页 tab 样式切换；初始化、执行 / 暂停、停止三个执行按钮包在同一个浮动容器内；托盘管理作为单独悬浮入口，点击后切换为生产执行工作区内的完整托盘管理页面，并提供进入理料区视图的入口。
- 底部生产执行 footer：设备状态灯，按 PLC、机器人、相机等设备逐项展示红 / 灰 / 绿状态。
- 左侧任务树：现有任务概要升级为工单概要，按排单顺序展示已下发生产的工单；概要显示折叠 caret、自动生成的工单号、状态和展开后的总体进度，不显示排单序号、装配体图号、件数或独立拖动抓手。列表不承担理料确认，不显示「待理料 / 已理料」下拉。工单展开后直接显示原 WP 与工序子节点，不增加中间任务卡片。面板外壳继续复用工艺规划样式 C 的直角半透明侧栏、zinc 边线和 36px 标题栏；新建工单入口始终可用。新样式工序行默认在 checkbox 位置左对齐显示序号，hover / focus 不切换为 checkbox，也不显示行尾禁用 toggle，只有显式进入批量选择模式时显示居中 checkbox。
- 左侧生产任务和右侧单步调试 Header 复用工艺规划「零件结构 / 任务列表」的标题契约：`12px / 500 / text-ds-text-control`。任务概要进度轨道使用组件库 zinc token `bg-ds-bg-slider-track`；WP 分组标题使用半透明 zinc-100 结构面，hover 使用可感知的 zinc-200 层级；WP 分组之间不绘制顶部 divider；WP 分组内容使用 `min-w-0 / max-w-full` 约束，工序条目保留轻量任务面但不绘制逐条 stroke。
- 中间 3D 产线 / 模型回显：生产工作台、模型视图和视觉监控统一使用与工艺规划一致的中性灰视窗底色 `color.bg.viewport / #E4E4E4`；产线视图展示上料、打磨、装配、焊接、翻面、下料等工位示意，并根据当前任务状态高亮；生产工作台采用灰底等轴测产线示意，工位以 6 个同尺寸扁立方体表达相对位置，沿与 AGV 托盘平行的轴测线从右到左依次为主筋板打磨工位1、主筋板装配工位1、贴板打磨工位1、翻面工位、贴板打磨工位2、主筋板装配工位2；工位卡片竖线垂直锚定在对应立方体上表面中心，磨砂标签和垂直指示线标注工位，未执行工位卡片使用约 68% 白色透明背景并折叠为标题 + 状态行，下方以浅灰灰度立方体展示 01-09 AGV 托盘位置且不显示蓝色参考线，编号从右往左依次为 01 到 09，AGV 按 09 / 08-05 / 04-02 / 01 分组排布，组内托盘距离更近，组间及首尾大托盘到相邻小托盘距离更大，01 和 09 托盘俯视面积为其它托盘的 4 倍，端部大托盘按左下侧面（厂房正面）与其它托盘对齐，托盘排列方向与工位线在轴测投影中保持平行；每个托盘立方体上表面中心长出垂直竖线并连接轴测托盘卡片，卡片展示托盘标号、现场状态和载荷摘要，已占用时显示零件或成品名称及数量，已预约时显示等待 AGV 入站，空托时显示空料框；托盘卡片不显示区域归属，地面仅按轴测方向标注 01 上料区和 09 下料区，02-08 统一作为装配托盘位且不显示区域名称或区域 tag；运行中工位使用半透明蓝色遮罩和淡蓝棱线表达状态，并通过工位卡片展示当前加工零件；模型视图展示当前工件零件，并复用工艺规划工序隔离回显逻辑。
- 模型视图结构树：仅在模型视图内显示，作为中间视窗左侧悬浮面板展示当前工件零件层级，不替换左侧生产任务栏。装配体行使用无阴影的冷灰填充；零件行仅显示零件编号，保留轻量 fill，并提供 hover 与选中态。结构树下方同列展示只读“属性参数”浮层：装配体的 4 个零件均以纵向卡片呈现，复用工艺规划的名称、材质、重量、厚度字段；卡片标题沿用结构树 fill 与关联高亮语义，可逐张折叠，点选树节点后自动展开对应卡片；收起属性参数时整个面板只保留标题条。字段区独立滚动，整组不覆盖顶部控制条或底部打印日志。
- 右侧单步调试：右侧栏显示单步调试面板，宽度统一沿用工艺规划任务列表的 420px；面板不显示独立的六工位按钮，用户点击中间生产工作台的现有工位卡片选择工位；选中工位后回显当前工序任务、加工零件名称、加工数量和当前 WP；主筋板装配工位1/贴板打磨工位1/主筋板装配工位2/贴板打磨工位2 四个物理工位卡片保留，但点击其中任意一个都打开对应复合工位详情；TaskStatusMonitorPanel 代码保留但不在生产执行主页面挂载显示。
- 单步调试面板顶部固定提供「自动 / 单步 / 手动」分段执行模式，便于在面板内容滚动时持续切换；自动模式按工位执行单元自动推进：同一工位或复合工位内，先按聚合工步顺序执行完当前工位的全部工步，再切换到任务中的下一个工位，不把整张工单的 process 列表作为唯一推进边界。从工位详情启动「自动执行」时，起点对齐到当前查看工位的工步段落起点（复合工位取该工位在任务工序链中的首个启用工序），相当于从本工位开始的连续工步执行，不从整张工单首道工序开始；当前查看工位没有该任务的启用工序时「自动执行」置灰并提示「当前工位没有可执行的工序」；已暂停任务点「继续」仍从当前工步续跑；任务级从工单头开始执行的入口保留在主控制条。单步模式提供「初始化」和「执行工步」按钮，工位工步可逐项选中后执行。点击「执行工步」后同一按钮切换为可点击的「暂停」，工步进入执行态；点击「暂停」后任务与工件保持在当前工步，按钮恢复为「执行工步」。执行期间仍允许切换查看三种模式，但只有当前执行模式、当前执行工位保留可操作的暂停按钮；其它模式的执行 / 初始化按钮和其它工位的执行按钮置灰。主生产任务处于加工中时，工位详情中的手动设备按钮全部置灰，hover 提示「请先停止生产任务」。空闲工位仍允许选中其演示工步并触发、暂停单步演示；复合工位的单步执行允许打断自动顺序并把当前 WP 跳转到选中工步（可跨工序段落），进入同一执行 / 暂停闭环；手动模式只展示当前所选工位或托盘工位的设备控制，不再显示「手动执行当前工位工步 / 与左侧工件工序同步」操作块，也不通过手动设备命令推进 WP 工步。
- 翻面工位之外的主筋板打磨工位1、复合工位1和复合工位2，在单步模式选中「二次定位/导入工件位置」并点击「执行工步」时打开定位方式弹窗。弹窗左右提供「执行定位」和「导入工件位置」：执行定位成功后完成当前工步、保持弹窗并显示「查看视觉结果」；导入第一次点击模拟失败并在当前栏提示，第二次成功、覆盖旧结果并直接进入视觉监控。单步模式完成后不自动推进，自动模式获得结果后继续推进。只要该工步已有结果，工步行始终显示「查看工件位置」。
- 生产工作台 01-09 托盘卡片与工位卡片一样可点击进入右侧「工位详情」；点击卡片只切换详情对象，不自动切换执行模式，不为工位卡片或托盘卡片新增持久选中描边。已占用托盘内的铅笔编辑入口保留独立交互。
- 机器人、打磨头、三轴、支撑装置、压紧装置和 AGV 调度控制只在右侧「工位详情 -> 手动」模式中显示。复合工位手动模式在面板顶部用 tab 在两个物理工位间切换：装配 tab 显示焊接机器人、支撑装置和压紧装置控制，打磨 tab 显示三轴控制和打磨头；设备回显状态按物理工位隔离，切换 tab 不互相影响。新增控制按钮统一为矩形、透明背景、灰色 stroke 的硬件控制按钮，不使用品牌色填充。点击命令按钮后按钮闪烁，直到当次命令执行完成；J 轴点动按钮在按住期间闪烁，松开即停止。
- J 轴点动统一使用「J 编号 / 正向点动按钮 / 只读位置回显 / 负向点动按钮」组件；按下开始点动，松开停止。三轴工位额外提供「回原位」。
- 工步回显规则按显式工位模板展开，其中四个物理工位合并为两个复合执行单元展示：复合工位1 = 主筋板装配工位1 + 贴板打磨工位1，复合工位2 = 主筋板装配工位2 + 贴板打磨工位2；自动和单步模式下工位详情标题统一显示加号相连的复合名称（如「主筋板装配工位1 + 贴板打磨工位1」）。复合工步列表按工序段落顺序拼接，当前工步高亮 = 活动工序所在段落起点 + 段内工步索引：复合工位1 依次为上料段「支撑调整、主筋板抓取、主筋板放置」（3 步）、打磨段「贴板【0162-01-010101-02】粗定位、抓取、侧面打磨、正面打磨、放置、精定位/导入工件位置、二次调整」（7 步）、装配段「贴板【0162-01-010101-02】焊接」（压紧、定位扫描、定位焊接等设备级动作合并展示为单步），共 11 步；复合工位2 结构相同，依次为 03 零件的上料段、打磨段、装配段「贴板【0162-01-010101-03】焊接」，随后重复一遍 04 零件段落（贴板【0162-01-010101-04】取料到贴板【0162-01-010101-04】焊接），04 装配段末尾追加「主筋板组件下料抓取、主筋板组件下料放置」，共 21 步。v1 归档 24 步流程的设备级子工序（放置、翻面压紧、定位焊扫描、定位焊）通过别名映射归入对应复合段落。翻面工位保持「支撑位置执行、压紧位置执行、翻面」，表面打磨任务进入该工位时使用打磨工步；主筋板打磨工位1 保持「支撑位置执行、二次定位/导入工件位置、正面打磨执行、压紧位置执行（如有）、翻面（如有）、反面打磨执行（如有）」。定位扫描执行和定位焊接执行属于同一焊接任务的内部设备工步，展示层已并入装配段的「贴板【编号】焊接」单步。完整零件名称来自当前工序 `partObject`，组合序号来自当前工件组合关系；现阶段没有可选设备配置时，带「如有」的候选工步保留展示。
- 工位没有在执行的任务时，右侧单步面板仍展示该工位完整工步模板（复合工位展示完整合并工步列表），标题标记为「工位工步」且不标记当前工步、不伪造任务状态；单步模式下工步可选中并触发演示执行，进入真实执行后切换为任务当前工步回显。
- 3D 视窗内打印日志浮窗：复用工艺规划圆角玻璃浮层样式，在工作台视窗内左右留边后横向占满可用宽度，记录新建、初始化、执行、暂停、停止、AGV 和视觉监测反馈。
- 托盘管理页面：完整页面展示 AGV 任务调度表和不含计划上料卡片的托盘整体视图，并在页面 Header 提供理料区视图入口；AGV 标题栏提供历史任务和新建任务，不提供批量生成上料任务。已完成任务可归档到历史任务；历史模式仍位于托盘管理页面内，隐藏托盘整体视图并让只读任务表占满内容高度，可将任务恢复到当前列表。理料区视图继续展示同一份托盘整体视图，并额外展示当前缓存工单的计划配盘及真实零件俯视图，多料托盘暂按无分隔线单列变体展示，图例工作区使用白底；顶部以横向短名称 tag 切换“配置完成且未下发”的缓存工单，不使用下拉选择器；工单下发后从 tag 和计划摆盘区移除；每张计划卡片在序号行提供执行和确认到达入口。
- 视觉监控：切换时只替换中间视窗内容，左右生产任务栏和单步调试栏保持不消失；中间为单一视觉监控视窗，底部 Tab 切换 8 路视觉，覆盖桁架 1/2、搬运机器人 1/2 和焊接机器人 1/2/3/4。视觉监控不使用独立深色背景，使用统一视窗灰底、浅灰网格和白色半透明信息层。默认状态显示「当前无视觉内容」，不加载点云；第 06 道装配异常时加载真实点云，Tab 切换对应的观察角度和右侧异常处理面板，一次只显示当前视觉，不平铺 8 个面板。桁架面板展示 X、Y、Z、Rx、Ry、Rz 和工件代号；从第 06 道异常切换到桁架 1/2 视觉时，右侧当前任务固定回显 WP-01 的第 04 项抓取任务，工件代号为 `0162-01-010101-02`；搬运面板在装配异常态只展示装配定位字段，直线 / 圆弧控件与“装配定位”同排；直线模式下“第一组装配基准”“第二组装配基准”各自展示基准距离和角度，圆弧模式下各自展示中心距；不再显示独立的装配基准线回显框。双击左侧第 04 项「抓取」时，临时切换为抓取六轴和工件代号 Hack；焊接面板展示测量交点 X、Y、Z。所有 Demo 面板均支持修改结果、重新扫描、扫描中反馈、跳过和确定。视觉状态栏以绿 / 黄 / 灰分别表达正常在线 / 在线告警 / 离线，当前异常上下文保留红灯；异常处理完成后任务继续保持暂停。
- 正常二次定位结果进入同一个视觉监控工作区，但使用独立「视觉结果」右栏，不构造异常工件或显示异常原因。执行定位结果显示视觉选择栏；导入结果隐藏视觉选择栏。两者均复用真实点云，并只读回显结果来源、工件和六轴位置。

## Hierarchical Workstep Display (2026-08-26)

工位详情的工步回显采用三级结构：当前批次工件顺序编号 → 工步类 → 工步。三层对象统一使用 14px 字号，层级差异只通过字重、颜色、图标和缩进表达。最上层编号来自当前任务 `workpieces` 中执行工件的顺序，格式为「工件-01」「工件-02」；`WP-xx` 仅保留在任务上下文信息中。

工步类右侧对象名称必须来自当前工序的 `partObject`；不使用示例图中的历史工件号。组合对象（`partObject` 中用 `+` 连接的多个零件）在展示时统一采用「合并同类项」写法，与生产任务栏工序对象一致：各零件共享同一前缀时，改写为「前缀 + 括号内尾号相加」的格式，例如 `0162-01-010101-02 + 0162-01-010101-01` 显示为 `0162-01-010101- (02 + 01)`（由 `formatCombinedPartObject` 统一改写）；前缀不一致或无法解析时保留原始 `+` 连接全文。工步名称按现场工位模板使用完整业务文案：主筋板上料 / 打磨、贴板 02 / 03 / 04 装配与焊接、翻面、主筋板组件下料；装配段压紧 / 扫描 / 焊接动作合并为「贴板【编号】焊接」单步，不再使用 `W-*` 焊缝编号工步。

工步树是展示层分组，叶子节点继续携带扁平执行索引；当前、已选、执行中、已完成和定位结果入口的行为保持原单步调试规则不变。空闲工位展示同一份完整模板，不伪造任务状态。

## Workbench Tray Region Labels

- 生产工作台地面区域标注固定为：01 上料区、09 下料区。02-08 不显示装配区名称或区域 tag。
- 保留区域文字的几何基准必须来自对应托盘立方体上表面的实际占地范围，不得按编号位置简单平均，也不得为单个区域写独立 `x/y` 偏移。
- 区域文字中点从区域几何中心沿统一左下视觉引导方向移动。该方向取托盘横轴屏幕法线与轴测地面垂直轴的单位角平分线，当前距离为 `48` SVG 单位，对应约向左 `34`、向下 `34`。
- 区域文字横轴保持平行于托盘立方体前表面上边线，文字变换不得改变外层几何锚点；详细公式和 SVG 实现契约以 `docs/frontend/production-workbench-isometric-geometry.md` 为准。
- 验收时上料区和下料区必须使用同一方向和距离；在 100%、110% 以及非默认视窗宽度下，区域文字与对应托盘组的相对位置不得漂移。

## Workbench Station Card Variants

- 生产工作台支持两套卡片展示方案：水平方案和 skew 方案，默认使用水平方案。
- 视窗工位卡片和托盘卡片沿用工艺规划任务条目的中性层级：白色任务面、zinc 结构边线、`rounded-ds-md` 和 `shadow-ds-sm`；状态只通过左侧短条、状态圆点和轻量 badge 表达，不使用整张卡片的状态色边框或大面积状态阴影。工位标签统一为“空闲 / 执行中 / 已暂停 / 异常”，异常处理完成后变为“已暂停”；托盘标签继续使用自己的现场物流状态，不与工位标签混用。
- Component Lab 的工位卡片方案按钮是当前原型的方案选择入口；选择结果需要同步控制生产执行工作台中的工位卡片和托盘卡片，并在刷新后保留。
- 水平方案保持平面显示，不应用轴测变形；工位卡片和托盘卡片均按当前水平基础尺寸整体缩放到 `0.75`，并展示与 skew 方案一致的字段。
- 两套方案的工位卡片均展示工位名称、空闲 / 执行中 / 已暂停 / 异常和“加工零件：当前工序零件对象”；异常处理完成后工位卡片切换为“已暂停”，异常工位不在卡片内展示“查看视觉”按钮。
- 生产工作台轴测工位、竖线和工位卡片的几何细则以 `docs/frontend/production-workbench-isometric-geometry.md` 为准。
- skew 方案卡片外壳沿工位立方体右侧面轴使用约 `-25.4°` 的 `skewY`，并沿卡片长度方向使用 `scaleX(0.84)` 收短；不额外绘制灰色厚度层。外壳保持 `overflow-visible` 避免轴测后底部提前裁切，内部单独使用圆角裁切层承载白底、左侧状态竖条和内容。标题、badge 和加工零件信息继承同一轴测变换，像贴附在卡片面上一样渲染；整张 skew 方案卡片再按原尺寸的 `0.75` 进行视觉缩放，并使用缩放后的宽高参与主视图锚点定位。水平方案与 skew 方案下 6 个工位竖线均使用同一短线长，线的下端垂直锚定在对应立方体上表面中心，线的上端对齐卡片底边中点。
- 工位卡片与竖线必须通过 `getProductionStationCardPlacement` 统一计算位置。该方法以工位立方体 `topCenter.x` 作为竖线和卡片底边中点的唯一横向锚点，对两套方案返回同一个“卡片底边中点 / 竖线上端”语义坐标；调整卡片尺寸只能改变卡片本体相对底边中点的外扩范围，不得改变竖线下端或让竖线上端脱离卡片底边中点。
- 水平方案工位卡片基准最小尺寸为 `252px × 92px`，视觉缩放后最小定位尺寸为 `189px × 69px`；skew 方案工位卡片基准最小尺寸为 `252px × 104px`，视觉缩放后最小定位尺寸为 `189px × 78px`。加工零件名称超过两行时，卡片按换行行数动态增高，生产工作台和 Component Lab 均使用同一份实际高度计算。
- 两套方案的卡片定位均以底边中点作为 transform origin 和连接线锚点，生产工作台使用 0×0 锚点容器定位到竖线终点，再把卡片本体以 `left = -width / 2`、`top = -height` 挂到该锚点，确保竖线的上端结束在工位卡片下边沿的中点。
- 两套方案均不使用横向锚点偏移；如果后续需要避让两侧区域，应优先调整工位几何、卡片尺寸或改用非竖直连接线，不应在保持“竖线”的同时单独移动卡片横向锚点。
- 方案切换不得重置生产任务、当前工序、执行进度、视图 tab 或日志状态。
- 工位卡片高度随方案变化时，垂直连接线仍需锚定对应工位立方体上表面中心。

## MVP Flow

1. 用户点击主导航「生产执行」进入生产执行工作台。
2. 用户点击「新建工单」打开编辑器，再从最左工单栏连续新建一张或多张待下发草稿工单；每张卡片自动生成工单号并独立保存配置。
3. 用户选中某张工单卡片，在项目管理结构树选择装配体；右侧工作区上部预览模型，下部预览工序、关联零件和禁用状态，数量统一在「加工设置」中调整。
4. 用户在当前工单局部 footer 点击「下一步：预览配盘」，只替换上部 3D 视窗为托盘区位图，并在原工序任务预览位置展示托盘卡片；底部设置区、项目树和面板尺寸保持不变。
5. 用户点击「返回任务设置」回到模型 / 工序内容，点击其右侧「确认工单」确认当前草稿配置；配置完成且数量有效的工单卡片 Checkbox 变为可选。用户勾选需要下发的工单后，弹窗 footer 左侧显示已选数量，右侧「下发生产」按钮变为可用；点击后只按 Checkbox 勾选项创建生产任务，未勾选草稿继续保留在缓存区。
6. 用户点击「初始化」，任务状态进入就绪，日志打印 PLC、机器人、视觉信号复位。
7. 用户点击「执行」，按钮切换为「暂停」，任务状态变为加工中，右侧保持单步调试面板，工件进度和 3D 工位高亮推进。
8. 任务状态监控组件作为保留实现暂不挂载在当前生产执行主页面。
9. 用户在旧样式生产任务中点选某个工序时，顶部 tab 切到模型视图，视窗内左侧悬浮结构树和中间模型同步高亮该工序对应零件，其它零件半透明显示；新样式生产任务仅选择任务与驱动现场状态，不触发模型高亮。
- `WP-01` 第 06 道「装配」直接出现焊接机器人1视觉异常，系统在右上角显示全局异常 Alert；用户点击「查看详情」后进入视觉监控并在右栏打开「异常处理」。首屏以 `当前任务：WP-01 · 装配0162-01-010101- (02 + 01)`、红色异常原因块、粗定位坐标和结果点六轴只读坐标回显异常上下文。Demo 变体的拍照位置区域保留六轴坐标编辑，隐藏重置和绝对位置 / 相对位置操作；用户修改坐标后可点击页脚中位于「跳过」左侧的「重新扫描」，成功后接收新的视觉结果，坐标修改未重新扫描时「确定」不可用。跳过或确定后解除视觉异常并保持任务暂停，左侧第 06 道装配行保留当前工序并显示黄色暂停状态灯。
- Demo 快捷入口：在新版生产任务树中双击 `WP-01` 第 06 道「装配」，复用同一份视觉异常状态构造，直接进入视觉监控并打开异常处理；自动执行和单步执行原有的第 06 道异常触发路径保持不变。
10. 用户可点击「暂停」暂停当前任务，再次点击「执行」恢复。
11. 用户点击「停止」需确认；停止后任务必须重新初始化才能执行。
12. 用户点击生产监控主「执行」后，demo 以每步 12 秒的节奏推进工位工序，给用户足够时间观察当前工位和 WP 状态；`00 -> 01` 上料仍依次回显 01 已预约、零件01到达和工位接料，随后自动回收 `01 -> 00` 空托，mock 09 接收加工完成装配体并执行 `09 -> 10` 满托下料，确认到达后 09 恢复空闲。用户打开「托盘管理」完整页面，可手动执行 / 确认到达 AGV 上料、空托、满托任务，并从页面 Header 进入理料区视图查看托盘整体状态；返回后保留原生产执行视图状态。

## Interaction Rules

- 「生产执行」作为主导航一级入口，不改动现有工艺规划工作区。
- 在工艺规划与生产执行之间切换时，生产执行工作台保持挂载并保留当前任务、执行进度、托盘、日志、视觉处理和视图 tab 状态；刷新网址后允许恢复为 demo 初始状态。
- 生产执行不保留独立顶部工具栏，视图切换和执行控制均悬浮在当前视窗上端。
- 生产监控 / 模型视图 / 视觉监控采用同组窗页 tab 切换；托盘管理作为独立悬浮按钮进入完整托盘管理页面，不进入顶部 tab 分组；托盘管理页面通过显式入口进入理料区视图，并可返回托盘管理或生产执行。
- 旧样式生产任务点选工序后自动进入模型视图；模型视图是顶部悬浮 tab 的一级视图，不放在左侧生产任务栏内。旧样式工序任务条目点选态使用主高亮样式，模型视图结构树中的对应零件条目使用组件库次高亮样式。再次点击同一工序任务必须取消选中并清除对应模型高亮；点击执行 / 恢复执行时，左侧生产任务列表清空点选与批量勾选，仅以浅灰底执行状态变体标记当前执行或暂停中的工序，用于对应右侧任务状态卡片中的执行状态，右侧任务状态卡片条目样式保持不变。新样式生产任务与模型高亮解耦，任务行不切换模型视图也不改变模型高亮。
- 模型视图复用工艺规划隔离语义：旧样式当前工序关联零件保持 100% 显示，非关联零件在视窗内悬浮结构树和模型视窗中半透明显示。点击结构树零件时，零件行进入浅橙 fill + stroke 选中态，并以同一隔离高亮方式在 3D 模型中显示该零件；该选择仅覆盖模型视图本地回显，不改变旧样式工序选中或新样式任务状态。再次点击该零件或点击视窗空白处清除选择，随后恢复已有的旧样式工序高亮。
- 「执行 / 暂停」为同一个主按钮，根据当前任务运行状态切换。
- 任务执行中不允许删除任务；停止和初始化也不应直接作用于运行中任务。
- 左侧生产任务筛选支持按工序状态、零件名称和工序类型多选组合过滤，筛选方式中工序状态排在首位且不展示项目筛选；筛选以工序条目为粒度，同一条件内任一选中值命中即可保留，不同条件之间同时生效，不符合条件的工序条目必须隐藏，父级生产任务仅在仍有命中工序时保留；点击清除列表必须先弹窗确认，确认后只清除当前筛选后可见任务，不表示删除底层工艺规划数据。
- 新建工单入口不受当前列表数量限制；关闭弹窗不清空待下发缓存。点击「下发生产」后，只有 Checkbox 勾选工单追加到生产任务列表，默认折叠，点击概要或 caret 展开。
- 待执行工单可通过拖动整条概要调整排单顺序；运行中、暂停和异常工单锁定顺序。执行中展开其它工单只改变左栏可见内容，不切换中间生产监控、单步调试、托盘和视觉异常的活动工单上下文。
- 已下发但未执行工单在状态左侧提供 hover / focus 才显示的删除图标；删除前打开居中确认弹窗，确认后只从当前生产任务列表移出该工单，不删除工艺规划数据。状态区域保持固定宽度，删除入口显隐不得改变「待初始化 / 待执行」的右对齐基线。
- 工单概要条目不使用外壳 stroke；生产任务栏中的工单 stack 顶部 padding 与左右 padding 同为 `8px`，展开工单后不得把该 padding 叠加到 WP 容器内部。
- 左侧生产任务列表的标题栏和筛选区域固定在面板顶部，任务条目内容区独立纵向滚动；旧样式 24 个工序、新样式每个 WP 的 16 条聚合任务及筛选后的任意数量条目都必须能够滚动查看完整。
- 新样式任务条目不显示工位，使用单行序号、状态灯、Zinc 工序名称和低饱和 Slate 零件对象；序号默认固定显示，只有显式批量选择模式才切换为 Checkbox，行尾不提供 hover 禁用入口。
- 执行新样式任务时，中间生产监控视图按任务映射更新工位卡片；托盘卡片与轴测立方体只读取托盘、料框和 AGV 的现场状态。主执行按钮的上料 mock 在 WP-01 开始前将 `00 -> 01` 依次回显为已预约、零件01 `×5` 到达和空托在位。
- 左侧生产任务为空、当前筛选无结果，以及右侧单步调试暂无内容时，缺省态复用工艺规划任务列表规范：虚线框占满内容区，内部使用图标 + 单行文案并整体轻微上移；默认文案为「暂无任务」。
- 左侧工序任务禁用为软禁用：新建工单弹窗中禁用的工序保留在任务定义中并由执行器跳过，但不渲染到生产任务列表，不进入筛选条件或工序计数。装配体 / 生产任务条目不承载禁用状态。
- TaskStatusMonitorPanel 保留原工件实例监控实现；当前主页面不挂载，因此右侧只显示单步调试空状态。
- 停止任务后必须通过初始化复位，才能重新进入执行流程。
- 新建工单弹窗标题不显示草稿数量胶囊；左栏标题固定为「工单列表」，不显示「待下发草稿」，「新建工单」按钮使用品牌橙色。工单栏在两个局部阶段中固定显示，并 stack 用户待下发的多张草稿工单卡片。每张卡片左侧增加 Checkbox：只有「配置完成」且数量有效的卡片可勾选，未设置数量的卡片只禁用 Checkbox，卡片本身仍可点击进入右侧编辑区。两阶段共享同一套「项目管理结构树 + 上部视窗 + 下部设置 / 预览」骨架；配盘阶段只将上部 3D 视窗替换为托盘依据视图，并将工序任务预览位置替换为托盘卡片。加工数量始终位于「加工设置」内。局部 footer 在第一步提供「下一步：预览配盘」，第二步提供「返回任务设置 / 确认工单」；弹窗 footer 左侧显示选中数量，右下角使用「下发生产」，无选中项时禁用。
- Demo 快捷入口：双击新建工单弹窗左栏标题「工单列表」，为当前缓存中的全部草稿工单补齐配置。已有装配体保持不变，未选择装配体的草稿按工件库顺序补齐；每张草稿在对应托盘容量上限内生成随机正整数数量并标记为「配置完成」。快捷入口不自动勾选工单，也不触发「下发生产」。
- 草稿工单卡片的删除入口统一命名为「删除工单」；点击后打开就地确认 popover，用户确认后才删除该草稿。Popover 复用组件库磨砂玻璃 surface 和「取消 / 删除」紧凑操作，不得被工单栏滚动容器裁切。
- 工单栏标题行在「新建工单」左侧提供全选 Checkbox，仅勾选配置完成且数量有效的工单；存在部分已选项时显示半选，没有可选工单时禁用。取消全选只清除可下发工单的勾选状态。
- 工单栏标题行下方固定显示关键词筛选框，复用项目管理结构树搜索输入样式；按工单号、装配体图号 / 名称和配置状态过滤当前卡片列表。筛选只改变左栏可见项，不修改草稿内容、当前编辑工单或勾选状态；无匹配项时显示「暂无匹配工单」。
- 新建任务第一步的左侧工件库结构树零件行可单选并在 3D 视窗高亮对应零件，零件名称左侧需与装配体名称左侧对齐。结构树零件选择与右侧工序任务预览选择互斥，点击任一侧都必须清除另一侧选中态。
- 新建任务第一步的工序任务预览支持每条工序单独禁用 / 解除禁用；列表左侧 checkbox 支持勾选多条后批量禁用或批量启用。禁用行置灰、不响应弹窗内模型高亮，但仍可勾选用于批量解除禁用。
- 新建任务第一步右侧「当前工件」下方提供「加工设置」，其中「禁用侧面打磨 / 启用侧面打磨」快捷 toggle 只作用于 `generated-grind-02`、`generated-grind-03`、`generated-grind-04` 三道贴板侧面打磨；`generated-grind-01` 和其它普通打磨不参与该快捷切换。
- 确认创建任务时，弹窗内禁用的工序必须作为任务级软禁用状态写入生产任务；新任务加入左侧列表后对应工序不显示，执行和恢复执行均跳过这些工序。
- 新建任务第二步复用托盘管理托盘依据视图，仅替换 3D 工件视窗；托盘卡片排在原「工序任务预览」位置，区位图不再额外带独立托盘结构树。新建任务预览的托盘矩形仅在满盘时显示“满盘”tag，普通已配盘和多料状态不显示矩形内状态文字。
- 托盘配盘预览以“一种料放一堆”为原则，数量表示每堆同零件物料件数。新建任务 mock 固定展示 4 种料：加工数量 1-2 时，01 号托盘集中展示四种料各一堆；数量 3 时，01-03 号托盘承载四种料，其中最后一张托盘可合并显示剩余料种；数量 4-5 时，01-04 各放一种料，01 号零件优先放入 01 号托盘，其余零件按托盘序号顺移。数量大于 5 时，每种料拆为每批最多 5 件的连续独占托盘，例如数量 6 时四种料均为“5 + 1”，依次使用 01-08 共 8 个托盘。09 是下料区，不能用于该配盘。每批达到 5 件时对应卡片和区位图显示“满盘”警告；加工数量 10 时 8 个托盘全满，输入框下方显示已到配盘上限且增加 stepper 禁用。超过该数量的手工输入显示托盘不足，确认任务不可操作。
- 托盘俯视图用于识别零件种类，不作为真实摆放坐标；多料托盘当前使用连续承载面内的单列展示，不绘制料框、网格或分割线。后续只有在取得托盘有效尺寸、间距、允许旋转角度和禁放区数据后，才能升级为按比例摆放视图。
- 托盘管理中，上料任务从图外 `00` 确认到达至 01-09 点位后，整体区位图回显实际零件名称和“已占用”。实际占用点位可点击释放为“空托在位”，用于 mock 人工取料后的空托回收准备；计划摆盘卡片的物料内容保持只读，序号行只提供任务执行和确认到达动作，满盘提示仅表达容量预览。
- 托盘状态梳理：托盘卡片保持现状，不改成工位三态；空托位置显示“空闲 / 空托在位”，AGV 目的地显示“已预约”，上料 / 空托回收过程显示等待或取货状态，已装载或满托显示“已占用”，AGV 任务行另显示“执行中”。
- 工作台已占用托盘卡片在编号右侧提供编辑图标，点击后打开托盘编辑弹窗；用户可从当前工件的零件 01-04 中重新选择零件类型并修改数量，保存后更新现场托盘载荷，取消或关闭不写回。弹窗编辑期间托盘 Demo 节奏暂停等待，完成后顺延一个完整步进间隔；普通托盘展示态和托盘管理计划卡片不变。
- 任务状态监控组件保留以工件实例为粒度展示当前进度、当前工序和状态的实现，但当前主页面暂不显示。
- 设备状态灯使用红 / 灰 / 绿表达异常 / 未连接 / 连接。
- AGV 执行中按钮或状态应有明确 loading / 闪烁反馈。

## Current MVP Scope

- 当前实现为前端 demo 状态模拟，不连接真实 PLC、机器人、视觉或 AGV 后端。
- 当前 3D 产线使用轻量示意图表达工位与工件流转；生产工作台模型视图使用轻量零件示意，复用工艺规划点选工序后的零件隔离高亮语义。
- 当前托盘配盘根据工件数量生成展示数据，用于演示人工理料和 AGV 调度闭环。
