# MES 物料管理 Product Spec

## Goal

物料管理为制造构件提供物料主数据、可用量、批次质量和工单齐套的统一查看入口，帮助计划人员在下发和执行前识别物料风险。

## Navigation

- 物料管理是紧随生产管理之后的一级导航，入口路径为 `/mes/materials`。
- 构件追溯不属于物料管理，保留在生产管理中，记录的是构件实例的生命周期证据。
- 库存管理仍处理入库单、库位和实物库存流转。
- 项目管理保留项目本身的维护入口；模型导入与构件列表作为生产准备页面，不再在项目管理页内以页签入口出现。

## Page Structure

页面使用以下三个页签：

1. **物料台账**：按物料编码、名称、类别、规格、仓库和库位查看现存、已预留、可用量、批次及质量状态。支持关键词、物料类别、库存状态和质量状态筛选。选择一条物料后，在右侧显示基本信息、库存汇总、批次质量和关联工单需求。
2. **工单齐套**：按工单查看物料需求量、已预留量、已发料量、缺口和齐套状态。状态为缺料、已预留、已发料或已齐套。
3. **批次与质检**：按物料批次或炉批号查看质检结论、质保书状态、可用数量与存放位置。

## Interaction Rules

- 所有数据仅为前端 Demo 数据；筛选、页签和详情选择在页面本地生效。
- 页面不提供自动扣减库存、BOM 解析、入库或出库操作；这些动作分别属于库存管理、工单配置及后续服务端能力。
- 物料台账的可用量、工单缺口和齐套状态按领域规则展示。

## Acceptance Criteria

- 物料管理页可从一级导航进入，标题为“物料管理”。
- 三个页签均可切换，且能表达物料、工单需求和批次质量三个不同视角。
- 库存管理、托盘物流和构件追溯的页面职责保持不变。
