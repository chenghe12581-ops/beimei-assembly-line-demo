# 生产执行 · 执行控制功能说明（v3.1 · 2026-10-28 最终版）

> 核心规则（截图批注）：**整线控制按钮与单站控制按钮不可同时使用，一方按钮处于使用状态时另一方置灰。**
> v3 变更要点（2026-10-28 定稿）：执行控制每组只保留「初始化 + 执行/暂停」两个执行按钮；「暂停」语义改为**软暂停**——系统自动把当前工步执行完（该工步状态显示完成），然后停住等待再次点击执行；报错或人工急停 → 弹窗报错 + 当前工步标记**异常**，人工可选中该工步单步执行重做；**删除**单步执行确认弹窗和单步执行结束弹窗；仅在「人工跳选某步 + 单步执行 + 其前序工步存在非完成状态（未执行或异常）」时弹窗提示；单步完成仅通过工序状态回显体现；执行推进动画继续暂缓。
> v3 修订（2026-10-28）：**单步 tab 精简**——单步运行不需要初始化和暂停，单步 tab 仅保留「单步执行」一个按钮，执行状态完全通过工步状态回显；初始化与执行/暂停仅存在于整线顶栏和单站自动 tab。
> v3.1 修订（2026-10-28）：**顶栏恢复「停止」按钮**（仅整线顶栏，单站面板仍不设置停止）。处于暂停或运行状态时，点击停止用于**跳出执行状态**，以便进行单站 / 单步调试：暂停态点击 → 直接跳出；运行态点击 → 系统自动把当前工步执行完（软暂停语义）后跳出。跳出后会话释放、任务进入「已中断」态、执行进度保留，可直接再点执行续跑，无需初始化。

## 0. 执行进度模型（本次设计的核心）

- 每个工单维护一份**执行进度**：`{ 当前工位, 当前工步 }` 与每个工步的**状态**（未执行 / 执行中 / 完成 / 异常），表示"下一次执行从哪里开始"。
- **首次执行**：整线执行起点 = 工单首道工序的首工步；单站执行起点 = 该工位在工单工序链中的首个工步（复合工位取首个启用段落起点）。
- **进度续跑**：执行过程中进度随完成度推进；自动和单步共用同一份进度——无论哪种模式执行完某工步，进度都落到该工步的**下一工步**。
- **执行 / 暂停两个状态**：
  - **执行（运行中）**：从当前进度工步开始连续推进，按钮显示为「暂停」。
  - **暂停（软暂停）**：点击后**不再中断当前工步**——系统把当前正在执行的工步**执行完**（该工步状态显示**完成**），然后**停住**，等待操作员再次点击「执行」从下一工步继续。没有"工步内进度记忆"的概念。
- **异常 = 中断的唯一方式**：执行中出现报错或人工触发急停 → 软件**弹窗报错**，当前工步标记为**异常**（已做部分作废），进度停留在该工步；人工可**选中该工步**后点击「单步执行」重做，重做成功后状态转为完成、进度推进。
- **停止 = 主动跳出执行状态**（v3.1 恢复，仅整线顶栏）：运行态点击停止 → 先执行完当前工步再跳出；暂停态点击 → 直接跳出。跳出后任务进入「已中断」态，进度保留，可直接再执行续跑。
- **初始化 = 全部重置**：把设备状态和软件流程全部初始化，所有工步状态清零，之后执行从最初开始。初始化**不是执行的前置**——新建工单选中后直接点执行即可开始。

## 1. 两区域按钮总览

| 区域 | 位置 | 按钮 | 作用范围 |
| --- | --- | --- | --- |
| 整线控制按钮 | 生产监控视窗顶栏中部 | 初始化、执行（运行中变为「暂停」）、**停止** | 整条产线（当前工单的全部工位） |
| 单站控制按钮 | 右侧工位详情内「自动顺序执行工序内工步」条 | 自动 tab：初始化、自动执行（运行中变为「暂停」）；单步 tab：仅「单步执行」 | 仅当前查看的工位（复合工位视为一个执行单元） |

## 2. 按钮功能说明

### 2.1 整线控制按钮

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化 | **整线设备状态 + 软件流程全部初始化**，所有工步状态清零；再执行从工单最初开始 | 任务非执行中（running / paused 均禁点，暂停表示还在运行中）；空闲 / 已中断时可点 |
| 执行 | 从**当前进度工步**（首次为工单首道工序首工步）开始整线自动推进；运行中按钮切换为「暂停」 | 已选中工单；整线执行中**不允许进入单步** |
| 停止（v3.1 恢复） | **跳出执行状态**：暂停态点击 → 直接跳出；运行态点击 → 系统先把当前工步执行完（软暂停语义）再跳出。跳出后**会话释放**、任务进入「已中断」态、**执行进度保留**，可直接再点执行续跑（无需初始化） | 任务处于运行中或暂停态时可用；**互锁豁免**——单站会话期间同样可点（用于跳出单站执行状态做单站 / 单步调试） |

### 2.2 单站控制按钮

**按钮组随 tab 切换**：自动 tab 显示「初始化、自动执行（运行中变为「暂停」）」；**单步 tab 仅显示「单步执行」一个按钮——无初始化、无暂停**，执行状态完全通过工步列表的状态回显（未执行 / 执行中 / 完成 / 异常）体现；手动 tab 不显示执行控制条。两组按钮共享同一份工序状态与进度回显——执行中切换 tab 只换按钮、不换数据。

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化（仅自动 tab） | **当前工位设备 + 流程全部初始化**，该工位工步状态清零；再执行从该工位段落首工步开始 | 任务非执行中（running / paused 均禁点）；当前工位无执行中会话 |
| 自动执行（自动 tab） | 从**该工位当前进度工步**开始连续自动执行；首次为该工位首个工步；单步走到某步后再点自动，也从该步开始 | 无执行会话进行中；当前工位存在该工单的启用工序，否则置灰并提示「当前工位没有可执行的工序」 |
| 单步执行（单步 tab，唯一按钮） | 执行当前选中的单个工步；执行期间按钮禁点；执行完成后该工步状态显示完成、进度推进到下一工步，结果仅以工步状态回显，**不弹结束弹窗** | 任务非执行中；已选中工步；当前工位存在该工单的启用工序；若人工跳选工步且其前序工步存在非完成状态，先弹窗提示（见 4.3） |

**三种执行方式的区别**：

| | 整线执行（顶栏） | 单站自动执行（自动 tab） | 单步执行（单步 tab） |
| --- | --- | --- | --- |
| 起点 | 工单首道工序首工步（首次）/ 当前进度工步 | 本工位当前进度工步（首次为该工位首工步） | 用户选中的工步 |
| 推进范围 | 跨工位推进整张工单 | 仅当前工位（复合工位为一个执行单元） | 一次一个工步 |
| 典型用途 | 批量生产 | 某工位复产 / 续跑 | 调试、验证单工步、重做异常工步 |

## 3. 互锁设计

### 3.1 状态定义

- **执行会话**：`{ 执行侧: line / station, 模式: auto / single-step, 工位 }`，任务进入执行态（running）时建立，软暂停时保留，工位全部执行完、停止跳出或异常时释放。
- **执行中（running）**：会话存在且任务运行中。
- **暂停（paused）**：会话保留；当前工步正在执行完，执行完后停住等待；**仍视为运行中**——初始化禁点，仅「执行（恢复）」与「停止」可点。
- **已中断（stopped）**：会话释放，任务由**停止跳出**（v3.1）或异常产生；执行进度**保留**（停留在停止时 / 异常时的进度工步），不视为执行中——初始化与执行按钮均恢复可点，可直接再执行续跑。
- **空闲（idle）**：任务就绪、无会话；可能存在**异常工步**（历史报错/急停留下），异常步不阻塞执行按钮，仅作为状态回显与单步重做的入口。
- **异常（abnormal）**：某工步被标记异常（已做部分作废），进度停留在该工步；人工可选中该步单步执行重做。

### 3.2 互锁规则

1. **双向区域互斥**：整线会话中 → 单站控制按钮组整体置灰；单站会话中 → 整线控制按钮组整体置灰。
2. **执行中禁初始化、禁其他执行按钮**：任务处于执行中（running）或暂停（paused，暂停表示还在运行中）时——「初始化」禁点；非本会话模式的执行按钮禁点；另一侧按钮组按规则 1 置灰。会话结束（工位执行完 / 停止跳出 / 异常）后，初始化与执行按钮恢复可点。
3. **暂停 = 软暂停**：点击「暂停」不打断当前工步——系统把当前工步执行完（状态显示完成）后停住，等待再次点击「执行」从下一工步继续。暂停期间初始化禁点。
4. **停止 = 跳出执行状态（v3.1，仅整线顶栏，互锁豁免）**：运行态点击停止 → 系统先把当前工步执行完（软暂停语义）再跳出；暂停态点击 → 直接跳出。跳出后：会话释放、任务进入「已中断」态、**执行进度保留**，初始化与执行按钮恢复可点，可直接再执行续跑（无需初始化）。停止按钮**不受互锁限制**——无论整线还是单站会话期间都可用，用于跳出当前执行状态后进行单站 / 单步调试。
5. **异常中断（弹窗 + 标记异常）**：执行中出现报错或人工急停：
   1. **弹窗报错**：标题区分执行侧——「整线执行中发生异常」/「单站执行中发生异常」，回显工位、工件、异常工序与错误原因；无取消按钮；
   2. **当前工步标记异常**：已做部分作废，会话释放，进度停留在该工步；
   3. **恢复方式**：排除故障后**直接再次执行**即从异常工步所在位置继续——自动执行从异常工步重做；或**人工选中异常工步单步执行**重做，重做成功状态转完成、进度推进。**不需要先初始化**（初始化仅用于"全部重来"）。
   - 弹窗出现期间两侧所有按钮均不可点（弹窗独占）。
6. **模式内互斥**：执行会话期间执行模式 tab 可自由切换、状态实时同步查看，但非会话模式的执行按钮置灰；**自动执行会话中，单步 tab 仅可查看——工步列表不可选中、单步执行禁点**（不允许借单步选择其他工步打断自动执行）。整线运行中**不允许进入单步执行**（单步按钮置灰即可，不弹窗）。单步 tab 本身只有「单步执行」一个按钮，无初始化、无暂停。
7. **进度共享**：自动与单步共用同一份执行进度；单步执行完成一工步后，进度推进到下一工步，此时点「自动执行」即从该工步开始连续执行。
8. **工单级约束**：未选中工单时两组按钮均不可用；新建工单选中后即可执行，无需初始化。
9. **置灰反馈**：置灰按钮 hover 时以 tooltip 说明原因，如「整线正在执行，暂不可操作」「执行中不可初始化」「当前工位没有可执行的工序」「自动执行中不可单步执行」。

### 3.3 互锁矩阵

| 当前状态 | 整线组 | 单站组 · 自动 tab | 单站组 · 单步 tab |
| --- | --- | --- | --- |
| 空闲（就绪，无会话） | 初始化✓ 执行✓ | 初始化✓ 自动执行✓ | 单步执行✓ |
| 整线执行中 | 暂停✓ 停止✓（初始化✗ 执行✗） | 全部置灰 | 全部置灰（不允许进入单步） |
| 单站自动执行中 | 仅停止✓（跳出执行状态，其余置灰） | 暂停✓（初始化✗） | 仅查看：工步禁选、单步执行✗ |
| 单站单步执行中 | 仅停止✓（跳出执行状态，其余置灰） | 仅查看：自动执行✗ 初始化✗ | 单步执行✗（执行中，状态以工步回显） |
| 暂停（当前工步执行完后停住，仍视为运行中） | 执行（恢复）✓ 停止✓（初始化✗） | 执行（恢复）✓（初始化✗） | 仅查看：单步执行✗（回自动 tab 恢复执行） |
| 已中断（停止跳出，进度保留） | 初始化✓ 执行✓（从进度工步续跑） | 初始化✓ 自动执行✓ | 单步执行✓ |
| 存在异常工步（会话已释放） | 初始化✓ 执行✓（从异常工步重做） | 初始化✓ 自动执行✓ | 单步执行✓（可选中异常步重做） |
| 执行中报错 / 急停 | 弹窗（区分执行侧）→ 确认后当前工步标记异常、会话释放；弹窗期间全部禁点 | 同左 | 同左 |

### 3.4 原型落地映射

- 整线组 = 生产监控顶栏浮动按钮组；单站组 = 工位详情内按钮条（随 自动 / 单步 tab 切换）。
- 状态机：`执行会话 { side, mode, stationId }` + 任务状态（running / paused / stopped / idle）+ **每工步状态（未执行 / 执行中 / 完成 / 异常）与进度 `{ stationId, workstepIndex }`**。
- 互锁由三者推导：区域互斥看 `side`（停止按钮豁免），模式内互斥看 `mode` vs 当前 tab，初始化/执行按钮看 running 态。

## 4. 弹窗提示设计

### 4.1 执行异常弹窗（区分执行侧，确认后标记异常）

- 触发：执行中（整线或单站/单步）出现报错，或人工触发急停。
- 弹窗标题：「整线执行中发生异常」/「单站执行中发生异常」。
- 内容：回显异常工位、工件号、异常工序/工步、错误原因；说明「确认后当前工步将标记为异常，已做部分作废；排除故障后可直接再次执行从该工步重做，或选中该工步单步执行」。
- 按钮：［确认］（红色，无取消）。
- 行为：确认后当前工步标记异常、会话释放、写日志；弹窗独占。

### 4.2 定位方式弹窗（已存在，保留）

- 触发：单步模式执行「精定位 / 导入工件位置」工步。
- 内容与交互维持现状（执行定位 / 导入工件位置两栏、失败重拍受「失败重拍次数」约束）。

### 4.3 前序工步非完成提示弹窗（v3 新增）

- 触发：单步 tab 中**人工跳选**某个工步并点击「单步执行」，且该工步的**前序工步存在非完成状态**（未执行或异常）。
- 内容：回显选中工步名称；提示「该工步的前序工步存在未执行/异常状态（列出前序工步名称及状态），直接执行可能产生干涉或基准缺失」。
- 按钮：［仍要执行］（品牌色）／［取消］。
- 行为：确认后正常单步执行该工步；取消则不执行。顺序执行（从进度工步逐歩推进）不触发本弹窗。
- 注：v3 起**不再有**单步执行确认弹窗与单步执行结束弹窗——顺序单步执行开始不再询问，单步完成仅通过工步状态回显（该步显示完成、进度推进）体现。

### 4.4 弹窗通用规范

- 样式沿用现有玻璃浮层风格；主按钮品牌色，取消灰色，危险操作（异常中止）红色。
- 弹窗打开期间互锁照常生效；异常弹窗（4.1）为独占弹窗。
