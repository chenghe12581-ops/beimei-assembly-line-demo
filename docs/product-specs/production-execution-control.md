# 生产执行 · 执行控制功能说明（v2 · 2026-10-28 重构版）

> 核心规则（截图批注）：**整线控制按钮与单站控制按钮不可同时使用，一方按钮处于使用状态时另一方置灰。**
> v2 变更要点（2026-10-28 定稿）：引入**断点续跑**模型（停止/暂停都记住工位+工步）；初始化从"停止后的强制前置"改为"主动重置手段"，且 running / paused 均禁点（暂停表示还在运行中）；停止后执行按钮直接恢复可点；整线运行中不允许进入单步；新增单步执行确认/结束两个弹窗；执行推进动画暂缓，待重新设计。

## 0. 断点模型（本次设计的核心）

- 每个工单维护一个**断点** `{ 工位, 工步 }`，表示"下一次执行从这里开始"。
- **首次执行**：整线执行起点 = 工单首道工序的首工步；单站执行起点 = 该工位在工单工序链中的首个工步（复合工位取首个启用段落起点）。
- **断点续跑**：执行过程中断点随进度推进；执行到某步后点「停止」或「暂停」，断点保留在该工位该工步——之后无论从哪一侧、哪种模式（自动/单步）再次执行，都从这个断点工步开始。自动和单步共用同一份断点。
- **暂停与停止的区别**：
  - **暂停**：记住当前工步**执行到哪里**（工步内进度保留）；点「继续」后可以**执行完这个工步**，再自动推进到下一工步。
  - **停止**：把当前工步**已完成的全部忘掉**（该工步标记为**执行错误**，已做部分作废）；断点停留在该工步；停止后执行按钮**恢复可点**，再次执行从该工步**重做**。
- **初始化 = 重置断点**：把设备和流程初始化，断点清零，之后执行从最初开始。初始化**不是执行的前置**——新建工单选中后直接点执行即可开始。

## 1. 两区域按钮总览

| 区域 | 位置 | 按钮 | 作用范围 |
| --- | --- | --- | --- |
| 整线控制按钮 | 生产监控视窗顶栏中部 | 初始化、执行（运行中变为「暂停」）、停止 | 整条产线（当前工单的全部工位） |
| 单站控制按钮 | 右侧工位详情内「自动顺序执行工序内工步」条 | 初始化、自动/单步执行、停止执行 | 仅当前查看的工位（复合工位视为一个执行单元） |

## 2. 按钮功能说明

### 2.1 整线控制按钮

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化 | **整线设备状态 + 软件流程全部初始化**，断点清零；再执行从工单最初开始 | 任务非执行中（running / paused 均禁点，暂停表示还在运行中）；ready / stopped 可点 |
| 执行 | 从**断点**（首次为工单首道工序首工步）开始整线自动推进；运行中按钮切换为「暂停」，暂停后按钮为「继续」 | 已选中工单；整线执行中**不允许进入单步** |
| 停止 | 全局停止当前执行动作（可停整线或单站会话）；当前工步已做部分作废并标记执行错误，断点保留 | 任务处于运行 / 暂停态 |

### 2.2 单站控制按钮

**按钮组随 tab 切换**：自动 tab 显示「初始化、自动执行、停止执行」；单步 tab 显示「初始化、单步执行（执行工步）、停止执行」；手动 tab 不显示执行控制条。两组按钮共享同一份工序状态与断点回显——执行中切换 tab 只换按钮、不换数据。

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化 | **当前工位设备 + 流程全部初始化**（自动 / 单步 tab 语义一致），该工位断点清零；再执行从该工位段落首工步开始 | 任务非执行中（running / paused 均禁点）；当前工位无执行中会话 |
| 自动执行（自动 tab） | 从**该工位断点工步**开始连续自动执行；首次为该工位首个工步；单步走到某步后再点自动，也从该步开始 | 无执行会话进行中；当前工位存在该工单的启用工序，否则置灰并提示「当前工位没有可执行的工序」 |
| 单步执行（单步 tab） | 执行当前选中的单个工步；执行后断点推进到下一工步；执行中按钮切换为「暂停」 | 同「自动执行」 |
| 停止执行 | 全局停止当前执行动作（与整线「停止」等效）；断点保留、当前工步标记执行错误 | 任务处于运行 / 暂停态 |

**三种执行方式的区别**：

| | 整线执行（顶栏） | 单站自动执行（自动 tab） | 单步执行（单步 tab） |
| --- | --- | --- | --- |
| 起点 | 工单首道工序首工步（首次）/ 整线断点 | 本工位断点工步（首次为该工位首工步） | 用户选中的工步 |
| 推进范围 | 跨工位推进整张工单 | 仅当前工位（复合工位为一个执行单元） | 一次一个工步 |
| 典型用途 | 批量生产 | 某工位断点续跑 / 单独复产 | 调试、验证单工步 |

## 3. 互锁设计

### 3.1 状态定义

- **执行会话**：`{ 执行侧: line / station, 模式: auto / single-step, 工位 }`，任务进入执行态（running）时建立，暂停保留，停止或完成释放。
- **执行中（running）**：会话存在且任务运行中。
- **暂停（paused）**：会话保留，任务暂停，工步内进度记忆；**仍视为运行中**——初始化禁点，仅「继续 / 停止」可点。
- **已停止（stopped）**：会话释放，断点保留，当前工步标记执行错误。
- **空闲**：任务就绪、无会话。

### 3.2 互锁规则

1. **双向区域互斥**：整线会话中 → 单站控制按钮组整体置灰；单站会话中 → 整线控制按钮组整体置灰。
2. **执行中禁初始化、禁其他执行按钮**：任务处于执行中（running）或暂停（paused，暂停表示还在运行中）时——「初始化」禁点；非本会话模式的执行按钮禁点；另一侧按钮组按规则 1 置灰。只有「停止 / 完成 / 异常停止」释放会话后，初始化才恢复可点。
3. **停止全局同步**：任一侧「停止 / 停止执行」停止的都是当前执行动作，不区分触发侧，且是互锁豁免项（对方组置灰时本方停止仍可用）。停止后：
   - 断点保留（记住停在哪个工位哪一步），当前工步标记为执行错误；
   - **执行按钮恢复可点**，再次执行从断点工步重做——**不需要先初始化**；
   - 初始化同样可点（用于"全部重来"）。
4. **模式内互斥**：执行会话期间执行模式 tab 可自由切换、状态实时同步查看，但非会话模式的执行按钮置灰；**自动执行会话中，单步 tab 仅可查看——工步列表不可选中、单步执行与初始化禁点**（不允许借单步选择其他工步打断自动执行）。整线运行中**不允许进入单步执行**（单步按钮置灰即可，不弹窗）。
5. **断点共享**：自动与单步共用同一份断点；单步执行完成一工步后，断点推进到下一工步，此时点「自动执行」即从该工步开始连续执行。
6. **异常处理流程（弹窗 + 自动停止）**：执行中检测到视觉异常：
   1. **异常弹窗**：标题区分执行侧——「整线执行中检测到视觉异常」/「单站执行中检测到视觉异常」，回显工位、工件、异常工序；无取消按钮；
   2. **确认后自动停止**：等同「停止」——断点保留、当前工步标记执行错误、会话释放；
   3. **处理后续跑**：操作员在视觉监控中处理异常数据；处理完成后**直接再次执行即从断点续跑，无需初始化**。
   - 弹窗出现期间两侧所有按钮均不可点（弹窗独占）。
7. **工单级约束**：未选中工单时两组按钮均不可用；新建工单选中后即可执行，无需初始化。
8. **置灰反馈**：置灰按钮 hover 时以 tooltip 说明原因，如「整线正在执行，请停止后再操作」「执行中不可初始化，请先停止」「当前工位没有可执行的工序」「自动执行中不可单步执行」。

### 3.3 互锁矩阵

| 当前状态 | 整线组 | 单站组 · 自动 tab | 单站组 · 单步 tab |
| --- | --- | --- | --- |
| 空闲（就绪，无会话） | 初始化✓ 执行✓ | 初始化✓ 自动执行✓ | 初始化✓ 单步执行✓ |
| 整线执行中 | 暂停✓ 停止✓（初始化✗ 执行✗） | 全部置灰（仅停止执行✓¹） | 全部置灰（仅停止执行✓¹，不允许进入单步） |
| 单站自动执行中 | 全部置灰（仅停止✓¹） | 暂停✓ 停止✓（初始化✗） | 仅查看：工步禁选、单步执行✗ 初始化✗ 停止✓ |
| 单站单步执行中 | 全部置灰（仅停止✓¹） | 仅查看：自动执行✗ 初始化✗ 停止✓ | 暂停✓ 停止✓（初始化✗） |
| 暂停（会话保留，仍视为运行中） | 继续✓ 停止✓（初始化✗） | 继续✓ 停止✓（初始化✗） | 继续✓ 停止✓（初始化✗） |
| 已停止（含异常自动停止） | 初始化✓ 执行✓（断点续跑） | 初始化✓ 自动执行✓（断点续跑） | 初始化✓ 单步执行✓ |
| 视觉异常出现 | 弹窗（区分执行侧）→ 确认自动停止；弹窗期间全部禁点 | 同左 | 同左 |

> ¹ 停止全局同步（规则 3）：单站会话中顶栏仅「停止」可点（停掉单站会话），整线会话中面板仅「停止执行」可点；任一侧停止都作用于整个执行动作。

### 3.4 原型落地映射

- 整线组 = 生产监控顶栏浮动按钮组；单站组 = 工位详情内按钮条（随 自动 / 单步 tab 切换）。
- 状态机：`执行会话 { side, mode, stationId }` + 任务状态（running / paused / stopped）+ **断点 `{ stationId, workstepIndex }`**（含"当前工步是否标记错误"）。
- 互锁由三者推导：区域互斥看 `side`，模式内互斥看 `mode` vs 当前 tab，初始化/执行按钮看 running 态与断点。

## 4. 弹窗提示设计

### 4.1 视觉异常弹窗（区分执行侧，确认后自动停止）

- 触发：执行中（整线或单站/单步）检测到视觉异常。
- 弹窗标题：「整线执行中检测到视觉异常」/「单站执行中检测到视觉异常」。
- 内容：回显异常工位、工件号、异常工序/工步；说明「确认后任务将自动停止并记住当前断点，处理完视觉数据后可从断点继续执行」。
- 按钮：［确认并自动停止］（红色，无取消）。
- 行为：确认后等同「停止」——断点保留（当前工步标记执行错误）、会话释放、写日志；弹窗独占。

### 4.2 停止确认弹窗

- 触发：任一侧「停止 / 停止执行」。
- 内容：停止后当前工步已完成的进度将作废（该工步标记为执行错误），任务记住断点；可直接再次执行从断点重做，或初始化后从头开始。
- 按钮：［确认停止］（红色）／［取消］。

### 4.3 定位方式弹窗（已存在，保留）

- 触发：单步模式执行「精定位 / 导入工件位置」工步。
- 内容与交互维持现状（执行定位 / 导入工件位置两栏、失败重拍受「失败重拍次数」约束）。

### 4.4 单步执行确认弹窗

- 触发：单步 tab 中点击「执行工步」（已选中某个工步）。
- 内容：回显工位名称、选中工步名称、执行方式「单步执行」；说明执行完成后断点将推进到下一工步。
- 按钮：［确认执行］（品牌色）／［取消］。
- 行为：确认后建立单步执行会话并执行该工步；取消则不建立会话，不推进断点。

### 4.5 单步执行结束弹窗

- 触发：单步执行完成一个工步。
- 内容：回显刚完成的工步名称；断点已推进到下一工步「××工步」（若是本工位最后一个工步，则提示「当前工位工序已执行完」）。
- 按钮：［继续执行下一工步］（主按钮，直接以单步方式执行下一工步，不再弹确认）／［关闭］。
- 行为：「继续执行下一工步」等同再次单步执行下一工步（仍受互锁约束，若下一工步为精定位类工步则正常走定位方式弹窗）；「关闭」仅关闭弹窗，断点保留。

### 4.6 弹窗通用规范

- 样式沿用现有玻璃浮层风格；主按钮品牌色，取消灰色，危险操作（停止 / 异常中止）红色。
- 弹窗打开期间互锁照常生效；异常弹窗（4.1）为独占弹窗。
