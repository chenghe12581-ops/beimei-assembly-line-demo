# 生产执行 · 执行控制功能说明

> 依据真实软件截图整理。核心规则（截图批注）：**整线控制按钮与单站控制按钮不可同时使用，一方按钮处于使用状态时另一方置灰。**

## 1. 两区域按钮总览

| 区域 | 位置 | 按钮 | 作用范围 |
| --- | --- | --- | --- |
| 整线控制按钮 | 生产监控视窗顶栏中部 | 初始化、执行（运行中变为「暂停」）、停止 | 整条产线（当前工单的全部工位） |
| 单站控制按钮 | 右侧工位详情内「自动顺序执行工序内工步」条 | 初始化、自动/单步执行、停止执行 | 仅当前查看的工位（复合工位视为一个执行单元） |

## 2. 按钮功能说明

### 2.1 整线控制按钮

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化 | 整线 PLC、机器人、视觉信号复位，任务进入就绪态，日志打印复位结果 | 已选中工单，且任务未处于运行 / 暂停态 |
| 执行 | 下发任务信息至 PLC，整线按工序链自动推进；运行中按钮切换为「暂停」，点击暂停后任务保持当前工步可续跑 | 任务已初始化；无未处理的视觉异常 |
| 停止 | 停止整线执行，任务退出运行态 | 任务处于运行 / 暂停态 |

### 2.2 单站控制按钮

**按钮组随 tab 切换**：自动 tab 显示「初始化、自动执行、停止执行」；单步 tab 显示「初始化、单步执行（执行工步）、停止执行」；手动 tab 不显示执行控制条。两组按钮共享同一份工序状态回显——执行中切换 tab 只换按钮、不换数据，工序进度、当前工步高亮实时同步。

| 按钮 | 功能说明 | 前置条件 |
| --- | --- | --- |
| 初始化 | 仅复位当前工位的设备信号，不影响其他工位 | 无执行会话进行中；任务停止后必须先初始化才能再次执行 |
| 自动执行（自动 tab） | 从**当前工位的工步段落起点**开始（复合工位取该工位在任务工序链中的首个启用工序），连续自动执行该工位工序内工步；不是从整张工单首道工序开始 | 无执行会话进行中；当前工位存在该工单的启用工序，否则置灰并提示「当前工位没有可执行的工序」 |
| 单步执行（单步 tab） | 执行当前选中的单个工步；执行后按钮切换为「暂停」，暂停后任务保持当前工步 | 同「自动执行」；复合工位允许跨工序段落选中 |
| 停止执行 | 停止当前执行动作（与整线「停止」等效），任务进入已停止态 | 存在执行中的会话 |

**三种执行方式的区别**：

| | 整线执行（顶栏） | 单站自动执行（自动 tab） | 单步执行（单步 tab） |
| --- | --- | --- | --- |
| 起点 | 工单首道工序 | 当前工位的工步段落起点 | 用户选中的工步 |
| 推进范围 | 跨工位推进整张工单 | 仅当前工位（复合工位为一个执行单元） | 一次一个工步 |
| 典型用途 | 批量生产 | 某工位单独复产 / 跳过前段 | 调试、验证单工步 |

## 3. 互锁设计

### 3.1 状态定义

- **整线使用中**：整线任务处于运行 / 暂停态（点了「执行」之后，直到「停止」或任务完成）。
- **单站使用中**：当前工位处于「自动执行」中（点了「自动执行」之后，直到「停止执行」或该工位工步执行完）。
- **空闲**：以上都不是。

### 3.2 互锁规则

1. **双向区域互斥**：整线执行会话中 → 单站控制按钮组整体置灰；单站执行会话中 → 整线控制按钮组整体置灰。两组按钮同一时刻只允许一方处于「使用中」。
2. **停止全局同步**：任一侧的「停止 / 停止执行」停止的都是**当前执行动作本身**，不区分触发侧——顶栏「停止」可以停掉单站会话，面板「停止执行」也可以停掉整线执行。**停止后任务进入已停止态，整线执行、单站自动执行、单步执行全部置灰，必须先初始化**，初始化完成后任一侧可重新发起执行。
3. **模式内互斥（单站会话期间）**：执行模式 tab 可自由切换、工序状态实时同步，但**非会话模式的执行按钮与「初始化」保持置灰**——
   - 单站自动执行会话中：切到单步 tab 可查看工步状态，但「单步执行」和「初始化」禁点；
   - 单站单步执行会话中：切到自动 tab 可查看，但「自动执行」和「初始化」禁点；
   - 即：初始化在整个执行会话停止前始终禁点，停止后它是唯一的恢复入口。
4. **执行模式联动**：单站按钮组仅在「自动 / 单步」tab 下显示；「手动」tab 下不显示执行控制条（手动模式只保留设备控制，不推进工步）。tab 切换本身不受执行状态限制（见规则 3），切换后看到的是同一份同步状态。
5. **异常处理流程（弹窗 + 自动停止）**：执行中（整线或单站）检测到视觉异常时，**初始化按钮始终不可点**，走固定流程：
   1. **异常弹窗**：标题与内容区分异常发生的执行侧——「整线执行中检测到视觉异常」（顶栏执行会话中）或「单站执行中检测到视觉异常」（单站/单步会话中），并回显工位、工件、异常工序；
   2. **确认后自动停止**：用户确认弹窗，任务自动停止（等同点击「停止」：进入已停止态、清会话、写日志）；
   3. **停止后才可初始化**：自动停止后所有执行按钮置灰，仅「初始化」可点；操作员可在视觉监控中处理异常数据，处理完成后点「初始化」复位设备信号，再从任一侧重新执行。
   - 异常弹窗出现期间，两侧所有执行类按钮与初始化按钮均不可点（弹窗独占）；不存在"异常未处理但可初始化"的中间态。
6. **工单级约束**：未选中工单时两组按钮均不可用。
7. **置灰反馈**：置灰按钮 hover 时以 tooltip 说明原因，如「整线正在执行，请停止后再操作」「当前工位没有可执行的工序」「存在执行中的会话，请先停止」。

### 3.3 互锁矩阵

| 当前状态 | 整线组 | 单站组 · 自动 tab | 单站组 · 单步 tab |
| --- | --- | --- | --- |
| 空闲（就绪，无会话） | 初始化✓ 执行✓ | 初始化✓ 自动执行✓ | 初始化✓ 单步执行✓ |
| 整线执行中 | 暂停✓ 停止✓（初始化置灰） | 全部置灰¹ | 全部置灰¹ |
| 单站自动执行中 | 全部置灰（仅停止可用¹） | 暂停✓ 停止✓（初始化置灰） | 状态可查看；单步执行✗ 初始化✗ 停止✓ |
| 单站单步执行中 | 全部置灰（仅停止可用¹） | 状态可查看；自动执行✗ 初始化✗ 停止✓ | 暂停✓ 停止✓（初始化置灰） |
| 视觉异常出现 | 弹窗提示（区分整线/单站）→ 确认后自动停止；弹窗期间所有执行类按钮与初始化均不可点 | 同左 | 同左 |
| 已停止（含异常自动停止） | 初始化✓，执行✗ | 初始化✓，自动执行✗ | 初始化✓，单步执行✗ |

> ¹ 停止全局同步（规则 2）：单站会话中顶栏仅「停止」可点（点击即停掉单站会话），整线执行中面板仅「停止执行」可点；任一侧的停止按钮一旦可用即作用于整个执行动作。

### 3.4 原型落地映射

- 整线组 = 现有生产监控顶栏浮动按钮组（初始化 / 执行（暂停）/ 停止）。
- 单站组 = 工位详情内新增「自动顺序执行工序内工步」按钮条，与截图对齐；按钮随 自动 / 单步 tab 切换（自动 tab → 自动执行，单步 tab → 单步执行），初始化 / 停止执行常驻。
- 置灰逻辑在现有任务执行状态机（`running / paused / stopped`）之上，新增**执行会话**状态 `{ 当前执行侧（line / station）、会话模式（auto / single-step）、占用工位 }` 即可推导互锁矩阵：区域互斥由"执行侧"推导，模式内互斥由"会话模式"推导，初始化禁点由"会话存在"推导，停止后恢复由任务 `stopped` 态推导。

## 4. 弹窗提示设计

弹窗共六类：

### 4.1 整线执行中进入单步调试（互锁冲突提示）

- 触发：整线使用中，用户在单步模式选中工步并点击「执行工步」。
- 弹窗标题：「整线正在执行」。
- 内容：整线任务正在执行中，进入单步调试将暂停整线任务并切换到当前工位单步执行。
- 按钮：［暂停整线并执行］（主按钮）／［取消］。
- 行为：确认后整线任务转暂停、互锁权移交单步侧，随后打开 4.3 的执行确认弹窗。

### 4.2 视觉异常弹窗（区分执行侧，确认后自动停止）

- 触发：执行中（整线或单站/单步）检测到视觉异常。
- 弹窗标题：区分执行侧——「整线执行中检测到视觉异常」（会话 side = line）或「单站执行中检测到视觉异常」（会话 side = station，含单步）。
- 内容：回显异常工位、工件号、异常工序/工步；说明「确认后任务将自动停止，停止后请先处理视觉数据，再初始化重新执行」。
- 按钮：［确认并自动停止］（红色）／（无取消——异常必须中止执行）。
- 行为：确认后任务自动停止（等同「停止」：进入已停止态、清会话、写日志）；弹窗出现期间两侧所有执行类按钮与初始化按钮均不可点（弹窗独占）；自动停止后「初始化」恢复可点，处理完视觉异常后初始化复位，再重新执行。

### 4.3 单步执行确认弹窗

- 触发：单步模式下点击「执行工步」（无互锁冲突时直接弹出）。
- 内容：回显工位名称、选中工步名称、加工零件（合并同类项写法）、当前 WP。
- 按钮：［确认执行］／［取消］。
- 执行后：按钮切换为「暂停」，再次点击暂停则任务保持当前工步；空闲工位走演示执行。执行完成弹出 4.4 结束弹窗。

### 4.4 单步执行结束弹窗

- 触发：单步模式选中工步执行完成。
- 弹窗标题：「单步执行完成」。
- 内容：回显工位名称、已执行工步名称、执行结果（成功）；说明当前会话仍保持，可继续选择其他工步单步执行。
- 按钮：［继续单步］（主按钮，关闭弹窗、保持会话）／［停止执行］（结束会话，任务进入已停止态，需初始化后再执行）。
- 行为：选「继续单步」后回到单步面板，工序状态已同步推进；选「停止执行」等同点击「停止执行」按钮（走停止确认语义，因已弹窗可直接停止）。

### 4.5 定位方式弹窗（已存在，纳入本设计）

- 触发：单步模式执行「精定位 / 导入工件位置」工步。
- 内容：左右两栏「执行定位」「导入工件位置」；模拟失败时在当前栏内提示，重拍次数受工艺参数「失败重拍次数」约束，超过后报错终止并写日志。

### 4.6 停止确认弹窗

- 触发：任一侧的「停止 / 停止执行」（两者等效，均停止当前执行动作）。
- 内容：停止后任务进入已停止态，所有执行按钮（整线执行 / 自动执行 / 单步执行）将置灰，需先初始化才能再次执行；当前任务保持在当前工步。
- 按钮：［确认停止］（红色）／［取消］。

### 4.7 弹窗通用规范

- 样式沿用现有玻璃浮层风格；主按钮品牌色，取消灰色，危险操作（停止 / 异常中止）红色。
- 弹窗打开期间，互锁规则照常生效：另一侧按钮保持置灰，不允许绕过弹窗直接操作；异常弹窗（4.2）为独占弹窗，不提供取消。
