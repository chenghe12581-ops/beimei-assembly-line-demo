# 工艺安全点与位姿回显 Feature Spec

## Goal

工艺安全点弹窗用于编辑工序路径中的 6 个安全避让点，并在 3D 视窗中回显对应点位或位姿。任务卡片内的结果点位行也应支持点击回显对应高亮；打磨工序仅回显路径点，其他工序保留现有工具头或遮罩 mock。

当前为前端 demo 回显。打磨工序已接入特征 OBJ 几何，3D 视窗只回显打磨路径点及编号，不回显工具头模型；其余工序仍使用遮罩 mock。

## Entry Points

- 任务列表中支持路径点的任务条目。
- 点击任务条目内的安全点/路径点按钮后打开安全点弹窗。
- 再次点击同一工序按钮关闭弹窗。
- C/D 工艺规划布局中，安全点弹窗是 3D 视窗内浮窗，但必须定位在右侧任务列表面板左侧，不允许被任务列表遮挡；当前右侧任务列表宽度为 420px，弹窗右侧避让距离为 440px。

## Data Model

每个安全点使用 `PickPathPoint`：

```txt
x, y, z, rx, ry, rz
enabled
```

- `x/y/z`：安全点相对位置偏移，UI 标签显示为 `ΔX / ΔY / ΔZ`，单位 `mm`。
- `rx/ry/rz`：姿态角，单位 `°`。
- `enabled`：是否启用该安全点，缺省为启用。
- 支持安全点路径的单组工序默认有 6 个安全点。
- 放置和翻面压紧工序只编辑 J1-J8 结果点位，不显示安全点路径入口。
- 打磨路径点位只维护单组 6 个安全点，安全点弹窗不显示分组 tab；打磨结果点位仍按特征路径生成 `P1-6(n)`。
- 定位焊扫描按扫描结果点分组维护安全点：有几个结果点，就有几组安全点；安全点弹窗使用“扫描点1...N”tab，tab 数量与结果点位数量一致。
- 定位焊按焊缝段分组维护安全点：当前原型固定 4 个焊缝段，每段各 6 个安全点；安全点弹窗使用“焊缝段1-4”tab。
- 样式 C 合并焊接任务在路径点位页顶部增加 `扫描点位 / 焊接点位` 分段选择，位于坐标系和安全点配置工具栏之前。扫描点位和焊接点位均维护 6 组，每组各 6 个安全点；样式 A / B / D 保持原独立任务结构，其中独立定位焊仍为 4 组。
- tab 条为单行横向排列，数量多时允许横向滚动，不换行撑高弹窗。

## Pose Preview Methods

### 打磨真实几何回显

- 打磨结果点从所选打磨特征 OBJ 的中心路径按弧长 `0% / 20% / 40% / 60% / 80% / 100%` 取样，结果点坐标保留在特征线上。
- 安全点顺序为起点远、中、近和终点近、中、远；安全点沿特征面法向逐级接近/离开对应结果点。
- 打磨路径不回显工具头模型；已生成的结果点、安全点数据及点位编辑能力保持不变。
- 打磨结果点在 3D 视窗中使用橙色点和 `P1-P6` 标签标注，标注位置直接使用结果点世界坐标，不随工具头模型 group 姿态发生偏移。
- 点球与编号标签由共享 `ProcessPathPointMarkerModel` 渲染；虚拟仿真复用该组件回显扫描/焊接点位，只通过颜色、半径和标签偏移表达业务差异，不复制另一套点位样式。
- 当前一个打磨工序多选特征时，以第一条已选特征作为这组 6 个结果点的路径来源。
- 固定工序首次创建打磨任务时允许暂用 demo 点位；对应打磨特征 OBJ 加载完成后，如果任务仍保持未编辑的默认 demo 点位，系统必须自动替换为当前特征几何生成的结果点和安全点。已经人工编辑的点位不得被该自动同步覆盖。

安全点位姿预览逻辑应以方法表达，不直接散落在 JSX 中。

- `showPickPathPosePreview(stepId, pointIndex)`：显示某工序的位姿预览。
- `pointIndex` 为数字时，仅显示对应安全点。
- `pointIndex` 为 `all` 时，显示 P1-P6 全部位姿。
- `getPickPathPosePreviewItems(pointIndex)`：根据单点或全部模式返回 3D 视窗需要绘制的安全点锚点。
- `getPickPathPosePreviewTitle(pointIndex)`：根据单点或全部模式返回 3D 视窗提示标题。
- `selectProcessPathPointSegment(segmentIndex)`：切换定位焊扫描点或定位焊焊缝段，并清空当前位姿预览；打磨不使用安全点分组 tab。
- 样式 C 切换 `扫描点位 / 焊接点位` 时清空当前单点位姿预览；坐标系显示模式共用，分组折叠状态、结果点、安全点和安全点配置目标按当前分段隔离。
- `updatePickPathPoint(stepId, segmentIndex, pointIndex, axis, value)`：更新指定段、指定安全点、指定轴向值，并标记点位脏状态。
- `setPickPathPointEnabled(stepId, segmentIndex, pointIndex, enabled)`：启用或禁用指定安全点，保留原点位值。
- `resetPickPathPoints(stepId)`：将当前工序所有安全点组恢复为全局生成路径时的默认数值，并恢复全部启用状态。

结果点位回显沿用同一类方法入口，后续接真实 3D 时只替换数据映射，不改每一行的点击契约。

- `selectedResultPointPreview`：记录当前被选中的结果点位 `{ stepId, pointIndex }`，用于行高亮。
- `showResultPointPosePreview(stepId, pointIndex)`：结果点位行点击入口。
- 当前 demo 内，`showResultPointPosePreview` 会复用安全点遮罩回显，将结果点位索引通过 `pointIndex % 6` 映射到 P1-P6 的固定锚点。
- 真实 3D 接入时，保留 `showResultPointPosePreview(stepId, pointIndex)` 事件入口，把内部映射替换为该工序结果点的真实世界坐标、TCP 姿态和模型点位高亮 id；只有允许回显工具头的非打磨工序才绑定工具头模型实例。
- 定位焊焊缝段标题仍使用 `showWeldSegmentPreview(stepId, segmentIndex)`，用于高亮焊缝段并同时回显段起点/终点；段内起点/终点单行点击仍走 `showResultPointPosePreview`。

## Interaction Rules

- 点击图例中的 P1-P6：3D 视窗只回显对应安全点的高亮或位姿；打磨工序不显示工具头模型。
- 点击“显示全部位姿”：3D 视窗同时回显所有启用的安全点。
- 弹窗底部 footer 放置“更新”按钮，点击后清除当前工序点位脏状态。顶部右侧只保留图例折叠、最小化和关闭等窗口控制。
- 顶部右侧的图例折叠按钮用于隐藏/显示左侧图例，隐藏后弹窗整体缩窄，右侧安全点编辑区保持紧凑宽度；按钮 tooltip 使用“展开图例 / 收起图例”。
- 弹窗外壳使用 3D 视窗内浮窗统一样式：`bg-ds-bg-glass-float`、白色半透明 stroke、轻量 shadow 和 `backdrop-blur-md`；定位规则单独处理右侧任务列表避让。
- “显示全部位姿”按钮固定在图例区域下方，距离图例区域底部约 36px。
- 点击右侧安全点卡片：与点击图例点位一致，回显对应安全点。
- 当前被回显的安全点在图例和卡片中高亮。
- 每个安全点卡片标题行有独立启用/禁用控件，呈现为“启用”文字和 checkbox，不使用可见性图标表达启用状态。
- 每个安全点卡片参数区第一行显示 `ΔX / ΔY / ΔZ`，第二行显示 `RX / RY / RZ`。
- 安全点卡片内的 `ΔXYZ / RPY` 数值输入使用组件库独立 `SafetyPointNumberInput` 变体，避免标题行坐标摘要、输入框单位字符或上下步进按钮影响紧凑浮窗。
- 禁用安全点时，弹窗内图例点和安全点卡片变灰，输入框不可编辑，但保留原值。
- 禁用安全点时，C 工艺规划任务详情的路径点位列表隐藏对应安全点；结果点列表保持显示。
- 单点点击禁用安全点不回显位姿。
- 全部位姿模式下，仅启用的安全点高亮。
- 编辑任一安全点字段后，该工序进入点位脏状态。
- 点击“重置”后，当前工序所有安全点组的禁用状态和数值更改恢复为全局生成值，并进入点位脏状态。
- 点击“更新”后清除点位脏状态。
- 切换定位焊扫描点或定位焊焊缝段时，清空已有位姿预览，避免显示上一组的点位。
- 点击任务卡片内任一结果点位行：打磨工序在 3D 视窗中保留整组路径点并高亮当前行，不回显工具头模型；其他工序保留现有位姿回显。
- C 工艺规划布局焊接任务（定位焊、定位焊扫描、合并焊接）的路径点位改为焊缝段表格：上方以网格展示全部焊缝段（定位焊 4 段、定位焊扫描与合并焊接 6 段，一行三个），选中态高亮，点击某段后下方刷新该段详情；段详情标题行右侧为全部展开/收起图标，任务有未保存修改时焊缝段标题旁显示橙色标记。选中段下方显示「扫描路径 / 焊接路径 / 压紧配置」三个视图。扫描/焊接路径视图内嵌展示该段路径点位（扫描点/焊接点）与结果点位，可直接编辑写回，原“安全点配置”浮窗与顶部“扫描点位 / 焊接点位”分段在样式 C 已移除（安全点浮窗仅样式 A / B / D 保留）；未生成的路径视图显示空态。压紧配置视图内嵌压紧点配置面板：维护当前段 J1-J6 关节结果点（J1 为 mm、其余为 °，默认值与翻面压紧任务“生成压紧位置”的 demo 结果同源），可通过开关设置该段不启用压紧（关闭后关节角行禁用，不显示工作台、压紧编号、覆盖率字段）。坐标系 radio 已移除（内部固定按“世界”坐标系显示与写回，仅改变前端 demo 展示），焊接任务不再渲染路径点位工具栏。编辑任一安全点或结果点字段后，该工序进入点位脏状态，并让当前装配体进入未保存状态；面板右上角“重置”恢复该任务路径点位与压紧配置默认值并进入脏状态。
- 打磨结果点的 XYZ 编辑应实时驱动 3D 视窗中对应点位平移；RPY 数据仍保留并可编辑，但不通过工具头模型回显。
- 点击放置/翻面压紧的 J1-J8 行：3D 视窗回显该关节结果对应的 demo 工具头姿态，并高亮当前行。
- 点击抓取的电磁铁位置结果行：3D 视窗回显电磁铁工具头位置，并高亮当前行。
- 点击路径安全点时，应清空结果点位选中；点击结果点位时，应清空安全点弹窗中的单点选中语义，避免两个来源同时表现为当前回显。

## Demo Limitations

- 打磨工序当前只使用 OBJ 几何和路径点标记做前端回显，不接入真实 TCP、机器人运动学或后端路径规划。
- 定位焊、定位焊扫描、装配定位、抓取和放置/压紧继续使用原有遮罩 mock 回显。
