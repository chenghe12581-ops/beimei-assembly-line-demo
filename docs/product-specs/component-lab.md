# Component Lab Product Spec

## Goal

组件库用于管理当前原型中可复用 UI 组件、组件状态、组件变体和样式规范，避免主页面和组件示例不一致。当前 `/component-lab` 只展示样式 C 主线组件；旧强调态和过程稿统一进入 `/component-drafts`。

## Users

- 前端开发者
- AI coding agent
- 设计/产品评审者

## Views

交互组件页支持两种视图：

- 分栏：左侧组件目录，右侧查看选中组件、变体和样式参数。
- 平铺：一次性查看所有组件，用于快速扫视一致性。

交互组件页在分栏 / 平铺之上增加二级分页：

- 通用组件：跨页面复用的基础控件和状态原语。
- 工艺执行：工艺参数、路径点位、3D 视窗和工艺规划任务面板。
- 生产执行：生产工位、设备状态、托盘管理和 AGV 调度。

每个二级分页内的组件分组使用风琴式折叠：

- 默认展开当前分页的第一个分组。
- 展开任一分组时，当前分页内其它分组收起。
- 分栏目录和平铺总览共享折叠状态，帮助保留结构层级。

交互组件页目录采用四层结构：

- 基础交互控件：跨页面复用的按钮、输入、选择和状态原语。
- 领域复合组件：工艺参数、点位、路径、安全点和关节角等业务控件。
- 工作区 / 视窗组件：3D 视窗壳、工具条、视窗内浮层、模型对象 pill 和特征回显。
- 场景应用变体：按业务边界展示工艺规划、生产执行和托盘管理组合样式。

过程稿页 `/component-drafts` 用于留档：

- 旧白底橙色强调态点位 / 安全点。
- 抓取参数旧三列磁铁卡片和齿轮浮窗。
- 样式 A/B 完整工艺任务大卡片。
- 样式 D 圆角玻璃浮层探索稿。

## Required Component Categories

- 带单位输入框
- 范围输入框
- 百分比 Slider
- 多选控件
- 对象/特征多选下拉
- 轴向单位输入行
- 点位信息单行
- 关节角组件
- 视窗工作区组件
- 工艺规划任务面板
- 生产执行组件
  - 新建工单编辑器：草稿工单卡片 stack、可下发 Checkbox、项目结构树、上模型 / 下工序分区、局部下一步和全局下发生产
- 托盘管理组件状态
- 组合参数卡片

## Rules

- 主页面中出现的新组件样式必须同步到组件库。
- 组件库应展示默认、异常、置灰状态。
- 组件库应记录圆角、stroke、背景、字体、颜色等样式参数。
- 工艺规划任务面板应接近真实任务列表宽度，不要为了平铺而拉满整行。
- 视窗工作区、生产执行和托盘管理组件应独立成组，不得混入工艺规划任务面板。
- 生产执行整页预览应可切换旧样式 24 条工序与新样式每 WP 16 条聚合任务。
- 分栏和平铺只展示当前二级分页内的组件，不跨分页混排。
- 二级分页内的分组必须可折叠，避免单页内容过长。
- 平铺视图用于总览，分栏视图用于精调。
- 主 Component Lab 不展示完整旧强调态组件；历史过程稿必须从 `/component-drafts` 追溯。

## Acceptance Criteria

- [ ] 支持分栏和平铺切换。
- [ ] 支持通用组件、工艺执行、生产执行二级分页切换。
- [ ] 支持当前二级分页内的分组风琴式展开 / 收起。
- [ ] 带单位输入框有 sm/md/lg 和左右对齐规格表。
- [ ] 工艺规划任务面板至少覆盖抓取、放置、打磨、装配定位、翻面压紧和样式 C 合并焊接；合并焊接展示扫描参数 / 焊接参数分区，以及扫描点位 / 焊接点位分段，两侧各 6 组。
- [ ] 工艺规划任务面板使用样式 C 当前示例 + 覆盖矩阵，不再平铺七套完整 A/B 大卡片。
- [ ] `/component-drafts` 可追溯旧强调态、A/B、D 样式和重复过程稿。
- [ ] 视窗工作区组件独立展示 3D 视窗工具条、视窗内浮层和模型对象状态，并包含虚拟仿真“调整装配体位置”的世界 / 父系坐标切换、六轴输入及展开 / 收起状态。
- [ ] 生产执行组件独立展示工位卡片、产线轴测回显和设备状态，并展示普通现场托盘卡片与占用托盘编辑态。
- [ ] 生产执行组件展示新建工单编辑器的多草稿工单栏、配置完成后可用的 Checkbox、选中数量提示和局部两阶段布局，且弹窗级「下发生产」不与单工单下一步混用。
- [ ] 生产执行异常处理同时保留重构结果原组件、第二种异常处理原始样式和 8 视觉 Tab Demo；8 视觉 Demo 一次只显示当前视觉的点云与异常面板，支持对应结果字段编辑、重新扫描、跳过和确定。
- [ ] 新样式任务保持 WP 分组和单行条目，托盘任务执行时在中间视图更新对应托盘卡片。
- [ ] 托盘管理组件独立展示计划/实际视图、AGV 调度、归档/历史任务和托盘清单状态。
- [ ] 组件状态切换会影响当前展示组件。
- [ ] 复合组件优先引用基础组件，而不是重复写输入框视觉规则。
