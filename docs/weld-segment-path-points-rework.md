# 焊接任务路径点位改造 · 交互及说明文档

> 适用版本：北煤机拼装产线原型（beimei-assembly-line）2026-09-29 ~ 2026-09-30 改造
> 适用范围：样式 C 工艺规划布局中，焊接类任务（合并焊接、定位焊、定位焊扫描）的「路径点位」页签

---

## 1. 背景与目标

原实现中，焊接任务的路径点位存在三个问题：

1. **维度错位**：用户的心智模型是「一个焊缝段 → 一组扫描路径 + 一组焊接路径 + 一组压紧配置」，但界面把「扫描/焊接」放在面板顶部分段、「焊缝段」藏在弹窗内部，两个维度各管一摊；
2. **入口分散**：扫描安全点、焊接安全点、压紧配置分散在两个浮窗 + 一个顶部分段里，来回切换容易迷失；
3. **配置冗余**：安全点配置弹窗在实际流程中从未被使用，且编辑时浮窗遮挡 3D 视窗，无法对照模型。

改造目标：以**焊缝段为工作单元**重构路径点位，段内集中管理三组配置，全部内嵌面板完成，不再依赖浮窗。

## 2. 改动总览

| 序号 | 改动 | 说明 |
| --- | --- | --- |
| 1 | 移除坐标系 radio | 路径点位工具栏不再显示「世界 / 父系坐标系 / 物体」，内部固定按世界坐标系显示与写回 |
| 2 | 新增压紧点配置（第一版） | 曾在工具栏加「压紧点配置」按钮 + 浮窗（焊缝段 1-6 分页、J1-J6），后随方案 B 废弃浮窗形态 |
| 3 | 方案 B 重构 | 路径点位改为「焊缝段网格 + 段详情三视图」结构，见第 3 节 |
| 4 | 移除安全点配置（样式 C） | 工具栏「安全点配置」按钮与安全点浮窗在样式 C 移除；旧样式 A / B / D 的「查看路径点位」仍保留原浮窗 |
| 5 | 段列表网格化 | 段列表去掉摘要信息（扫描/焊接点数、压紧状态）和选中小圆圈，改为一行三个的网格按钮 |
| 6 | 展开/收起图标挪位 | 从段块标题行挪到段详情标题行最右侧 |

## 3. 现状交互说明

### 3.1 入口与整体结构

进入样式 C 工艺规划 → 选中一个焊接类任务（任务条显示「焊接」等）→ 右侧详情切到「路径点位」页签，结构自上而下：

```
┌─ 路径点位 ────────────────────────────── 重置 ─┐
│ 焊缝段（6）                                   │  ← 未保存时标题旁有橙点
│ ┌────────┬────────┬────────┐                │
│ │ 焊缝段 1 │ 焊缝段 2 │ 焊缝段 3 │                │  ← 网格，一行三个
│ ├────────┼────────┼────────┤                │
│ │ 焊缝段 4 │ 焊缝段 5 │ 焊缝段 6 │                │
│ └────────┴────────┴────────┘                │
│ ┌──────────────────────────────────────┐   │
│ │ 焊缝段 2  [扫描路径|焊接路径|压紧配置]      ⇅ │   │  ← 段详情
│ │  …（当前视图内容）…                       │   │
│ └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 3.2 焊缝段网格

- **段数**：合并焊接 / 定位焊扫描为 6 段，定位焊为 4 段；
- **选中**：点击任一段按钮，选中态为白底橙色文字，下方详情区立即刷新为该段内容；
- 段数超过一行时自动换行（6 段 = 两行，4 段 = 一行 + 一个）。

### 3.3 段详情三视图

选中段后，通过页签切换三组配置：

#### 扫描路径 / 焊接路径

- 内嵌展示该段的**路径点位**（扫描点/焊接点 1-6，XYZ + RX/RY/RZ 六轴可编辑）和**结果点位**（焊缝段起点/终点，灰底区块区分）；
- 点击点位行在 3D 视窗回显对应位姿；字段编辑即时写回并进入未保存状态；
- 该任务未生成的路径（如定位焊扫描任务没有焊接路径），页签显示「·未生成」，视图内为空态提示；
- 合并焊接任务的两个视图数据完全隔离（扫描存 `weldScanConfig`，焊接存 `weldConfig`）。

#### 压紧配置

- **启用压紧**开关：控制当前段是否参与压紧，关闭后 J1-J6 行整行禁用，并提示「该焊缝段已关闭压紧，关节角不参与回显与加工」；
- **J1-J6 关节结果点**：滑杆 + 步进输入，J1 单位为 mm（0~200），J2-J6 单位为 °（-180~180），可直接修改；
- 默认值与翻面压紧任务「生成压紧位置」的 demo 结果同源（12.50 / -18.20 / 36.80 / 72.40 / -44.60 / 28.30）；
- 只维护结果点位，**不显示**工作台、压紧编号、覆盖率等翻面压紧工艺参数字段。

### 3.4 展开 / 收起

- 段详情标题行最右侧的 ⇅ 图标，控制下方点位行的全部展开/收起，与工具栏时代的行为一致。

### 3.5 脏状态、重置与保存

- 编辑任一扫描点/焊接点/结果点字段、切换任一段的启用压紧、修改 J1-J6，该任务即进入**点位脏状态**：焊缝段标题旁出现橙色标记，任务条出现未保存状态（样式 C 规则）；
- 面板右上角「**重置**」：恢复该任务的全部路径点位与压紧配置为生成默认值，并进入脏状态；
- 通过任务条尾部「**保存**」统一应用并清除脏状态（不再有独立的「确认」按钮）。

## 4. 字段与数据说明

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 扫描路径点位 | `step.weldScanConfig.pathPointGroups[段]`（合并焊接）/ `step.weldConfig.pathPointGroups[段]`（定位焊扫描） | 每段 6 点，XYZ（mm）+ RPY（°） |
| 焊接路径点位 | `step.weldConfig.pathPointGroups[段]` | 同上；定位焊 4 段，合并焊接 6 段 |
| 结果点位 | `*.points` + `*.posePoints`，按 `段×2` 取起点/终点 | 未生成时回退到预览 mock 值 |
| 压紧配置 | 页面态 `clampPointSegmentsByStepId[stepId]` | 每段 `{ enabled, joints[6] }`，随任务重置恢复默认；当前为前端 demo 态，未持久化到项目数据 |
| 坐标系 | 固定「世界」 | 显示与写回均不再做坐标偏移换算 |

## 5. 技术实现要点

### 5.1 文件清单

| 文件 | 改动 |

| `src/app/BeimeiAssemblyLinePage.tsx` | 新增 `renderCompactWeldSegmentPathPoints` 渲染焊缝段网格 + 段详情三视图；删除安全点/压紧点工具栏按钮、压紧点浮窗、旧分组渲染代码；面板「重置」联动恢复压紧配置 |

| `src/app/ComponentLabPage.tsx` | 工具栏演示同步；新增「压紧点配置面板」演示；旧压紧点浮窗演示替换 |

### 5.2 复用组件

- 点位行：`ProcessPosePointInfoRow`（扫描点/焊接点/结果点通用）；
- 关节角行：`ProcessJointAngleRow`（滑杆 + 步进输入，J1 mm / J2-J6 ° 规则内置）；
- 开关：`ParameterSwitch`；按钮 / 页签分段：既有 `Button` 与设计 token 样式。

### 5.3 兼容性说明

- 样式 A / B / D 的旧任务面板**未改动**：「查看路径点位」仍打开原安全点弹窗，打磨工序的内联安全点编辑不受影响；
- 坐标系换算函数（`getCompactCoordinateFramePoint` 等）保留，固定以「世界」调用。

## 6. 已知限制与后续建议

1. **压紧配置为前端 demo 态**：`clampPointSegmentsByStepId` 存在页面内存中，切换项目/刷新后丢失，也未接入项目导出；如需持久化需扩展项目数据结构与保存/导出流程；
2. **段选择与 3D 视窗未联动**：当前点击焊缝段不会高亮视窗中对应焊缝（视窗已有焊缝段高亮能力，可复用 `weldSegmentPreview`）；
3. **旧样式浮窗仍保留**：若确认旧样式 A / B / D 不再演示，可连同安全点弹窗整体移除；
4. **组件库工序面板变体**：组件库中旧的「扫描点位 / 焊接点位」面板演示未按新结构重做，如需以组件库为新结构事实来源，可补一个焊缝段表格的完整演示变体。
