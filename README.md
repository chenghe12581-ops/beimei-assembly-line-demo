# 北煤机拼装产线

北煤机拼装产线 3D 可视化与工艺规划 Demo。

## 技术栈

- React 18
- Vite 6
- TypeScript
- TailwindCSS 4
- @react-three/fiber + @react-three/drei + three.js
- shadcn/ui 组件

## 安装依赖

```bash
npm install
```

## 开发

```bash
npm run dev
```

默认开发地址：`http://localhost:5173/`

## 构建

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

## 模型文件

STL 模型文件位于 `public/models/`，构建时会复制到 `dist/models/`。
